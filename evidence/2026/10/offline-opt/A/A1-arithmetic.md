# A1 定点与混音算术约定

对象：`rtl/prototypes/instrument_ram_wavetable_engine.v`（32 声部振荡器）、
`rtl/prototypes/instrument_ram_audio_compute.v`（lane 汇总）、`rtl/audio/wide_master.v`（主混音）。
日期 2026-10-24，无硬件条件。本文件是**实测与穷举证明的结论**，不是设计意图的转述：
所有数字由 `tools/offline_opt/a/a1_bounds.py` 穷举 48 张现装波表得到，证据见
`A1-bounds.json`；逐样本一致性由 `sim/opt_a/tb_opt_a_datapath.v` 与
`tb_opt_a_master.v` 对照 `tools/offline_opt/a/ref_engine.py` 得到。

## 2. 舍入约定

三级都用同一条“先算术右移、再补半个 LSB”的规则：

```
round_half_up(p, s) = (p >> s) + bit(p, s-1)        // >> 为算术右移，向下取整
```

对负的奇数乘积，这等价于**向 +∞ 取整**（不是向零、也不是远离零）。
每级误差 ≤ 0.5 LSB；全链最坏 ≥2 级舍入 = 1 LSB（8 位小数域），
相对最终 24 位输出 ≤ 2⁻¹³ LSB，记为“等价优化”允许的误差界。

主混音的两处偏置是同一规则：`base` 内的 `+(1<<(7+VOICE_SHIFT))` 是
`>>(8+VOICE_SHIFT)` 的半 LSB，`+(1<<11)` 是 `>>12` 的半 LSB。
两处串联后**零输入仍然精确为零**：`sine=0,bright=0 → numerator=2^12 → master_sample=0
→ output=(0·gain+2048)>>12=0`。`tb_opt_a_master` 的 `(0,0)` 用例逐位验证了这一点
（`dp` 场景的 192 帧预热同样逐帧为 0）。

## 3. 饱和与回绕

- 唯一饱和点在 `wide_master` 输出：`output_value > 8388607 → 0x7FFFFF`，
  `< −8388608 → 0x800000`。判定用饱和前的 51 位值，`clip_count` 只在真实削波时加一。
- 32 声部配置**结构上不可能削波**：单声部最大 8 388 351，求和后
  `255·2^28 / 2^13 = 8 355 584 < 8 388 607`，即 8/256 的余量来自 ×255/256 的
  混音系数。削波只在 64 声部双 lane 或外部注入超范围 lane 总值时出现，
  `tb_opt_a_master` 用 ±2³¹ 注入覆盖了两侧饱和。
- 其余各级均**不饱和**，靠位宽保证不溢出（见上表）；不存在“削波当保护”的隐藏行为。

## 4. 为什么没有改位宽

穷举结论：在冻结的 bank 映射与现装 48 张表下，每一级都有正余量，最小的是
插值值（256 LSB）和包络缩放（383 LSB）——这两级是**按 16 位表满量程精确设计**的，
不是余量紧张的错误：表值 32767 右移 8 位后 8 388 352，加上 16 位包络满量程
再右移 16 位必然回到 8 388 225，任何更窄的位宽都不成立，任何更宽的位宽都不会
改变结果。加大位宽只会延长 24 位进位链、消耗 v0.8 归档里仅 0.330 ns 的 setup 余量。

真正**有条件**成立的只有两处，均已在 `a1_bounds.py` 中作为守卫记录：

1. 插值增量：需要相邻采样步长 ≤ 32 768（实测最大 3 650，余 3.17 bit）。
2. 表对混合：需要可达的相邻表差 ≤ 8 388 607（实测可达 151 552，余 5.79 bit）。
   结构性最坏 14 018 091 出现在 guitar 变体 14/15 之间，但吉他
   `candidate_weight` 恒为 0，该乘法的乘积恒为 0，不可达。

若以后新增音区/换表，`a1_bounds.py` 会在任何可达切片的余量不足 1 LSB 时以非零退出拒绝，
不需要重新推算；结构性但不可达的一行标为 `(info)`，不计入判定。

## 5. 组合长路径（未改，记录）

v0.8 归档的最差 setup 路径是
`u_banks/u_guitar/gg5/DO[1] → u_core/mul_a[22]/D`，13.199 ns / 13.563 ns
（setup +0.330 ns）。即“ROM 输出 → `instrument_rom_banks` 组选择 mux（15:1 再 3:1）
→ 17 位差 → 33 位 mul_a 寄存器”。本任务不改它：

- 它属于 2026-10-22 已完成的流水重构范围（“优化 07”“close 73.728MHz timing”），
  再切一次是重复劳动；
- 该路径不经过本任务讨论的任何 24 位加法，A2 只换 ROM 内容、不增加 mux 深度，
  因此 A2 不会让它变差；
- 若要再争取余量，最小改动是把 `instrument_rom_banks` 的输出打一拍并把
  `bank_low/bank_low+1` 两次读的消费状态各后移一拍（+1 状态 = 20 拍/声部，
  帧预算 640/1536 仍满足）。需要时另开任务，不在本次静默实施。
