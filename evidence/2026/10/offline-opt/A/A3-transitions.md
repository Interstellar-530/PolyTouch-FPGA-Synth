# A3 去爆音与过渡：实测结论与移交

日期 2026-10-24。测量器：`tools/offline_opt/a/a3_transitions.py`，结果
`A3-transitions.json`。渲染用 A1 的 64 位参考模型，该模型已由
`tb_opt_a_datapath` 证明与 RTL 逐样本一致，因此下表是**数据通路本身的数字**。

## 1. 方法

对每个过渡给出四个数：过渡当拍的逐样本阶跃、过渡前后 ±64 拍的稳态阶跃 p99 与最大值、
以及**额外残差**（过渡阶跃减去稳态最大值，不足为 0）。高音正常波形本来就可能
每拍移动 1.5 万 LSB，所以只有“超过稳态斜率”的部分才算爆音，这也是计划里
“用连续参考及切换瞬间的额外残差比较过渡噪声”的落地方式。

## 3. 结论

1. **A 线数据通路没有引入任何爆音级阶跃。** 表阶段迁移、换表、释放、静音、
   主音量与压力阶跃的过渡阶跃都**低于同一片段正常波形的斜率**，额外残差恒为 0。
   因此不存在“用 weight/增益路径再平滑一次”的理由：现有的
   `frame_weight` ±1/拍、`gain_q12` ±32/拍、包络 ±140/−16/−48/拍 已经把这几处
   控制在正常波形运动之下。按计划“A3 只修改数据通路的过渡处理”，本轮**没有需要
   修改的数据通路过渡**，也就没有“关掉优化的对照”可做——不是省略，而是测下来
   没有可关的东西。
2. **唯一真实爆音来自重按时的包络清零**：`voice_sched32` 在
   `EV_COMMIT` 中把 `env[pick] <= 16'd0`，同一拍输出的残余幅度被直接砍断，
   额外残差 53 603 LSB（−43.9 dBFS），远高于正常斜率。
3. 重按的平滑属于**包络所有者（B 线）**，计划明确要求“包络和表阶段定时仍由 B 维护…
   避免两侧重复平滑”。A 线不重复实现，改为移交。

## 4. 移交 B 线的补丁建议（未应用）

`rtl/prototypes/voice_sched32.v`，`EV_SCAN`/`EV_COMMIT` 内：

```verilog
// 现状：重按直接把包络清零，输出在一拍内从残余幅度跳到 0。
env[pick] <= 16'd0;
// 建议：不变量中增加 prev_env[pick] <= env[pick]（或直接用 env[pick]），
// 重按首拍沿用旧包络并进入 3..4 拍的线性下坡，坡底再切到 0 并起音：
env[pick] <= pre_env;            // pre_env 为本次 commit 前的 env[pick]
est[pick] <= ST_ATTACK;
```

验收方式与本次相同：`a3_transitions.py` 的 `retrigger` 用例额外残差应从
53 603 LSB 降到 0；`tb_voice_sched32_review` 与 `tb_ram32_engine_audio` 需要
接受“重按后首拍包络不再为 0”这一有意行为变化。若选择不做，材料中应保留
“重按存在 −43.9 dBFS 数字阶跃”的实测记录，不声称已消除。
