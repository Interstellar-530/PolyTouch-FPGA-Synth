# CH9350L 模块端口与拨码丝印证据 20261028-v0.1

原始照片：`archive/FPGA-20261028-v0.2/evidence/ch9350-reference-0.png`（正面）与
`-1.png`（背面）。这两张文件扩展名是 `.png`，实际字节是 JPEG（原始对话附件即为 JPEG），
直接按 `.png` 打不开；用图片查看器或先改后缀再打开。

出处：本地对话“这是到位的CH9350L模块，告诉我应该如何把它连接到开发板上”
（2026-10-26，ID `01a177b9-ec94-7360-be5a-9db58086dd63`）的两张附件，
由 `ch9350-reference-provenance.txt` 记录提取过程。

本目录为本次（2026-10-28）回答“USB-A 是上面还是下面那个”时做的局部放大，
均为原图的裁剪 + LANCZOS 放大，未做内容修改（只调了对比度）。

| 文件 | 原图区域 | 看到什么 |
|---|---|---|
| `front-silk-upper-usb.png` | 正面，USB-A 左侧竖排丝印 | 竖排文字 `上层USB DM DP`（下端 `DP` 被裁掉）。说明这个双层座子的**上层**走 `DM/DP`，即 CH9350L 的第 1 组 USB |
| `front-connector-shell.png` | 正面 USB-A 外壳 | 金属外壳包住上下两层的叠层结构，顶部是外壳焊脚；受拍摄角度限制看不到两个口的内腔 |
| `back-dip-legend.png` | 背面五位拨码旁的功能表 | 表列 `S0 / S1 / BA0 / BA1 / SEL`；文字为 `工作状态设置`、`默认是0/1`、`波特率设置，默认是115200`、`1：下位机 0：上位机`、`485控制 外接485时的方向控制脚` |
| `front-dip-switches.png` | 正面五位拨码 | 上方丝印 `SEL BA1 BA0 S1 S0`（从左到右）对应开关本体上从左到右的 `1 2 3 4 5`；`ON` 字样印在左侧，即拨钮朝 `ON` 一侧为 1。照片里五个拨钮的位置差得很少，**不能**据此判断当时配的是 state 2 还是默认 state 0/1，实物以通电抓帧为准 |
| `back-connector-underside.png` | 背面插座的底面 | 只能看到外壳的两个焊脚，不能据此判断另一层端口的有无 |

结论边界：丝印只证明了**上层 = DM/DP**；“下层 = HM/HP”是按 CH9350L 手册“下位机模式有两组
USB（DM-DP、HM-HP）”和叠层座子的通例推得，**没有**在这两张照片上直接读到 `下层` 字样。
实物到手时以模块上的实际丝印为准。
