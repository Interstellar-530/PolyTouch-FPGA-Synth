# 第一项：FSR 全局音量控制

2026-10-16；基线 `40ef0128dadffdcbae221b79e7ee1bac11cf9ef0`；本地分支 `codex/s4-s6-pressure`。本项完成后等待用户指令，不继续构建入口、音色切换或后续优化。

## 实现结果

标准 I2S 档手动演奏时，FSR 的 CH0 原值经既有中值/IIR 滤波，再映射为全局 VCA 的 Q12 增益，在 16 位饱和之前作用于宽混音样值。压力不参与相位、音高、分配器或 ADSR，改变压力不会重新起音。

| 顶层参数 | 默认值 | 含义 |
| --- | --- | --- |
| PRESSURE_ENABLE | 标准档 1，PT8211 档 0 | 编译期旁路；为 0 时保持原混音逐位结果 |
| PRESSURE_ADC_LOW | 128 | 无载/轻压死区上沿，以下保持最低增益 |
| PRESSURE_ADC_FULL | 3200 | 满增益端点；以上钳位到 1.0 |
| PRESSURE_MIN_GAIN_Q12 | 1024 | 最低音量 25%，不用手压住 FSR 也能弹琴 |
| PRESSURE_GAIN_STEP | 32 | 每音频帧最大增益变化；完整 25%-100% 跨度 96 帧，48 kHz 下 2 ms |

128-3200 是可调的初始 ADC 标定，不是实物力值或已测校准。默认增益跨度和 ADC 跨度均为 3072，线性映射只用加法，不引入控制路径乘法/除法。自定义标定跨度使用常数比例换算，本轮也逐码验证了非默认标定分支。

启动和演示模式的目标增益为 1.0，手动模式转入压力控制时逐帧平滑；动态旁路也以同样方式回到 1.0。没有新增板级端口、引脚或 UART 命令。PT8211 默认旁路保证旧基线可用；标准档参数设为 0 可整体旁路。

新增 VCA 的算术宽度为 signed 18 位样值 × signed 14 位正增益，结果 32 位，再移位回到 Q0。输入分量和及混合权重保证样值适合 signed 18 位；全码随机极值测试验证了有符号运算。预计最多新增一组 18×18 级乘法运算，**不增加 BSRAM**；本轮未重做综合，不能把这项估计写成实际 DSP/Fmax 报告。满压力保持原主增益，因此此前满幅同相削波问题仍单列待优化。

## 本机验证

| 测试 | 本轮结果 |
| --- | --- |
| tb_pressure_gain（新增） | 4797 帧；4096 ADC 码；默认/非默认标定、逐帧步长、静态/动态旁路、正负极值、饱和前衰减、削波统计全部通过 |
| tb_pressure_top（新增） | 真实 GPIO + ADC 模型 + 合成 + 独立 I2S 接收；1494 帧音频解码、3712 帧宽混音逐值比较；相位/增量/包络/分配一致；演示旁路和松键归零通过 |
| tb_pressure_bend | 640 个压力 tick、4096 弯音码参考对照通过 |
| tb_shared_engine | 16 组原分量和、混合及削波用例通过，默认旁路保持旧语义 |
| tb_top_i2s | 8621 帧引脚解码通过，帧格式、A4、四声部增量与 M0/M1 均通过 |

顶层轻压/重压各采集 512 个独立解码样值，RMS 比 **3.999443**，约 +12.04 dB；压力由 0 阶跃至满量程，本次调度相位下增益达到 90% 变化约 **3569.286 µs**。该指标包括 RTL 的 ADC 轮询、压力滤波与增益平滑，不含模拟 DAC/传感器机械响应，也不是所有扫描相位的最坏实测延迟。

五项最终编译、仿真退出均为 0。新顶层参考模型首次运行混用了 unsigned 增益与 signed 样值，期望值的右移变为逻辑右移；已改为两个 signed 整数操作数并重跑，通过时生产逻辑未变。这是测试模型修正，不是移除断言。完整门禁脚本仅登记新增两台测试并通过 PowerShell 语法检查，本轮没有运行完整门禁、烧录或新的综合/PnR。
