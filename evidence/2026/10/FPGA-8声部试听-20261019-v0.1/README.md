# 8 声部试听音频

日期：2026-10-19。用当前 72 张钢琴波表按 `shared_wavetable_engine` 的选表/插值规则软件渲染。**注意：第一版试听脚本的相位增量单位写错（把 Hz 当表索引增量），C4 实际跑到约 24 kHz 并混叠，听起来尖锐、有毛刺；本目录已替换为修正版。**

## 文件

| 文件 | 采样率 | 说明 |
|---|---|---|
| `demo_8voice_48k.wav` | 48 kHz | Windows 播放用（从 46.875 kHz 线性重采样） |
| `demo_8voice_46875.wav` | 46.875 kHz | 原始采样率，6.6 s 单声道 16 位 |

## 内容

1. 0.05–1.45 s：C4–E4–G4–C5 和弦。
2. 1.55–4.0 s：C4–E4–G4–C5–E5–G5–C6 琶音。
3. 4.05–5.95 s：C4–D4–E4–G4–A4–C5–E5–G5 八音和弦。

## 处理

- 每声部 8 ms 起音、约 0.95 s 指数衰减、100 ms 释音；
- 起音从较亮表开始，按 8192 采样/级连续衰减到琴体表；
- 8 路求和后 ÷8；
- 0.75 FS 以上 4:1 软限幅；
- 归一化到峰值约 −1.03 dBFS。

## 实测

- 时长 6.6 s，48 kHz，316 800 样本；
- 峰值 29 162（−1.03 dBFS），RMS −20.05 dBFS；
- 削波样本 0；
- 频谱重心 **1.14 kHz**，5 kHz 以上能量 **0.66%**（修正前分别是 11 kHz 和 71%，即混叠噪声）。
