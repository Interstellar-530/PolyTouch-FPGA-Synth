## Flash 与冷启动

先重新编译并通过九项 RTL 门禁，再写入昨天发布的原始位流。普通操作9仍出现 `SPI Verify failed`，其退出码0不能算通过；改用操作37 GAO-Bridge，明确报告 `Program and Verify flash successfully.`，退出码0且无Error。Flash重载、延后读码为 `0x5633/0x6020`，D0/N69/O69/D1/M1全部返回OK。用户彻底断电重启后回复“正常”，重新只读确认仍为 `0x5633/0x6020`。详细日志见 [Flash记录](../logs/FPGA_DEBUG_LOG_20261014_V1_FLASH.md)。

首次重载后立即读取曾尚未Done，需等待配置就绪。冷启动后的串口因演奏窗口占用而未重复检查，保留窗口供用户使用；前述串口通过记录来自Flash重载后。Flash的新程序已经持久化，断电不会恢复旧版。

## S1 结果

使用 Icarus Verilog 12.0 (devel) 和 Windows PowerShell 5.1，真实27MHz时钟、每576时钟一个采样，Fs=46875Hz。测试通过UART引脚发送实际命令；接收端独立从PT8211 BCK/WS/DIN解码，不强制sample_tick，也不用发送器位计数器解码。对每帧同时检查声部音符、gate/idle、左右声道和保存的内部稳定样本。完整十项RTL门禁退出0，音频分析退出0。

| 验收项 | 结果 |
| --- | --- |
| 数量与格式 | 58880个完整立体声帧，各声道16位有符号；每段PCM/WAV格式、帧数及帧序正确 |
| 时序 | BCK周期18个系统时钟；每声道16个BCK；每帧576个系统时钟；sample_tick单周期；数据/WS在BCK低相位改变，无X |
| A4音高 | 32768点稳态，约439.9999747Hz，误差约0.0000253Hz，满足≤1Hz |
| 四音 | C4/D#4/F#4/A4同时存在，四个声部音符和gate独立；四基频拟合幅度约8933–8943 LSB |
| 逐个松键 | 松开60、63、66后，对应基频拟合残留均小于0.023 LSB，保留音持续存在；释放声部归idle |
| 全部释放 | 保存的512帧左右均严格为0；A4释音段保留尾音并在末512帧归零 |
| M0/M1 | 四音gate仍保持时M0的512帧严格为0，M1后四音恢复 |
| 分析器反例 | 错采样率、损坏声道、A4偏移3Hz、缺声部、忽略松键、静音非零、缺帧、瞬间截断尾音，八例全部被拒绝 |

A4的原始FFT频点间隔为1.430511Hz；先用Hann窗FFT寻找主峰，再直接对原始时域采样做正弦/余弦/DC最小二乘残差细化。这个数字是理想RTL采样模型的频率估计，不是实物晶振精度。四音窗口各4096点，基频同时拟合避免把泄漏当作松键残留；频谱图已视觉复核。

四音和恢复四音的4096帧各有11个样本触及满幅，现有除以二的混音仍有削波。该问题保留到清单S6处理，本次没有修改增益或宣称音频无失真。模拟静音底噪、供电、外置DAC及完整物理响应仍需实机验收。
