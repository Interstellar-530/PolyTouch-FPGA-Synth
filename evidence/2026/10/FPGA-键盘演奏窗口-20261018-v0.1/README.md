# 键盘演奏窗口扩展与板载 A/B

日期：2026-10-18。代码基线为 `ff2c7d6`，生产 RTL 未改动。电脑演奏窗口新增双排键位、八度移调、F1–F4 音色快捷切换与四音测试。

## 界面行为

低排 `Z S X D C V G B H N J M` 对应 C3–B3，高排 `Q 2 W 3 E R 5 T 6 Y 7 U` 对应 C4–B4。`PageUp/PageDown` 每次移调十二个半音，基准音限制在 MIDI 36–84。A、F、K 保留为 C4、F4、C5 别名。F1–F4 选择音色 0、64、160、255；四音测试发送 `N60/N64/N67/N72`，2.6 秒后全松键。

## 验证

`keyboard.ps1 -SelfTest` 通过按下/松开、自动重复、和弦、Panic、双排映射、八度边界、四音测试命令和 F1–F4 映射检查。C# 界面使用 Windows PowerShell 5.1 与 WinForms 编译通过，离屏渲染见 `keyboard-window.png`。

板载加载使用 `docs/evidence/FPGA-板载联调-20261018-v0.1/board_only.fs`。位流 SHA256 为 `F43E2B32A36853256026F024ED5B49DD8BA47D5FEE0E29FA188BA8085D84E9A8`，45 个生产源文件哈希与当前工作区一致。JTAG SRAM 烧录成功，读回 User Code `0x264C`。COM13 实测 `D0/M1/T0/T255/T0/X` 均返回 OK，演奏窗口已连接。

## 边界

用户明确要求跳过剩余耗时门禁，因此本轮没有完成全量仿真门禁；烧录前只使用了已完成的板载专用自检、生产源文件哈希绑定和此前运行到真实四音捕获阶段的门禁记录。Flash 未改写，断电会恢复旧程序。

最新四音捕获中四个基波均存在，峰值没有削波；旧 `0x5633` 捕获中四音峰值达到 32767。实物听感仍待用户确认。若四声部数量仍不足，后续单独实施 8 声部，不把当前四声部窗口声称为 8 声部。
