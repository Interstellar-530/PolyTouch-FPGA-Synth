# 模块间信息传递

## 1. 模块目标

定义输入层、事件层、声部分配器、合成引擎、混音器和输出接口之间的数据格式、握手方式、时序关系和调试接口。最低实现只使用 12.288 MHz 单时钟域，所有音频数据在 48 kHz `sample_tick` 上推进。

## 2. 算法逻辑

控制事件使用同步 `valid/ready` 握手，音频样本使用 `sample_tick` 作为全局节拍。建议定义四个结构：`note_event_t` 包含 `valid`、`type`（NOTE_ON/NOTE_OFF）、`note_id[6:0]`、`velocity[11:0]`、`timbre[1:0]`；`voice_ctrl_t` 包含 `voice_sel[2:0]`、`gate`、`note_id`、`phase_inc[31:0]`、`vel_gain[15:0]`；`voice_sample_t` 包含 `valid`、`sample[15:0]`、`active`；`status_t` 包含 `init_done`、`touch_ok`、`adc_ok`、`clip_count`、`active_voices`、`test_mode`。

声部分配器在收到 NOTE_ON 时按“空闲声部 → 已进入 RELEASE 且幅度最低 → 最老声部”的顺序选择；NOTE_OFF 只把对应声部切入 RELEASE，不立即清零，避免爆音。事件如果不在 `sample_tick` 上到达，就先锁存到事件寄存器，在下一个采样 tick 生效，最坏只增加一个采样周期 20.8 µs 的延迟。混音器在 4 个声部都更新完后，用一个固定流水线把 4 路样本相加、归一化、饱和，并在下一个 `sample_tick` 前把 `audio_l/audio_r` 装入 I2S 发送器。

所有内部逻辑都在 12.288 MHz 下工作，因此模块之间不需要跨时钟域 FIFO。只有 MPR121 的 IRQ、MCP3208 的 MISO、UART RX 等真正异步输入需要两级触发器同步。I2C 和 SPI 的时序全部由 FPGA 状态机产生，FPGA 在同步域内采样。

## 3. 例程参考

Sipeed `UART/UART_HELLO` 提供最小 UART 发送/接收参考；`PT8211/src/top.v` 中的 `req` 和逐样本接口可以作为音频数据请求握手参考；`Lite-bottom_test_project` 中的板上按键和 LED 例程可以参考状态指示习惯。高云 SUG935 说明 CST 约束，SUG940 说明时序约束，SUG949 说明同步器和 HDL 风格。`valid/ready` 是一种通用同步握手模式，不要求引入完整 AXI 总线；最低实现只需要一个 1 位 valid 和 1 位 ready。

## 4. 函数解释

建议实现 `sync2()` 两级同步器、`edge_det()` 边沿检测、`pack_event()` 把触摸位图和 ADC 值打包成 `note_event_t`、`voice_alloc()` 选择声部、`mix_valid()` 合并各声部 `valid`、`uart_status()` 生成调试字符串。事件 FIFO 在最低实现中可以省略，因为 MPR121 最多 12 键、48 kHz 采样 tick 足够快；但建议保留一个 16 项分布式 RAM 或 1 块 BSRAM 的 16 项 FIFO 作为后续优化，避免快速连击丢失事件。UART 采用 115200 波特率，只输出状态，不参与音频。

## 5. 后续优化方向

后续可以增加纯 RTL 的 UART 命令解析器，用 `T1`、`V80`、`A10`、`D12`、`S70`、`R25`、`OCT+`、`TEST4` 等 ASCII 命令在线修改音色、总音量和包络参数；可以增加 31250 波特率 MIDI 输入，把 MIDI Note On/Off 与触摸事件合并；可以增加 16～32 项事件 FIFO 和时间戳计数器，用于测量触摸 IRQ 到 I2S 首个非零样本的端到端延迟。若后续加入 SPI LCD 或蓝牙模块，应把它们放在独立状态机或独立时钟域，不能阻塞音频总线的 `sample_tick`。软核 CPU 只能用于界面和参数管理，不能进入 DDS、ADSR、混音和 I2S 路径。

## 6. 最小验收

用逻辑分析仪同时观察 MPR121 IRQ、`note_event_t.valid`、`sample_tick` 和 I2S DIN，确认事件在下一个采样 tick 生效；连续快速按 12 个键不丢事件；NOTE_OFF 后声部进入 RELEASE 而不是硬切；UART 能输出 `init_done/touch_ok/adc_ok/active_voices/clip_count`；断开传感器后测试模式仍能正常发声。

## 7. 测试与延迟测量

最低实现至少建立 6 个 testbench：`tb_phase_inc` 验证 A4 频率字；`tb_adsr` 验证四段包络的饱和和状态转换；`tb_voice_alloc` 验证空闲、释放中最弱和最老偷取；`tb_mixer` 用最大正负样本验证 4 路相加不溢出；`tb_i2s` 验证 LRCK 边沿后延迟一个 BCK 的 24 位标准 I2S 时序；`tb_i2c_mpr121` 验证初始化寄存器序列和触摸寄存器读回。硬件测量时用逻辑分析仪同时抓 MPR121 IRQ 和 I2S DIN：以 IRQ 下降沿为起点，以第一个非零 I2S 数据位为终点，记录 20 次演奏的最差值和平均值，写入验收报告。
