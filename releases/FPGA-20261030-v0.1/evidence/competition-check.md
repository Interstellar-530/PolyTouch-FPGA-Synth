# 官方条款与本次优化对应

官方来源：[高云 2026 竞赛选题二](https://www.gowinsemi.com.cn/university/match2026)。2026-10-30 直接访问核对；以下是条款摘要及项目对应，不是赛事合规认证。

| 条款 | 本次实现或图示 | 验收边界 |
|---|---|---|
| 至少 2 个独立演奏维度，交互灵敏稳定 | 键盘选音、FSR 延音、旋钮弯音；中值/回差/2与6点确认；IdleOnly 保持延音 | 需实物证明独立性、稳定性；当前 FSR 不是连续力度控制 |
| 完整音频通路由 HDL 逐样本生成 | 压力判定与演奏事件都由硬件处理，共用声部调度与合成流水线 | 本轮没有改变音频架构，也没有引入软件音频生成 |
| 基础控制到音频输出总延迟 ≤10 ms；拓展 ≤5 ms | 新增踏板状态小于5ms自检、真实顶层松开截止断言 | 状态更新时间、I2S 采样帧和整机模拟声音延迟必须区分；不得将本轮局部结果当作整机两项指标已达标 |
| 至少 4 个独立声部，变调、ADSR、混音 | 图示当前 32 声部 RAM 状态与共享合成流水线，松开事件进入 Release | 需现场不同频率谱峰、实际位流及代码佐证；曲目音符峰值不能证明32复音 |
| 禁止预录PCM、推流和整段录音触发 | 图示演示曲保存 Note On/Off、力度、等待和循环，单周期波表单独存储 | 运行时声音仍由 FPGA 合成；不把演示曲的自动弹奏当作自主交互展示 |
| 拓展多维表情、音色与效果、视听反馈 | 如实标注延音、弯音、音色及显示 | 不把ADSR当混响，不把音符统计当FFT，不虚构未实现加分项 |

稳定性取舍明确写入图稿：本版须小于5ms响应真实松开，所以持续5ms低值会被判为松开；对2ms短掉压提供仿真覆盖。逻辑稳定性测试不能替代传感器接触、供电、连续轻压和实物声音验收。
