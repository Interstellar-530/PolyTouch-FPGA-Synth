# PolyTouch 电脑演奏窗口

关闭 PuTTY 等占用 COM13 的串口工具，双击 `open-keyboard.cmd`。窗口自动连接 COM13、115200 8N1，进入手动模式并解除数字静音。默认音域为 C3–B4：低排 `Z S X D C V G B H N J M` 对应 C3–B3，高排 `Q 2 W 3 E R 5 T 6 Y 7 U` 对应 C4–B4；`PageUp/PageDown` 每次升降一个八度，MIDI 基准音限制在 36–84。A、F、K 保留为 C4、F4、C5 的快捷别名。

按钮可切换手动/演示、全松键和静音。空格也会全松键；手动时失去焦点会全松键，关闭窗口会等待 X 应答再释放端口。全松键后仍按住的键被抑制，要松开后重新按下。演示模式中按新的音符键会先切回手动。输入设备的多键识别能力取决于电脑键盘，部分键组合可能受键盘自身限制。

**显示切换**：按 **F7** 在“电脑仪表盘”和“外接 HDMI 仪表盘”之间切换。电脑端通过新增的 `Q` 命令每 100 ms 请求一次 FPGA 状态快照，绘制活跃声部、音符、波形、频带活动和相位图；切到电脑端时发送 `R0`，FPGA 保持 HDMI 时序但输出黑场；切回外接屏幕发送 `R1`。窗口退出、串口工作线程异常结束时会尽力发送 `R1`，避免电脑端关闭后 HDMI 长时间保持黑场。旧位流不认识 `Q/R` 时窗口会记录错误，重新连接或烧录兼容位流即可回退。

D0 本身只是进入等待音符的手动状态；这个窗口将真实按下/松开转换成既有 N/O ASCII 命令。固件必须支持 D0/D1，模式修复版 User Code 为 0x5633；旧 Flash 0xFCF0 在断电后加载，需重新加载模式修复版到 SRAM。GUI 下方显示设备的 OK/错误应答，运行记录保存到 `output/serial_keyboard/`。

运行环境是 Windows PowerShell 5.1 与系统 .NET Framework，使用 WinForms 和 SerialPort，无需 Python或新增第三方运行库。本轮实现是本项目电脑端代码；资料调研中的其他合成器只作交互思路参考，没有复制其源码。音频依然完全由 FPGA 实时生成，电脑端只解码状态快照并绘制仪表盘，不参与合成/播放音频。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\serial_keyboard\keyboard.ps1 -SelfTest
# 关闭串口窗口后才运行实机检查：
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\serial_keyboard\keyboard.ps1 -SmokeTest -Port COM13
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\tools\serial_keyboard\keyboard.ps1 -Port COM13
```

自检覆盖按下/松开、自动重复、和弦、原始音高的松键、双排键位、八度边界、四音测试命令、F1–F5 钢琴硬度映射以及 Panic 清除积压事件。实机检查验证 D0/M1、三音和弦 N/O 和关闭时 X 的全部 OK 应答。电脑输入到模拟声音的实际延迟尚未测量。完整硬件连接方案见 `docs/hardware/FPGA-硬件连接与演奏操作-20261013-v0.1.md`。

**音色切换**：窗口“音色：钢琴/吉他”按钮或 **F6** 发送 `I0`（钢琴，并补发当前 T250–T254）或 `I1`（8 声部 Clean 吉他）。统一 `debug8` 位流同时包含钢琴与吉他表，切换拍清空当前声部/事件，避免持音中途换表；切换后需重新按键起音。

五档钢琴硬度按钮与滑条对应串口 T250～T254，`F1/F2/F3/F4/F5` 分别选择柔和琴体、温暖、标准、明亮和强击弦。钢琴模式使用六个连续频谱表槽和独立击弦包络，随包络衰减从击弦层回到琴体层；切换硬度不切演奏模式、不松键，也不重触发已有包络。滑条每 40 ms 至多提交一次最新目标，发送队列再合并未发送的硬度请求，并优先发送音符。电脑显示的是主机目标，不回读板上 S1 的当前值；连接不会自动覆盖板上音色。旧固件需要先更新才能使用 T 命令。

“四音测试”会绕开电脑键盘的无冲限制，先发送 `D0/M1`，再依次发 `N60/N64/N67/N72`，2.6 秒后自动发送全松键。若这个按钮能听到四音和弦、直接按多个电脑键却不能，应检查键盘无冲能力；若两者都只听到一个音，再检查 FPGA 位流和串口队列。当前 `debug8` 是八声部；旧 `debug` 档仍为四声部。超过所选固件的声部数才触发窃声，不能用电脑键盘识别的按键数推断 FPGA 上限。

板载 S1 短按松开切伴奏，长按切下一档音色，持续按住不连发。长按计时从 20 ms 消抖成立后开始，门限为 600 ms。切换后一秒内，两颗速度 LED 暂时显示音色编号 00/01/10/11，然后恢复速度。S2 保持速度功能；S3 保留所选音色。现有 USB 线和板载按键即可操作，无新增硬件。

离屏布局复现可用 Windows PowerShell 5.1 执行 render_preview.ps1 -OutputPath '<完整PNG路径>'，不会连接串口。音色自检和资源报告见 docs/evidence/FPGA-音色控制-20261016-v0.1。


**音量**：**↑/↓** 每步 5%，发送 `V0`–`V100`；100 为原始电平，50 约 −12 dB，0 静音。状态栏显示当前百分比。
