## 现有测试边界与新自检要求

tb_mode_uart 使用 `force dut.sample_tick = 1'b1` 加快状态机，它证明模式和事件处理，不证明真实采样 PCM、频谱或数字延迟。新增 S1 必须使用实际时钟和单周期采样使能，不能把这个加速测试输出当音频证据。优先解码序列化输出得到实际发送的数字样本，另对照内部稳定样本寄存器，以覆盖输出路径。

现有 tb_pt8211_tx 只生成 VCD 后 finish，无自检断言，仍只作 GTKWave 环境展示。S1 新增 tb_audio_capture 以真实时钟运行，独立解码 PT8211 引脚，明确断言 sample_tick 高电平一周期、每帧 576 时钟、每声道 16 位及左右/内部稳定样本一致，已作为第十台加入门禁。tb_tick_rate 的真实频率为 27,000,000/576=46,875 Hz，v1.0.0 已修正旧打印公式。新增功能台继续使用超时保护和 `$fatal(1,...)`，本次捕获为确定性命令序列，不使用随机种子。

四音频谱建议用 C4、D#4、F#4、A4 等可区分组合，同时核对独立声部状态和逐个 Note Off 的衰减。C4 与 C5 的基频/谐波可能重叠，四峰图不能单独证明四个独立声部。频率误差验收须记录样本长度、FFT 分辨率和估计方法；短记录的粗频谱不足以支持 1 Hz 精度判断。Python 只用于参考/离线分析，FPGA 实际音频不由 Python 或 CPU 生成。

## 算法实现的边界

压力滤波先评估三点中值和 IIR `y += (x-y) >> 1`，用 2 kHz 控制采样模型测阶跃/尖峰响应、定点取整、边界和初始化，再选择参数。这里是 Python 参考写法；HDL 对有符号差值使用算术右移 `>>>`，保持符号扩展，不让负差值当无符号右移。FSR 是相对表情，不按牛顿精度验收；ADC 读到零或满量程不能单独证明断线。

初始 SPI 可按约 250 kHz、每通道 1-2 kHz 调度，低速事务跨音频帧独立运行；48 kHz 合成只读取已提交控制值。正式时钟迁移同步改 UART CLK_HZ、DDS 频率字、曲目样本数和 ADSR 的时间换算；保留 27 MHz 调试目标时也应明确各自参数，不能混用频率 ROM。

先生成正弦和限制谐波的亮音色单周期表，当前 C4-C5 可从最多 16 次谐波起步；扩展音域时重新核对 Nyquist。离线生成 hex 并校验长度/有符号范围/峰值/校验值；运行硬件用 Gowin BSRAM IP/原语。抽象同步 ROM 可以先验证算法，未接厂商模型时标记“厂商原语验证未完成”，异步数组不能代替真实 BSRAM 延迟验证。单周期函数表是实时合成数据，不存整曲/预录 PCM。

现有 mixer 四路求和后除以二仍可能削波。S6 测试最大同相/反相输入、最小负数、增益边界及饱和反馈；定义 clip 计数的统计点，旁路 FIR 时保留明确帧延迟。FIR 高频衰减、插值误差与模拟静音底噪是不同问题，不能用增加 DSP 算法宣称已解决电源/模拟链路噪声。

## 靠后进行的共享引擎与效果

基础数字链和四声部回归通过后，才安排八/三十二声部共享调度和短延迟。现声部约三只 18×18 乘法器：直接复制八路已达 24 只保守预算，32 路需 96 只，超过器件物理 48 只。46 块 BSRAM、24 只保守乘法器和每帧 256 周期必须同时满足，宏 DSP 与乘法器实例另记。

先用周期模型验证独立相位/包络上下文的保存恢复、同步 ROM/DSP valid、最坏帧截止，再上共享 RTL。四流水线×八上下文、每声部 16 周期，加控制/混音预留约 208/256 是已有预算，不是结果；波表先按八块保守预算，再计状态、频率表与效果缓存。扩声部/效果超过窗口就回退四声部，不挤占 10/29-11/04 材料周。暂不展开 FPGA FFT 显示、复杂混响、蓝牙/App 和另一套 MPR121 主键盘。

## 可复用来源与远程交付

可借鉴 [nishadsuresh/fpga-verilog-synth](https://github.com/nishadsuresh/fpga-verilog-synth) 的串行输入→RTL 样本→PCM/WAV/FFT 组织方式。该仓库的实时顶层与独立四声部混音测试范围不同，不能直接当本机四声部板卡固件。当前为 MIT，依赖 Icarus/GTKWave 和 Python 数值库；若复制源码，固定提交并保留许可。这里只规划验证思路，没有导入代码。

[XLS32](https://github.com/kazunori279/xls32-fpga-synth) 的状态/运算分离和握手可参考，其 Apache-2.0 许可和板级外壳需逐项适配；原 Basys 配置约 768 周期/帧不符合本项目 256 周期。SPI 模型依据 [Microchip MCP3208](https://www.microchip.com/en-us/product/MCP3208)，I2S 接收模型依据 [TI PCM5102A](https://www.ti.com/product/PCM5102A)。外部项目作为参考，不重复部署整套不匹配工具链。

每个数字交付包包含提交 ID、RTL/测试、固定随机种子、全部门禁日志、模型说明、ROM 校验值、构建/复现命令和限制。队友没有 Gowin 时先交 RTL 自检与算法数据；本机具备工具后由用户统一综合/PnR。用户拿到外设后测原始波形和供电/负载，队友据此分析。
