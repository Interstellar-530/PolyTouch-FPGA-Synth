# 硬件调试说明书

## 1. 适用范围与验收目标

本说明书用于 Tang Primer 20K Dock 3714 上最低实现版本的硬件调试，目标是把 4 声部、12 路触摸、1 路 FSR、两种音色、标准 I2S 输出和 48 kHz 实时合成链路逐步调通。调试顺序固定为：板卡与电压、时钟、FPGA 下载、板载 PT8211、外接 PCM5102A、MPR121、MCP3208/FSR、单声部 DDS/ADSR、4 声部混音、延迟实测、长时间稳定性。

| 验收项 | 通过标准 |
| --- | --- |
| 复音数 | 至少 4 个独立声部同时发声，频谱出现 4 个独立基频峰 |
| 演奏维度 | 触摸键可稳定选音/触发，FSR 可连续改变力度或表情 |
| 音高 | A4 实测 440 Hz ±1 Hz，单音实时变调正常 |
| ADSR | 起音、衰减、保持、释音四段可听且无爆音 |
| 延迟 | 触摸 IRQ 到 I2S 首个非零样本，目标 <5 ms，最坏 <10 ms |
| 输出 | 标准 I2S 到 PCM5102A 能正常发声；PT8211 仅作调试 |
| 合规 | ROM 只存单周期数学波形，无预录 PCM、无整段录音、无 MCU 参与音频 |
| 稳定性 | 连续快速演奏 10 分钟无卡死、挂音、随机重启 |
| 资源 | 最低实现 BSRAM ≤6 块，DSP ≤5 个，LUT/FF 余量充足 |
| 构建 | 固定 Tcl 构建能生成 `GW2A-LV18PG256C8/I7`、版本 C 的 `.fs` |

## 2. 仪器与安全

需要数字万用表、示波器或至少 24 MHz USB 逻辑分析仪、有源音箱/有源功放、3.3 V 外部 12.288 MHz 有源晶振、PMOD 转接板或焊接排针。严禁把 5 V 信号直接接 FPGA I/O；先确认 PMOD Bank 是 3.3 V。DDR3 Bank 通常是 1.5 V，不能直接接 MPR121、MCP3208 或 PCM5102A 的 3.3 V 信号。所有外设必须与 FPGA 共地，插拔前先断电。

## 3. 上电前的静态检查

1. 确认 Dock 版本丝印为 3714，核心板方向正确，Dock 1 号拨码处于使能核心板的位置。
2. 用万用表通断档检查 3.3 V 与 GND、5 V 与 GND 没有短路；检查 PMOD 的 3.3 V/GND 脚与原理图一致。
3. 检查 MPR121、MCP3208、PCM5102A 和 12.288 MHz 晶振的供电脚，确认没有 5 V 进入 3.3 V 器件。
4. 检查 I2C 上拉：MPR121 模块如果已经带 4.7 kΩ 上拉，不要再在 PMOD 上重复加上拉；如果没有，则在 SCL/SDA 到 3.3 V 各加 4.7 kΩ。
5. 检查 I2S 线序：PCM5102A 的 BCK、LRCK、DIN、GND 与 FPGA 一一对应；PT8211 的 `N15/P16/P15/R16` 与板载音频网络对应。

## 4. 分步调试流程

### 4.1 电源与下载

先只接 USB-JTAG，不接外设，确认板卡电源灯和核心板使能状态正常。打开 Gowin Programmer，选择 `GW2A-LV18PG256C8/I7`，下载最小 LED 工程，确认下载器、器件识别和 LED 翻转正常。UART 以 115200 波特率输出 `init_done=0`，下载本项目最小工程后变为 `init_done=1`。

### 4.2 时钟检查

用示波器依次测量 12.288 MHz 输入、3.072 MHz I2S BCK、48 kHz LRCK、48 kHz `sample_tick`。如果 12.288 MHz 没有波形，检查 GCLK 脚选择、晶振供电、串联电阻和焊接；如果 BCK/LRCK 不对，检查 256 计数器和分频逻辑。若 3714 PMOD 没有空闲 GCLK 脚，先不要接 PCM5102A，改用板载 27 MHz 加 PT8211 验证 DDS 和 ADSR，直到解决 12.288 MHz 输入。

### 4.3 板载 PT8211 调试

加载测试模式，先让 FPGA 产生 440 Hz 单音。示波器观察 `HP_BCK=N15`、`HP_WS=P16`、`HP_DIN=P15`，确认 BCK 约 1.536 MHz、WS 约 48 kHz、数据右对齐 16 位。上电时 `PA_EN=R16` 应先低后高，避免爆音。耳机口能听到稳定正弦后，说明 DDS、波表和 DAC 驱动链路基本正常。

### 4.4 PCM5102A 标准 I2S 调试

确认模块 FMT 跳线选择标准 I2S，FLT 可选低延迟滤波，XSMT 先静音后释放，DEMP 在 48 kHz 下按模块默认关闭。测量 BCK=3.072 MHz、LRCK=48 kHz、DIN 有 24 位数据。若没有声音，先检查模块供电和 I2S 线序，再检查 LRCK 与 BCK 的相位关系、24 位槽格式和静音脚。PCM5102A 输出接有源音箱，不直接接无源扬声器。

### 4.5 MPR121 触摸调试

先只接 MPR121，UART 输出 `touch_ok=0` 时检查 I2C 地址、上拉和供电。确认能读到设备后，依次触摸 12 个电极，UART 输出 12 位触摸位图。阈值必须在最终面板装好后重新校准；如果出现串键，缩短电极线、增大电极间距、调整阈值和去抖次数。目标是单键触摸稳定、无明显串键、按下和松开事件都能被捕获。

### 4.6 MCP3208 与 FSR 调试

把 FSR 分压接到 MCP3208 通道 0，VREF 和 VDD 接 3.3 V。UART 输出 12 位原始值和滤波值；按压 FSR，观察数值单调变化。若数值跳变，增加 RC 滤波和 4 点中值/IIR 平滑；若始终为 0 或满量程，检查通道选择、SPI 模式、CS 和模拟地。校准只要求相对力度稳定，不追求绝对牛顿值。

### 4.7 单声部 DDS 与 ADSR

测试模式先产生单声部正弦，验证 A4=440 Hz、八度切换和音高微调。然后打开 ADSR，用 UART 或按键切换 Attack、Decay、Sustain、Release，示波器观察包络或听感确认没有爆音。若出现爆音，检查包络复位、NOTE_ON 初始相位和释音结束后的静音处理。

### 4.8 4 声部混音与频谱

同时触发 4 个固定频率声部，用音频频谱软件或逻辑分析仪采集 I2S 数据，确认出现 4 个独立基频峰。检查混音是否出现回绕、直流偏置或削波；最大满幅时应有饱和而不是回绕。确认 NOTE_OFF 进入 RELEASE，不出现挂音；重复按同一个音时不会产生双重声部泄漏。

### 4.9 端到端延迟实测

用逻辑分析仪同时抓 MPR121 IRQ 下降沿和 I2S DIN 第一个非零数据位。以 IRQ 为起点，记录 20 次演奏的平均值和最坏值。当前预算为 MPR121 扫描和去抖 2～4 ms、I2C 读取小于 0.5 ms、等待采样 tick 小于 0.021 ms、DDS/ADSR/混音小于 0.01 ms、PCM5102A 滤波约 0.073～0.42 ms，合计约 3～5 ms。若超过 10 ms，优先缩短 MPR121 采样间隔和去抖，再检查 I2C 读取状态机是否阻塞。

### 4.10 长时间与异常测试

连续快速演奏 10 分钟，记录温度、电流、UART `clip_count`、活跃声部和重启次数。测试突然拔掉 MPR121、MCP3208 或 FSR 后，系统应保持音频输出并进入测试模式；重新插上后能重新初始化。反复断电重启 20 次，确认每次都能进入 `init_done`。

## 5. 常见故障与处理

| 现象 | 优先检查 |
| --- | --- |
| 完全没有声音 | 12.288 MHz 是否存在、PA_EN/XSMT 是否释放、BCK/LRCK 是否正确 |
| 只有板载耳机有声，PCM5102A 无声 | I2S 线序、FMT 跳线、DAC 供电、BCK/LRCK 相位 |
| 声音抖动或噪声 | 时钟源质量、共地、I2S 串联电阻、电源去耦、采样率误差 |
| I2C 无应答 | 地址、上拉、供电、SCL/SDA 线序、MPR121 复位 |
| 触摸串键 | 电极间距、阈值、去抖、电极线长度、地平面 |
| 压力跳变 | FSR 分压、RC 滤波、MCP3208 参考电压、IIR 参数 |
| 挂音 | NOTE_OFF 事件、声部分配器 RELEASE、偷音逻辑 |
| 削波/爆音 | 混音位宽、归一化移位、饱和函数、包络复位 |
| 下载失败 | 拨码使能、USB 线、Gowin Programmer 器件选择、驱动 |

## 6. 算法逻辑与调试函数

调试固件保留 `test_mode`、`single_voice`、`four_voice`、`sine_sweep`、`touch_map`、`adc_raw` 和 `latency_marker` 七种模式。`clk_ce()` 用于产生 48 kHz 采样使能，`note_phase_inc()` 用于验证音高，`env_next()` 用于验证 ADSR，`mix_add()` 和 `sat16()` 用于验证混音不溢出，`iir_update()` 用于压力平滑，`voice_alloc()` 用于验证声部分配。UART 状态串固定包含 `init_done`、`touch_ok`、`adc_ok`、`active_voices`、`clip_count`、`test_mode`，方便自动化判断。

## 8. 后续优化方向

基础验收通过后，先把 `VOICE_COUNT` 从 4 改到 8，确认 BSRAM 从 4 块增到 8 块、DSP 从 5 个增到 9 个；再把 8 声部改成 4 个共享 BSRAM bank 的 32 声部 TDM，目标是波表只占 4 块、幅度运算只用 4～8 个 DSP。之后可以加共享延迟/合唱、双操作 FM、MIDI 输入、Lissajous/简单波形显示和更精细的触摸阈值。逐声部滤波、逐声部插值、逐声部混响和并行 FFT 在 32 声部配置下不作为优化路线，除非显著降低声部数或引入 DDR3 控制器。
