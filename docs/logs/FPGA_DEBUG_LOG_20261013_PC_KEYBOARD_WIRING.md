# 2026-10-13 电脑手动演奏、接线方案与资料复核

用户反馈 D0 只停止演示。核对 top.v 后确认，D0 已进入手动等待状态，但 PuTTY 没有电脑琴键映射；用户进一步选择“按住电脑键发音、松开发送松键”。本轮新增 Windows 电脑演奏窗口，使用既有 N/O/X/D/M ASCII 协议控制 COM13，音频仍由 FPGA 合成。

客户端包含按下/松开、重复抑制、和弦、模式按钮、串口 OK 检查、积压事件清除和关闭时 X。复查并修正了两个电脑端问题：全松键后仍按住的键不应被自动重复重新触发；新窗口默认焦点不能留在串口选择框。最终源码自检、真实串口和窗口按键事件验证均通过，用户确认“按下、松开和和弦都正常”。失去焦点日志也记录 X -> OK。当前窗口保留打开且处于手动等待状态。

用户指出外设清单过期，要求检查其他对话。内置对话列表工具报 Invalid app tool request 后，只读检索本机 FPGA 项目对话记录。采购核对消息确认 P01、P03、P05～P10、P16～P17 已购；最新《检查能否同时用它取代MPR121》里已选择 12 个独立 GPIO 机械按键，MPR121 作为备选。没有据此宣称器件已到货或已调通。

本轮连接提案覆盖 12 键、ADC、FSR、电位器、PCM5102A、耳放、12.288 MHz 晶振和录音。3714 图纸与核心板电压图先用 Markdown 阅读，再渲染 PNG 核对；器件手册同样转换并视觉确认引脚。21 个拟定信号/排针均唯一，与当前 CST 无冲突。此前 N9 候选具有 D0 复用标注，方案将该琴键改为 J14-5/P9；原型使用的排针 1/2 是 3.3 V、3/4 是地，已在文档突出说明。方案只完成图纸级复核，未改 FPGA 生产约束或外设 RTL。

论文和开源复核包含 POWERWAVE、抗混叠振荡器综述、xls32、nishadsuresh 合成器、电脑串口合成器、I2C 和 Sipeed 示例。已指出 xls32 原配置帧周期不能直接适用本板时钟，nishadsuresh 顶层实时 MIDI 实际为单音，以及 MIT/Apache 与未确认许可的取用差异。本轮没有引入外部源代码；完整出处、适配模块与资源预算分别写入硬件和研究文档。

本轮没有修改 Verilog 或烧录 Flash。模式修复固件仍为之前加载的 SRAM 版，断电会回到 Flash 0xFCF0；该版本没有 D0/D1。本轮新增的只是电脑控制端和文档，GPIO/ADC/标准 I2S 外设驱动仍待实现。关键源文件、接线文档、参考资料与验证证据归档至 `archive/FPGA-20261013-v0.2/`；临时历史检索脚本和一次性渲染目录在保存证据后清理，运行时日志保留在 output/serial_keyboard 并加入 Git 忽略。
