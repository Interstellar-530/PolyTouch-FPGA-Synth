# 8 声部扩展与混音处理

日期：2026-10-19，版本 v0.1。对应方案 P2 的“先 8 声部”阶段。

## 1. 8 声部实现

| 项目 | 改动 |
|---|---|
| 顶层 | `top` 新增 `VOICES` 参数；标准 27 MHz 档设为 **8**，旧 debug/standard 档仍为 4 |
| 声部分配 | `voice_alloc #(.VOICES(VOICES))`，年龄位宽随 VOICES 自动取 `$clog2` |
| 每声部 | `note_phase_inc`、`voice_transition` 用 generate 循环实例化，避免复制 4 份代码 |
| 共享引擎 | 新增 `VOICES8`；相位/包络/力度/重触发扩展为 8 路，FSM 轮询 8 个声部 |
| 帧预算 | 8 声部 × 27 拍 = **216 拍/帧**，46.875 kHz 档每帧 576 拍，余量 360 拍；48 kHz 档 512 拍也够 |
| 存储/乘法器 | 仍是一套 72 表钢琴 ROM + 通用明亮表 + 正弦表；**BSRAM 40/46、MULT18X18 1 不变** |

`VOICES=4` 时引擎只轮询 4 个声部，旧档行为和旧测试保持不变；`VOICES=8` 时 `VOICES8=1`。

## 2. 混音与音质处理

### 2.1 余量

8 声部满幅叠加的理论峰值是 4 声部的 2 倍。`MASTER_VOLUME_SHIFT` 从 2（÷4）改为 **3（÷8）**，保持单声部满幅时输出仍为 16/24 位满幅的 1/8，8 声部满幅时正好到满幅，不会因为新增声部就先削波。

### 2.2 软限幅

`global_crossfade` 新增 `SOFT_LIMIT_ENABLE`（8 声部档启用）：

- 24 位满幅 8 388 608，拐点 **0.75 FS = 6 291 456**；
- 超过拐点按 **4:1** 压缩：`y = knee + (|x| - knee)/4`；
- 满幅输入压到约 6 815 744，仍留 24 位量化余量，不会硬削成方波；
- 只用比较、加减、右移，不占乘法器；拐点触发计入 `clip_count`，仍可观测。

旧 4 声部档 `SOFT_LIMIT_ENABLE=0`，逐位保持原行为。

### 2.3 滤波取舍

**没有在 FPGA 里再插一级 FIR。** 库里现有的 `(1,4,6,4,1)` FIR 在 46.875 kHz 下会把 10 kHz 压到约 −8.5 dB，直接损伤钢琴亮度，之前就是因此旁路。当前链路的抗混叠由三件事保证：

1. 72 张钢琴表与 6 级通用表本身是带限频谱，最高谐波在默认键盘上限下低于 Nyquist；
2. 512 点表 + 9 位线性插值，镜像落在超声区且幅度低；
3. PCM5102A 内部的重建滤波和 3 线 PLL 时钟。

软限幅处理的是“多声部叠加的峰值”，不是频响；两者分工明确。若后续要加滤波，应先做等响度 A/B 和频谱测量，不能直接启用旧 FIR。

## 3. 音色修复（2026-10-19 追加）

用户反馈“音色不柔和、毛刺、尖锐”，定位到三处：

1. **波表谐波离群**：72 张表里 28 张的二次谐波超过基频 3 倍，最大 45.36 倍；低音区平均 16 倍。波形被二次谐波主导，听起来像高八度啸叫而不是钢琴。`gen_bandlimited_prom.py` 现在按基频归一化、把每个谐波限制在“全体中位数的 2 倍”以内，并对 6 个阶段做 3 点中值平滑。清洗后二次谐波最大 **2.49 倍**，频谱重心均值 1.63。
2. **阶段方向反了**：上一版让音色从琴体走向击弦并停在最亮表，持续段一直是最硬的表。现在起音从较亮表开始，每 8192 采样降一级，连续衰减到琴体表（F1–F3 从第 4 级起步，F4–F5 从第 5 级起步），到最终级后计时器停住，不会周期性跳回。
3. **阶段切换跳变**：旧权重最大只有 0.715，切级时从 0.715 直接跳到下一张表，每 125 ms 出现一次咔嗒。现在权重从 8191 连续降到 0，到阶段末尾正好等于下一张表，切级无跳变。

另外，第一版试听脚本把相位增量单位写错（Hz 当表索引增量），C4 实际约 24 kHz 并混叠，造成“毛刺”；修正后频谱重心从 11 kHz 降到 **1.14 kHz**，5 kHz 以上能量从 71% 降到 **0.66%**。

## 4. 指标（`standard27`，8 声部）

| 指标 | 4 声部 v0.5 | 8 声部 v0.6 |
|---|---:|---:|
| Logic | 7001 | **9869 / 20736（48%）** |
| Register | 2777 | **3380（21%）** |
| BSRAM | 40 | **40 / 46（87%）** |
| MULT18X18 | 1 | 1 |
| Fmax / 约束 | 49.407 / 27 MHz | **34.138 / 27 MHz（1.26×）** |
| Setup/Hold 违规 | 0 / 0 | **0 / 0** |

Fmax 下降是 8 路相位/包络选择、更宽总线与共用乘法器调度的直接代价。34.138 MHz 高于 27 MHz 且 Setup/Hold 违规为 0，余量 26%。若后续要拉回余量，可把 `cur_inc` 的 256 位桶形移位改成两级 4 选 1，或把 8 路求和改成流水两拍；这需要单独的时序签核。

## 5. 试听音频

用当前 72 张钢琴表按引擎的选表/插值规则渲染，6.6 s、单声道：

- 0.05–1.45 s：C4–E4–G4–C5 和弦；
- 1.55–4.0 s：C4–E4–G4–C5–E5–G5–C6 琶音；
- 4.05–5.95 s：C4–D4–E4–G4–A4–C5–E5–G5 **八音和弦**。

处理：每声部 8 ms 起音、约 0.95 s 指数衰减、100 ms 释音；起音从较亮表开始，按 8192 采样/级连续衰减到琴体表；8 路求和后 ÷8、0.75 FS 软限幅、归一化到 −1.03 dBFS。实测峰值 −1.03 dBFS、RMS −20.05 dBFS、削波样本 0、频谱重心 1.14 kHz、5 kHz 以上能量 0.66%。

文件：

- `docs/evidence/FPGA-8声部试听-20261019-v0.1/demo_8voice_48k.wav`（Windows 播放用）
- `docs/evidence/FPGA-8声部试听-20261019-v0.1/demo_8voice_46875.wav`（原始采样率）

说明：这是**软件按当前波表渲染**的试听，不是从板载 DAC 录的；第一版脚本相位单位错误导致混叠，已替换。RTL 8 声部仍以仿真和 PnR 验证为准。
