# 键控响度混音：可行性审核与资源优化版

日期：2026-10-20。审核输入为 2026-10-19 的 v0.1、v0.2 方案，以及当前本地 RTL 和已有 debug8 构建报告。本版是待实现设计，附离线数值复核；资源和音质的最终结论仍需 RTL 仿真、综合布局布线及试听。

## 审核结论

逐声部键控补偿可行。优先采用只衰减的曲线，将力度和补偿系数合并后，复用现有共享乘法器和声部幅度乘法步骤。首版不加入节目压缩、前瞻缓存、双段动态平衡，也不先实现全局最低音增益。后者会让高音随低音加入和松开一起改变电平，增加后续比较与调试工作。

最小资源目标为新增 BSRAM 0、新增 18×18 乘法器 0。推荐串行共享一份系数查询和幅度合成逻辑，每帧多做每声部一次小乘法；先用空闲时钟换掉八份并行电路和缓存。LUT4、寄存器、Fmax 必须以新综合结果为准，不能由常量表位数直接换算。

只衰减方案会让高音相对低音变轻，低音绝对电平保持现状，不能保证实现最初“低音实际增加 5 dB”的目标。每个音内部的谐波比例也基本保持不变；改善尖锐感主要来自电平降低，频谱变柔由波表和低通承担。此处的取舍应在同一回放音量下试听判断。

## 原方案需要修正的内容

| 项目 | 发现与处理 |
|---|---|
| 系数位宽 | 256=1.0 需要 9 位。v0.1 的 +5 dB 系数约 455，也需要 9 位，不能用 8 位系数 ROM。 |
| 逐声部溢出 | E=2 时声部结果为有符号 18 位，最大 131071。当前合法包络结果 131068，力度补偿到 226 后结果为 231417，截断发生在求和和限幅之前。 |

| 曲线不一致 | v0.2 公式为 C5 降 6 dB，验收却写 C5 约降 3 dB。本版统一公式、系数与验收表。 |
| 相消与峰值 | 逐声部衰减不能保证实际和弦峰值下降：0.9 与 -0.9 原本相消，第二声部减半后总和为 0.45。安全依据应是各声部绝对上界之和，不能要求限幅触发次数必然不增加。 |
| 主增益补偿 | 主音量从除以 8 改成除以 4 增加 6.02 dB。禁止把它当作只衰减方案的无风险补救。 |

| 动态处理延迟 | 包络 attack 是响应时间，不等于信号流水延迟；一阶 IIR 群延迟随频率变化，也不能简单称为固定一拍。 |

## 与当前工程绑定的证据

基准 PnR 报告为 output/handoff_milestone2_20261008/source/build/gowin_top_dbg8/runs/20261019T160656857-b589c0e8/instrument/impl/pnr/instrument.rpt.txt：Logic 10647/20736、寄存器 3309、BSRAM 40/46、MULT18X18 1、MULT9X9 1。日志记录该版本 Fmax 33.703 MHz。这些是已有构建数据，不能替代本版未来的资源报告。

现有 shared_wavetable_engine 在帧边界锁存力度、相位增量等参数，串行轮询八声部，sums_valid 后由 global_crossfade 复用同一乘法器完成交叉混合、压力与静音增益。top 已有 engine_mult_req 与 xf_mult_req 冲突断言。voice_transition 的 render_note、render_velocity 表示淡出后真正开始发声的音符，新增补偿必须跟随它们，不能跟随分配器已切换的 v_note。

当前吉他 bank 选择由 guitar_band_config 根据频段及原始力度门限 32/64/96/112 等决定，低音区另有特殊映射。必须保留原始力度，不能简单把经补偿的幅度再送回该函数。piano_bank_meta.json 仍显示历史 72 表/36 BSRAM，与当前实际 18 个钢琴 pROM 不一致；本次按原语数量与 PnR 判断容量，后续应同步生成器与 metadata，再把该项纳入发布检查。

## 首版曲线和校准方式

先采用保守曲线，未测量前不宣称符合等响曲线：

```text
d = max(note - 60, 0)
piano_db  = -min(0.25*d, 6.0)
guitar_db = -min(0.25*d, 5.0)
C = round(256 * 10^(G_db/20))
```

| 音高 | MIDI | 钢琴 | 吉他 |
|---|---:|---:|---:|
| C2–C4 | 36–60 | 0 dB | 0 dB |
| E4 | 64 | -1 dB | -1 dB |
| C5 | 72 | -3 dB | -3 dB |
| G#5 | 80 | -5 dB | -5 dB |
| C6–C7 | 84–96 | -6 dB | -5 dB |

钢琴仅 note 60..84 的 25 个系数、吉他 note 60..80 的 21 个系数需要存储，其余由边界常量返回，逻辑常量共 46×9=414 bit。也可用共享的 25 项 0..6 dB 斜坡，吉他地址限在 20，以进一步复用到 225 bit；先比较该共享查询实现与直接表的综合结果。无需实现运行时指数、对数或断点插值。它是小幅度系数表，不是替代 BSRAM 波形 ROM。

系数 C 为 9 位无符号 128..256，离线量化最大偏差约 0.02793 dB。本版默认只作用于钢琴/吉他模式，通用正弦/明亮模式保持旁路，便于诊断。最省首版使用编译期开关：关 C=256；弱 Cweak=(256+C+1)>>1；强 Cstrong=C。弱档是在**线性增益**上取中点，-6 dB 处弱档约 -2.49 dB，不能标成严格“50% dB 曲线”。

若以后要运行时旋钮或串口命令，必须定义消息兼容、参数帧锁存及平滑策略。首版避免新增命令，配置只能在编译期或全部声部静音时切换。固定曲线不会实现所有耳机、回放声压下的绝对等响；试听后可在 PC 端重新校准表值，硬件格式不变。

## 幅度合并：保留弱奏分辨率

规定输入有效力度范围 0..127，并在仿真中断言；接口虽为 8 位，不能默认 128..255 也安全。保留 vel_raw 用于选音色，另外计算：

```text
A = vel_raw * C                  // 无符号 15 位，最大 32512
sample = (enveloped_sample*A + R) >>> 15
R = 16384 if EXTRA_FRACTION_BITS>0 else 0
```

原引擎的幅度是 (enveloped_sample*vel + Rold)>>>7，Rold 为 64（E>0）或 0（E=0）。当 C=256 时，两式整数结果严格相同；已对 E=0/1/2 的完整输入样本范围和六档力度复核 2752512 组。A=0 在数学上输出仍为零，不能施加最小值 1。C=128、vel=1 时保留 1/256 的实际缩放，而整数力度方案会被迫选择静音或维持原有 1/128。

enveloped_sample 保持原有最多 18 位有符号范围，A 以显式补零作为正数送入现有 18 位乘数端口，36 位乘积足够。保留原先 E 小数位和每声部结果/累加位宽。修改乘积右移位数时同步修改舍入常量，所有中间数都明确 signed/unsigned。此次对全部 C=0..256、力度 0..127 和 E=0/1/2 的符号端点共 493440 组验证无乘积越界和声部越界；中间范围由正系数线性单调性保证。

## 调度与状态：只实例化一份控制逻辑

推荐先每帧为当前轮询声部重新计算 A，随后分别用于 sine/bright 两次已有幅度乘法。这样每帧最多增加八次小乘法和一个共享 A 寄存器，无需八套乘法器，也不必先实现起音缓存、有效标志、清空和抢占逻辑。

新增 render_note 帧快照 8×7=56 bit；A 寄存器最多 15 bit；再加少量查询结果与 FSM 状态。在 sample_tick 边界同时锁存 note、vel_raw、instrument 等实际渲染参数，后续整帧保持一致。不能从弯音后的 DDS 相位增量倒推补偿音高，否则弯音会引入电平调制。

查表、设置乘数、等待结果、锁存 A 预留每声部四拍，加入共享引擎自己的 FSM；不增加第三个抢占乘法器的控制者。在已有共享乘法器协议下，必须逐周期验证每次请求与结果对应。现路径为每声部 27 拍，预算为：

```text
1 帧启动 + 8*(27+4) + 16 帧尾保留 = 265 拍
```

27 MHz 下约 9.815 微秒，576 拍帧预算余 311 拍；对 512 拍预算余 247 拍。这里是源码路径推导与保守预留，不是新 RTL 仿真测得的延迟。帧尾 16 拍覆盖现有全局共享运算和公共滤波输出所需时间，落实时应测量并断言。优化目标是始终在下一帧前准备好样本，因此额外计算通常不需要增加完整样本帧延迟。

如果综合证明保持八份 A 缓存反而更省，则可转起音计算，但必须覆盖 render_retrigger、声部抢占、淡出、panic、音色切换和参数更新。缓存不是首版必需条件，不能仅因“起音算一次”就预设它资源更省。

## 峰值安全与保真边界

C<=256、vel<=127 保证每声部数值范围不扩大。八声部按绝对值三角不等式求上界，既有 19+E 位两条累加器仍够，主音量保持除以 8，mix 权重和为 255/256、压力/静音增益不大于 1。以当前合法波表峰值、包络上限与量化规则复核整链路，不能只测随机和弦。

该设计保障不增加声部数学上界；由于相消会改变，实际某段音频的峰值可以高于旁路版。验收改为“无内部溢出、最终无硬削波、记录软限幅占比”，不以“限幅次数必然不增加”为条件。现有 0.75 FS 以上 4:1 软整形在同相八声部时仍可能触发并带来谐波，保留为安全兜底。当前 clip_count 在启用软限幅时统计拐点触发，不等同硬削波计数，离线分析应分别记录。

保守数值模型按 E=2 的完整有符号 18 位包络后样本范围计算：每声部界为 -130048..130047，八声部界 -1040384..1040376，满足 21 位累加。遍历两路和的正负端点、全部 256 个混合权重和压力增益端点，软限幅前 24 位主输出界为 -8290560..8290496，仍落在 24 位范围。这个证明依赖前级本身没有溢出、力度不超过 127、补偿不超过 1、主增益除以 8；不覆盖绕过这些条件的参数配置。

若实测软限幅占比仍过高，先在公共主增益增加**固定衰减**并盲听，不能自动补回 6 dB。可选更保守的模式将所有补偿系数再限制到 0.75 倍上界，代价是低音也衰减约 2.5 dB；它应作为另一个可评估配置，不能暗改既定低音 0 dB 目标。

只有用户仍要求实际低音正增益，且固定余量不能接受时，才进入宽位宽加动态控制方案。+5 dB 不必机械地把所有节点扩到 24/32 位，应从18位声部结果新增至少一位、累加和全局拆分乘积逐段推导；是否需要前瞻取决于允许的瞬态失真和实现目标，节目压缩与前瞻限幅并非不可分割的强制组合。

## 公共低通与输出量化

只保留一份公共滤波，在 24 位全局有效样本之后运算，16 位由同一结果量化输出。原有 16 位滤波删去；双滤波实现可作短期对照，不作为资源最省的终态。

滤波内部建议 24 位样本加两个小数保护位：26 位状态、27 位差分。半差分使用明确定义的舍入方式，避免负数算术右移导致静音停在 -1。可用对差分的幅值除二并在半 LSB 时向远离零方向取整，使常量输入最终收敛到输入值；绝对值应额外扩一位处理最负数。输出量化与饱和另行定义，验证静音尾音最终为零及 DC 偏置。

当前 sums_valid 早于 global_crossfade 的共享计算完成；滤波更新必须绑定全局最终结果的有效拍。计划在该模块输出独立 result_valid 脉冲，或在同一模块内顺序完成滤波与输出，避免顶层复制内部 state 编号。每帧只执行一次滤波。该接口属于待实现变更，本轮仅记录设计，不修改公共接口。

24 位 I2S 取公共滤波值，16 位 PT8211/I2S 从其有符号舍入并饱和得到；满幅附近舍入后可能得到 32768，必须再次饱和。两者数值差应由量化界约束，不能只看“5 kHz 以上小于 1 dB”；静音频点或很弱频点上的 dB 比值无意义。是否保留当前截止频率，通过同滤波、不同键控曲线的盲听独立决定，防止两种处理叠加后过暗。

## 资源预算与验收

| 项目 | 本版设计预算 | 签核依据 |
|---|---|---|
| BSRAM | 增量 0，基线 40/46 | 新综合确认系数未推断成 BSRAM；波形表仍使用 pROM |
| MULT18X18 | 增量 0，基线 1 | 共享调度及综合报告；MULT9X9 原有 1 另行列出 |
| 系数常量 | 最多共享 25×9=225 bit | 物理 LUT4/ALU 数量取决于综合，不能按位数换算 |
| 声部控制状态 | note 快照 56 bit、共享 A 15 bit、少量状态 | 不新增八套并行乘法和八份系数计算器 |
| 公共低通 | 26 位状态替代原 16 位，净状态约 +10 bit | 差分、舍入和流水 FF 另计，无乘法器 |
| 调度 | 265 拍预留预算 | 逐周期仿真验证 next sample_tick 前完成且请求不重叠 |
| 新前瞻缓存/动态检测器 | 0 | 首版完全省去 |
| Fmax | 不作预报 | 目标时钟下 PnR setup/hold 通过，并保留工程余量 |

先生成关/弱/强三个版本的离线同片段 WAV，覆盖 C2–C7、力度 1/2/16/64/100/127、C5前后逐半音、吉他变体门限及音区交界。首轮试听用于确定曲线，不以短音 LUFS 直接认证等响；固定时窗 RMS/峰值、加权电平和全频谱作为辅证，回放音量与设备固定。为评价舒适度和相对响度保留原始电平对照；评价音色偏好时另提供整体等响度对照，不逐音归一化抹掉键控效果。

RTL 实现阶段新增自检：补偿关闭时幅度操作逐位等价、零力度静音、所有合法系数/力度位宽、音色选择保持、帧快照一致、抢占淡出时 note/gain 同拍、乘法请求无冲突、样本不丢帧、DC/脉冲/静音尾巴、公共输出量化关系、八同相音及混合相位的整链路最坏情况。所有不成立条件使用 $fatal。

验收不承诺“C2–C7 听感 ±2 dB”或“绝对最佳音质”。数值目标是系数量化误差 <0.05 dB、补偿旁路严格等价、无内部越界/最终硬削波、调度不超帧；感知目标由盲听及真实板卡回放确认。最终运行项目完整 run_simulation.ps1，再做综合/PnR、试听；本轮没有 RTL 改动，未执行硬件门禁或烧录。
