# 电吉他第一版与 HID 可靠性修复

日期：2026-10-19；依据：`archive/FPGA-20261019-v0.8` 的《8声部电吉他规划与代码审核》。本轮按它的顺序先修 P1，再做 Clean 吉他第一版；未烧录。

## 1. P1 可靠性修复

| 问题 | 修改 |
|---|---|
| HID 事件 FIFO 指针 5 位、mem 只有 16 项 | `wptr/rptr` 改为 **4 位**，`count` 保留 5 位；累计 16 次后正确回绕 |
| flush/超时/0x86 只清按键、不清队列 | 新增 `clear_all`，同一高优先级周期清 `wptr/rptr/count/overflow`，并禁止该拍入队/出队 |
| 满队列同拍可出队时仍丢事件 | `room = (count < 16) || (ev_valid && ev_ready)`；满且本拍出队时允许入队，不再静默丢 Note Off |
| 0x86 未进入顶层 clear_events | `host_kbd_input` 引出 `device_notify`；`top` 把它并入 `manual_flush` 与 `clear_events`，清声部/事件 |
| UART 停止位错误后仍拼旧帧 | `ch9350_rx` 新增 `frame_error`，立即回到 `W57` 重新找头 |
| A/F/K 与 Q 等映射同一音高，按音高释放会误停 | 停用 A/F/K 兼容别名，只保留双排键位 |

验证：`tb_host_kbd` 扩展了 20 次按/松（40 事件，跨 16 项两次）、flush 清队列、0x86 拔出；PASS。

## 2. Clean 电吉他第一版

- **波表**：`tools/gen_guitar_bank.py` 生成 6 张 512 点带限表，按 MIDI 频段 0–47/48–59/60–66/67–75/76–83/84–95 分档，拨弦位置 0.18、`1/h` 衰减、3 次谐波身体共振；每档谐波数按最高音限制。
- **存储**：6 表装进 3 个 pROM（每块 1024×18，两表共用），新增 **3 块 BSRAM**；吉他档构建时钢琴/通用表被裁掉，实测 BSRAM 7/46。
- **选表**：`shared_wavetable_engine` 新增 `GUITAR_ENABLE`、`guitar_enable`、`guitar_sel_q`，`guitar_band_config` 按 inc 选 0..5 档；`rom_bright_d` 三选一（吉他/钢琴/通用）。
- **包络**：`voice_transition` 新增第三套 ADSR（attack 256、decay 3、sustain 45875≈0.70、release 8），起音/重起音时锁存 `guitar_mode`；与钢琴/普通包络并列，不改旧路径。
- **音色选择**：运行时 `I0/I1`（钢琴/吉他），电脑端新增“音色：钢琴/吉他”按钮和 **F6**；切换拍清声部/事件，避免持音中途换表。统一 `debug8` 档同时包含钢琴与吉他表（43/46 BSRAM），无需换位流。原 `debug8g` 构建期档保留作回退。
- **未做**：过载/箱体滤波/2× 过采样、压力表情与手势、运行时切换、8 键 NKRO。这些按 v0.8 规划留在后续。
