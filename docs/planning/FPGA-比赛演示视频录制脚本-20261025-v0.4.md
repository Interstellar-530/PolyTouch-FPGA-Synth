## 4. 正式录制前验收

### 4.1 版本和位流冻结

1. 固定使用已通过门禁的 `standard27` 位流，录制期间不改源码。
2. 记录分支、提交号、构建时间、位流 SHA256。
3. 保存 Quick 门禁或完整门禁日志、构建收据和 PnR 报告。
4. 视频中的 RTL、资源数字和位流必须来自同一个版本。
5. 不显示 GitHub Token、串口账号、本机用户名和其他敏感信息。

### 4.2 必须通过的硬件检查

| 检查项 | 通过标准 |
|---|---|
| Dock 供电和下载 | 配置成功，串口命令有 `OK` 应答 |
| CH9350L 键盘链路 | 按下、松开、四音和弦有效 |
| MCP3208 与 FSR | 松、轻、重三档数值可重复变化 |
| PCM5102A | BCK 约 3.000 MHz，LRCK 约 46.875 kHz，每帧 64 BCK |
| 模拟输出 | 示波器或 Line In 能看到对应频率 |
| 四音和弦 | 至少四个独立音符同时发声 |
| 八音并发 | 串口八音事件全部被接受，频谱有八个基频峰 |
| 双音色 | F6 或 `I0/I1` 生效，切换后重新起音 |
| 长按与清音 | 五秒以上长按不被误截断，Esc/X 能清音 |
| 延迟测量 | 十次波形完整，最大值记录清楚 |

### 4.3 测量的通用规则

本版把示波器测量放进对应分镜，不再集中放在前置章节。每场拍摄前按该分镜下的“本场测量”执行，测量数据与画面使用同一冻结位流。

- 所有数字测量使用 10× 探头和高阻输入，地夹接 GND，不夹信号线。
- I2S 优先在 PCM5102A 模块端测量，既证明 FPGA 输出，也证明连接线到达 DAC。
- 模拟输出使用 3.5 mm 立体声转接头：`TIP` 为左声道，`RING` 为右声道，`SLEEVE` 为音频地。
- 每次截图必须保留垂直档位、时间基准、触发电平和探头倍率。
- 测量记录必须写明位流 SHA256、探头位置和测试条件。
- 找不到安全 `T13` 测试点时跳过串口精确延迟项，不能直接碰芯片球。
- 官方总延迟只认 `L9/T13` 控制事件到 PCM5102A 模拟输出的测量；只看 FPGA 到 DIN 的数字延迟时必须明确标注。

## 6. 2 分 55 秒旁白提词版

> 这是一台由 FPGA 逐样本实时计算的电子乐器。键盘决定音高，压力传感器控制表情，所有振荡、包络、混音和输出都在硬件逻辑中完成。
>
> 系统以 Tang Primer 20K 为核心。CH9350L 接收键盘事件，MCP3208 采集 FSR 压力，PCM5102A 接收 FPGA 输出的标准 I2S 音频。电脑只用于调试和测试事件，不参与音频合成。
>
> 每个声部都有独立相位累加器和 ADSR 包络。ROM 保存的是单周期波形，不是整段歌曲或预录 PCM。相位步进、插值、包络和混音都在每个采样节拍实时计算。
>
> 按下四个键后，四个声部同时保持各自的音高和包络。松开一个键，只有对应声部进入释放，其余声部继续发声。FSR 提供连续的力度或表情控制。
>
> 这里切换钢琴和吉他两种音色。音色参数和包络切换由 FPGA 内部完成，电脑不参与声音生成。
>
> FPGA 通过标准 I2S 将音频送入 PCM5102A。当前整机档 BCK 约 3 MHz，LRCK 为 46.875 kHz，每帧 64 个 BCK。
>
> 为避免普通键盘的无冲限制，这里通过串口发送八个实时音符事件。FPGA 同时运行八个独立声部，频谱中出现对应的八个基频峰。
>
> 延迟测量从键盘事件进入 FPGA 的 UART 起始位开始，到 DAC 模拟输出达到峰值百分之十为止。十次触发中，最大延迟为 [X.XX] 毫秒。
>
> PolyTouch 完成了实时波表合成、多声部混音、多维演奏输入、双音色和标准 I2S 输出。所有关键结果都来自同一冻结版本的 FPGA 位流与实测证据。
