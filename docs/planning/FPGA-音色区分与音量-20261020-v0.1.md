# 音色区分与音量控制

日期：2026-10-20；对象：`debug8` 统一档。

## 1. 音色区分

用户反馈钢琴/吉他区别不明显。原两套表都走同一 24 位 5.4 kHz 公共低通，且包络都偏持续，听起来接近。本轮改动：

| 维度 | 钢琴 | 吉他 |
|---|---|---|
| 波表 | AKWF 电钢琴表提亮：阶段倾斜 `0.006 + 0.014×(5−s)`，钟形谐波 `0.30` | Karoryfer 真实采样不变 |
| 包络 | attack 1024、decay 2、sustain 32768（0.50）、release 32（约 68 ms） | attack 256、decay 8、sustain 16384（0.25）、release 8（约 44 ms） |
| 音体 | 走公共 5.4 kHz 低通 | 额外 3.5 kHz 一阶低通（a=0.375），钢琴旁路 |
| 听感目标 | 明亮钟形、长延音 | 短促拨弦、暗音体 |

- 吉他额外低通在 `top` 的 24 位公共低通之前；`guitar_mode=0` 时该滤波器状态跟随输入，切换时不会留下旧尾音。
- 钢琴表重新生成，36 表/18 BSRAM 不变；吉他 36 表/18 BSRAM 不变。
- 这是**音色设计改动**，最终区分度需上板盲听确认；目前只保证结构差异和包络差异。

## 2. 音量控制

- UART 新命令 `V0..V100`：0 静音、100 原始电平；平方律增益表 101×9 bit（100=256，50=64≈−12 dB）。
- `top` 内 1%/采样 slew（约 2 ms 从 0 到 100），避免按键调音量时咔嗒。
- 24 位路径乘 `volume_gain` 后再派生 16 位：`vol24 = (filtered24 × gain) >> 8`；16 位从 `vol24` 舍入饱和。
- 资源：新增一个 24×9 乘法（综合报告仍为 MULT18X18 1 + MULT9X9 1）和 101 项 LUT；Logic 10899（+4）、Register 3424（+32）。
- 电脑端：**↑/↓** 每步 5%，状态栏显示“音量 xx%”；`KeyboardCore` 白名单加入 `V[0-9]{1,3}` 并限制 0..100。
- 串口实测：`V50 -> OK`、`V100 -> OK`、`V0 -> OK`、`V100 -> OK`。

## 6. 追加修正：吉他过暗/偏轻（10:45）

用户反馈吉他太朦胧、同音量下比钢琴听感小。测量发现吉他表 RMS 其实高于钢琴（0.587 vs 0.501），问题不是表电平，而是：

- 额外 3.5 kHz 音体低通与公共 5.39 kHz 级联，把吉他高次谐波压掉太多，听感发闷；
- 吉他 sustain 0.25、decay 8，持续段比钢琴 0.50 低 6 dB，整体响度偏小。

修正：

- **移除吉他专用 3.5 kHz 低通**，两件乐器只共用 5.39 kHz 公共低通；音色区分主要靠钢琴提亮表、吉他短衰减。
- 在 `global_crossfade` 软限幅**之前**给吉他 +3.5 dB（×1.5，`x + x>>>1`），钢琴直通；峰值由现有 0.75 FS 软限幅兜底。
- 吉他包络保持 sustain 0.25，保留拨弦短衰减特征。

结果：Logic 10837（53%）、Register 3398、BSRAM 40/46、MULT18X18 1、MULT9X9 1、Fmax 33.548 MHz、违规 0；位流 `EEC3292D…0CAE487E`。Flash 操作 37 成功（27.04 s），UI `D0/M1 -> OK`（PID 25200）。

仍建议上板对比：同一音高、同一音量下钢琴长音 vs 吉他短音；若吉他仍偏轻，可把 +3.5 dB 调到 +5 dB（1.75×：`x + x>>>1 + x>>>2`），或把 sustain 从 0.25 提到 0.30。
## 7. 追加修正：整体音量变小（10:51）

用户反馈整体音量变小。定位到 24 位公共低通的**定标错误**：

- 滤波器状态 `mix_lp_y` 是 26 位（24 位样本 + 2 个保护位），但差分输入直接用了 24 位 `mixed_shared24`，没有同乘 4。
- 一阶低通稳态 `y* = x`，输出 `y[25:2] = x/4`，即整体 **−12 dB**；这与“高音变柔”叠加，听起来就是整体变小。

修正：

```verilog
wire signed [25:0] mix_lp_in = {mixed_shared24, 2'b00};
wire signed [26:0] mix_lp_diff = $signed(mix_lp_in) - mix_lp_y;
```

输出 `y[25:2]` 恢复为输入本身；音量 100 重新是 unity。吉他 +3.5 dB 补偿保留。

指标：Logic 10778（52%）、Register 3398、BSRAM 40/46、MULT18X18 1、MULT9X9 1、Fmax 31.386 MHz、违规 0；位流 `2F8DB574…5DFC8606`。Flash 操作 37 成功（26.89 s），UI `D0/M1 -> OK`（PID 36012）。

这次也暴露出测试缺口：`tb_top_switch` 只验证切换/门控，不检查低通直流增益。后续应补一个 C2 长音 `final_sample24` 峰值与 `mixed_shared24` 峰值的比值断言（目标 1.0±0.02），防止同类定标错误。
