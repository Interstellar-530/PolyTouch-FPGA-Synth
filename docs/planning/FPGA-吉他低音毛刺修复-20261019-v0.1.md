# 吉他低音毛刺修复

日期：2026-10-19；对象：v0.11 的 Karoryfer 低音吉他表。

## 现象

低音区（C2–G3）有明显毛刺/噪点，高音区正常。

## 根因

1. **循环接缝**：旧生成器在时域取“一个周期”后重采样到 512 点。低音周期长，自相关 lag 与真实周期有小数误差，首尾样本不闭合。实测最低表 `wrap/median step = 20.5`、最大步进 3979；高音表只有 0.003 级。每周期一次跳变，低音听起来就是连续毛刺。
2. **取样点太晚**：旧脚本从 0.30 s 开始取段。Karoryfer 的 `p` 动态在 E3 上 0.3 s 已衰减到噪声级（基频约 −44 dBFS，5 次以上谐波 −90 dBFS），归一化会把噪声底抬起来。
3. **默认力度映射到 `p`**：`DEFAULT_VEL=100`，旧映射 `vel[7:5]=3` → `black/p`，正好是最轻、信噪比最差的采样。

## 修改

- 用**精确 f0 谐波分解**代替时域截周期：
  - 零填充 FFT + 抛物线插值估计 f0；
  - 在 `h*f0` 上做 Goertzel，取每个谐波的幅度/相位；
  - 幅度低于基频 0.0008（约 −62 dB）连续 4 次即停止，压掉非谐波噪声；
  - 6.5 kHz 一阶低通，合成 512 点严格周期表。
- 取样窗口从 0.30 s 提前到 **0.08 s**，取起音后的稳定段。
- 低音区（band 0–1）不再用 `p`：`vel<112` 统一 `green/f`，`vel≥112` 用 `black/f`；默认力度 100 现在是 `green/f`。
- 高音区保持 `p/mf/f` 力度分层。

## 结果

| 最低表最大步进 | 3979 | **671** |
| 最低表 5 kHz 以上能量 | 6.2% | **0%**（低音表谐波到 1–2.3 kHz） |
| 低音表谐波数 | 5–13（含噪声） | 6–14（gate 后） |

## 边界

Karoryfer 这套采样最低音是 **E3（MIDI 52）**，没有 E2。C2–D#3 仍是 E3 表下移，低频 body 不如真实低音弦；本次只解决毛刺/噪声，不声称低音音色已经真实。过载/箱体/2× 过采样仍未做。
