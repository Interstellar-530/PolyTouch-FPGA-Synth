# 双通路后续实现草案

## 时钟与提交

原12.288MHz晶振直接生成I2S BCK/LRCK，避免把PLL输出作为DAC串行时钟来源；内部rPLL四倍至49.152MHz，仅计算及后续控制使用。I2S每帧tick经toggle同步至计算域；计算870拍完成后，24位样本保持并用完成toggle同步到参考域，在下一I2S帧边界使用。预期两端同步总开销低于约0.5微秒，须实际相位扫动及PLL厂商模型验证。跨域总线只在完成标志同步后采样，样本至少保持一个音频帧。复位要同时归零两边toggle，异步置位、各自时钟同步释放。

PLL参数拟定FCLKIN=12.288、IDIV_SEL=0、FBDIV_SEL=3、ODIV_SEL=16、DEVICE=GW2A-18C；输出49.152、VCO786.432MHz。UG286-2.0.2E印刷p30/33，DS102-2.7.8E印刷p38–40已Markdown转换及视觉复核：C8/I7 VCO500–1250MHz，输入/PFD3–500MHz，最大锁定1ms，最小复位10ns。仅参数合法，尚未证明物理实现。保持原生产顶层和两档构建入口，先增加独立测试封装与定向PnR。

## RAM声部控制候选

当前每声部4字仅存外部包络/力度、相位、增量。后续改每声部8字，单路32声部只用256个32位字，仍在单块SDP512×32内。候选布局如下，仍须通过独立参考验证。

| 字 | 候选内容 |
|---|---|
| 0 | 当前16位包络、逻辑力度7位、重触发待消费标志、gate/状态辅助位 |
| 1 | 相位32位 |
| 2 | 逻辑/待启动实际增量32位 |
| 3 | 渲染力度7位、ADSR状态、淡出标志、16位淡出步长 |
| 4 | 当前渲染增量32位 |
| 5–7 | 事件年龄、音高/版本、保留状态，按最终分配器需要确定 |

每声部额外读取渲染控制与增量，目标把当前4拍读取改成6拍；在最后捕获沿决定包络/淡出/相位，计算段仍23拍，预计29×32=928拍，主混合6拍，跨域及调度后仍应小于1024。当前19ns过渡路径包含音高到频率查找，新方案使用缓存增量避免该组合链。写回包络/相位/渲染控制/渲染增量可安排在四个ROM读状态，SDP读写地址不得冲突。这是预算，实际FSM若超拍需重排，不能沿用870拍结论。

重触发时旧包络非零则按ceil(env/64)淡出，最多64帧，保留旧增量/渲染力度；逻辑参数继续接受新事件，淡出不延长，结束时原子提交最新目标、相位归零。取消gate后不应复活待启动音符。初次空闲起音立即启动。共享ADSR必须保留现有时长/舍入口径或单独记录可接受差异，先测8再32/64。

## 事件与弯音缓存

现有配置握手两字写入占3拍，不能每帧通过配置口逐个更新64路包络：64×3=192拍超过当前154拍空隙。因此包络/淡出必须移入RAM核心，在逐声部时隙更新；外部配置仅承担稀疏音符事件。分配器可监视每帧读取的逻辑声部元数据，或保留小型gate/note表，避免复制64套包络与相位寄存器。

后续每路一块SDP缓存128个MIDI实际弯音增量，双银行128+128=256字。后台用已有第0路双乘法器计算33位非负基础增量×Q16比例，写入两路相同缓存，完成后在帧边界切换银行。2kHz弯音更新间隔有24个音频帧，预计128音高缓存可在若干帧空隙内完成；需测最大更新延迟、事件抢占及银行原子性。缓存2块加现有10块=12BSRAM，保留4块余量。主混合优先，后台乘法不能覆盖未消费结果。
