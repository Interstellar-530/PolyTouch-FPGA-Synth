# 极致低延迟优化方案

建议采用两条输入路径：保留完整 USB 键盘作为通用演奏输入，优先优化 CH9350L 串口及 DAC；另设直接接入 FPGA 的光电或霍尔演奏键，用于追求更低且可控的延迟。当前 32 声部计算已经足够快，主要优化收益在输入和转换环节。本文件是方案，没有修改 RTL、拨码、DAC 跳线或烧录。

## 已测基线与验收口径

现有 32 声部原型在 12.288 MHz 参考、73.728 MHz 计算、48 kHz 输出下，音符请求至首个非零 I2S 样本为 67.668..83.293 µs；包含 115200 UART 键盘帧接收为 1020.710 µs。617/1536 个计算周期是本次观测的最大帧尾。它支持继续做 32 声部集成，不代表尚未实现的 27→54 MHz 板级版本已经通过。原始结果见 ../reviews/FPGA-32声部延迟仿真-20261026-v0.1.md。

整机应分别测物理动作至首个数字非零样本、物理动作至模拟输出相对固定参考响度门限的起音，以及包络达到 10%/90% 的时刻。数字非零不等于人耳可闻，包络 90% 也不能替代起音延迟。对按键输入记录最大值和分布，并覆盖满 32 声部、反复重按、事件突发、不同事件相位；不只给平均值。

目标是完整键盘路径整机低于 3 ms、直接演奏键路径约 0.5..1.2 ms。这些是待验证的工程目标。现有仿真没有测到键盘扫描、USB 轮询、CH9350L 内部排队、DAC 模拟及听音阈值。普通键盘若自身耗时数毫秒，FPGA 合成优化无法补回这部分。

## 优先修改：利用现有硬件

首先评估 CH9350L 300000 波特率。已核对 WCH V2.3 手册第 6 页表 7-2，BAUD0、BAUD1 均为低电平时为 300000，默认均高为 115200。项目旧手册将双低配置标为不推荐，因此先确认实物版本及实测稳定性，不能直接假定现有模块支持。支持后需同时修改 FPGA 的接收配置；当前 host_kbd_input 有 BAUD 参数，但 top 没有把可选择的键盘波特率贯通到生产构建入口，需要补参数传递。27 MHz / 300000 恰为 90；12.288 MHz 原型用整数分频会有小量误差，需要检查允许的双方时钟误差。

11 字节、8N1 报告的理论时间从 110/115200=0.954861 ms 缩为 110/300000=0.366667 ms，单份节省 0.588194 ms。重复报告还可能占据串口带宽，连续换键时应实测积压；不能据单份帧计算宣称整个键盘延迟固定。现有报告去重应保留，不能等待几份重复报告再确认，也不提前使用未收完的报告推测松键。

其次核对 PCM5102A 的 FLT。TI SLAS859C 第 4、5 页明确：FLT 为低选择正常滤波，为高选择低延迟滤波；48 kHz 下典型数字滤波延迟从 20/Fs=0.416667 ms 降为 3.5/Fs=0.072917 ms，节省 0.343750 ms。46.875 kHz 下对应 0.426667、0.074667 ms，节省 0.352000 ms。这是数字滤波段的典型值，不能当作整个 DAC 模拟输出总延迟。模块 FLT 的焊盘、上拉和现状尚未核对；如果已经为高，则没有这项额外收益。修改前核对模块电路，不能给已硬接地的焊盘直接接高电平。

正常演奏期间持续输出 BCK/LRCK，并保持 DAC 已初始化、解除硬静音。不要在每次 Note On 时才启用时钟、启动 PLL 或重新拉动 XSMT；断流唤醒和软静音恢复会引入额外等待。压力静音、暂停和尾音依然在样本域使用已有平滑控制。

串口提速和正常滤波改为低延迟滤波两项理论合计节省约 0.932 ms（48 kHz）；前提是实物均支持且当前确实没有采用这些配置。不能将它从 1.021 ms 仿真结果中直接全部扣除，因为原仿真未包含 DAC 延迟。

## FPGA 与起音优化

板级先研究 27 MHz 控制域、54 MHz 音频计算域，音频计算与 I2S 使用同一 54 MHz 时钟，46.875 kHz 时每帧为 1152 拍。键盘逻辑仍留在 27 MHz；本轮完整键盘整机报告约 39.381 MHz 的 Fmax，不能不加检查就整体提高到 54 MHz。只让事件通过小型握手或异步 FIFO 跨到音频域，保留可靠的 CDC。取消的是音频结果来回跨域的等待，不是同步器。

通过对齐计算启动相位和 I2S 左帧装载时刻，争取音符事件至有效串行输出不超过 2..3 个采样周期（约 43..64 µs，46.875 kHz），具体仍需新时钟配置下仿真和布局布线。左右声道保持原子样本，不能中途改写半帧。当前约 83 µs 已很小，这部分收益只是几十微秒，应放在输入和 DAC 优化之后。

Note On 到达后立即调度，不等待整批事件或整小节；Panic 最高优先，释放事件保留，演奏事件优先于大批演示配置更新并为其他事件保留服务机会。保留事件 FIFO 的防丢功能，不用简单删队列追求低延迟。效果器保持干声直通，延迟/混响作为并行湿声混合，避免让整条干声等待一个音频块。不要为此盲目提高采样率：96 kHz 会减少 32 声部帧余量，既有声部渲染成本基本不变，应先解决毫秒级输入等待。

增加可选快速起音配置：在 48 kHz 下 ATTACK_STEP=2048 时满幅约 0.667 ms、90% 约 0.604 ms；3072 时满幅约 0.458 ms、90% 约 0.417 ms。当前默认 140 的 90% 约 8.79 ms。快速模式改变触感与音色，不冒充计算流水线加速；为钢琴等瞬态音色选用，慢起音音色保留原设置。保持相位、包络连续过渡及窃声淡出，不能直接跳到满幅。所有新增预算以真实音频、短仿真及点击瞬态检查确认。

| 优化项 | BSRAM / 18×18 乘法器增量规划 | 待验证内容 |
|---|---|---|
| UART 参数贯通、采样计数、快速包络参数 | 0 / 0 | 双方波特率误差、重复报告与连续换键 |
| 小型事件 CDC，音频同域 | 目标不新增 BSRAM、0 DSP；必要时寄存器 FIFO | 54 MHz 时序、背压、帧期限 |
| 直接演奏键同步、短时稳定判定与锁定 | 0 / 0，使用少量寄存器计数 | 实体传感器响应及误触 |
| 更换为 FPGA USB Host 核心 | 未估算，不纳入上述零增量 | USB 电气接口、时钟、资源和兼容性 |

以上是不新增声部、波表或效果器的优化。32 声部仍复用既有共享 ROM 和乘法器，原型 BSRAM 为 26/46，实际板级总量以后续实现报告为准。

## 追求更低且可控的延迟

增加光电/霍尔数字演奏输入，绕过实体电脑键盘扫描、USB 轮询及 UART，CH9350L 键盘继续供宽音域演奏和模式控制。对干净数字输入设计 0.05..0.20 ms 的按下稳定判定，再在约 0.10 ms 内完成数字音频响应；DAC 低延迟滤波预算约 0.075 ms，模拟电路及其他余量预算约 0.20 ms。首个数字/模拟起点目标约 0.425..0.575 ms，加快速包络后较明显的起音目标约 0.8..1.2 ms；均需按统一门限实测，不能视为已实现上界。

机械开关不要简单取消消抖。可评估带硬件施密特整形的首次有效边沿触发，然后对该键设置重复边沿锁定，松开另行稳定确认；毛刺和误触需实测。MPR121 等电容触摸控制器有内部采样与滤波等待，不能未经配置核对就套用上述光电/霍尔预算。

若必须只用完整 USB 键盘且串口仍成为瓶颈，再评估 FPGA 直接实现 USB Host。检索到 m1nl/usb_hid_host（Apache-2.0），支持低速/全速 HID，README 标注 12/60 MHz 相关时钟及可配置轮询，具有可复用基础。迁移仍需要相应 USB 主机供电、电气接口、时钟和报告兼容性工作，也不能消除键盘内部扫描等待。本轮仅检索，没有引入代码或工具依赖，不作为近期首选路线。

## 完整键盘路径的目标预算

| 环节 | 目标预算 |
|---|---:|
| 键盘内部扫描 | ≤0.50 ms，必须实测 |
| USB 轮询及 CH9350L 内部处理 | ≤1.00 ms，必须实测 |
| 300000 串口单份 11 字节帧 | 0.367 ms，理论值 |
| FPGA 调度到串行输出 | ≤0.100 ms，待板级验证 |
| DAC 低延迟数字滤波 | 约 0.075 ms，典型值 |
| 快速包络到 90% | 约 0.417 ms，3072/48 kHz 的理论值 |
| 模拟电路及预留 | 0.350 ms，预算 |
| 规划合计 | 约 2.809 ms |

这是选择满足输入预算的键盘后才有机会达到的目标，重复报告或物理输入更慢时不能沿用。若现用键盘在输入两项已超过 2..3 ms，优先采用直接传感器路径，不继续挤压只有几十微秒的合成时间。

实施顺序为：用同一时间基准测物理输入、UART 首位、事件接受、I2S 样本和模拟输出；先调整已确认支持的 DAC/串口配置，再做 32 声部板级集成和快速起音，最后才重构音频跨域或 USB Host。保留现有位流和音色配置，可按步骤独立回退。本轮无功能修改、无新性能验收、无烧录。
