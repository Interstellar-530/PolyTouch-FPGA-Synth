# 键控响度混音设计（修正版）

日期：2026-10-19；范围：设计思路与大致方案，不含 RTL 实现。修正自 v0.1，原因见下。

## 0. 对前一版的修正

1. **Q8 增益系数宽度**：1.0 若写成 256，需要 9 位；`vel_amp` 即使能塞进 8 位，也不代表系数可以 8 位。首版把系数做成 **9 位无符号 Q8（0..256）**，但只使用 ≤256 的衰减段。
2. **声部样本通路溢出**：当前每声部 `velocity_result` 是 16+E 位，`sine_acc/bright_acc` 是 19+E 位；把 `vel` 放大到 >127 会让 `velocity_result` 先溢出/截断，后级限幅救不回来。**首版不做放大**，`vel_amp` 始终 ≤127，保持现有通路的满幅范围；将来要低音提升，必须先把每声部乘积/累加扩到 24/32 位，再谈压缩器。
3. **16/24 位输出口径**：现有 5.2 kHz 一阶低通只接在 `mixed_shared`（16 位）上；`mixed_shared24` 直接送到 I2S，绕过低通。首版的键控增益在声部求和前，天然同时作用于两条输出；低通必须**统一到 24 位公共节点**，或对 16/24 位各做一份同系数滤波，不能只处理 16 位。

## 1. 首版目标（资源最省）

- 低音区**保持 0 dB**，高音区逐渐衰减；不做低音提升。
- 不增加压缩器、前瞻缓存、双段动态处理。
- 复用现有共享乘法器；不新增 BSRAM；延迟基本不变。
- 代价：整体电平降低，低音不会比当前更响；这是首版有意接受的折中。

## 2. 首版曲线

以 C4（MIDI 60）为 0 dB，高音每半音衰减 0.5 dB，两端限幅：

```text
G_db(note) = 0,                              note ≤ 60
G_db(note) = clamp(-0.5 × (note - 60), -6, 0), note > 60
```

| 音 | MIDI | 钢琴 | 吉他 |
|---|---:|---:|---:|
| C2–C4 | 36–60 | 0 dB | 0 dB |
| C5 | 72 | −6.0 dB | −5.0 dB |
| C6 | 84 | −6.0 dB | −5.0 dB |
| C7 | 96 | −6.0 dB | −5.0 dB |

- 5 个半音后到 −2.5 dB，10 个半音后到 −5 dB，12 个半音后限幅 −6 dB；曲线很平缓。
- 吉他在 C5 后限幅 −5 dB，保留一点空气感；钢琴 −6 dB。
- 如果听感仍偏尖，可把斜率改成 0.7 dB/半音；如果太闷，改成 0.3 dB/半音。斜率作为编译参数，不改结构。

## 3. 增益应用：折叠进力度，只衰减

- `gain_q8`：9 位无符号，256=1.0，128=−6 dB，0=静音；首版只取 128..256。
- `vel_amp = max(1, (vel × gain_q8) >> 8)`。
  - 因为 `gain_q8 ≤ 256`，`vel_amp ≤ vel ≤ 127`，**不会超过现有通路的满幅范围**；
  - `vel_amp` 仍是 8 位，不需要 9 位样本通路；
  - 系数本身是 9 位，解决“Q8 >1 需要 9 位”的宽度问题，但首版不进入 >1 区间。
- `vel_variant` 保持原始力度，只给吉他选 p/mf/f；`vel_amp` 只给幅度。两者分离，避免高音衰减改变吉他采样变体。
- 每个声部只在**起音/重起音时算一次**，之后保持不变；复用现有 18×18 共享乘法器（`vel × gain` 一次 8×9 乘法），不增加每采样乘法。
- 曲线可用 16 断点 + 线性插值，或直接分段线性；不需要 128 项表。

## 4. 16 位与 24 位输出

### 4.1 增益

键控增益在 `shared_wavetable_engine` 的每声部幅度缩放里完成，位于 `sine_acc/bright_acc` 求和之前，因此 `sample_out`（16 位）和 `sample_out24`（24 位）都会得到同样的音高补偿，不存在只处理一条的问题。

### 4.2 低通

现有 5.2 kHz 一阶低通只作用于 16 位 `mixed`；24 位 I2S 是另一条路。首版必须二选一：

- **推荐：统一到 24 位公共节点**  
  在 `mixed_shared24` 之后做 24 位一阶低通，状态 24 位、差分 25 位；16 位输出由滤波后的 24 位饱和右移 8 位得到。这样 PT8211 和 I2S 的频响一致，16 位只是 24 位的量化版本。
- **最小改动：双份同系数滤波**  
  保留现有 16 位低通；另加一份 24 位低通给 I2S，系数同为 a=0.5。两份量化不同，但频响一致；资源多 24 位状态和移位，仍无 BSRAM/乘法器。

不建议保留“16 位滤波、24 位直通”的现状，否则两条输出的高音舒适度不一致，验收也无法用同一套指标。

### 4.3 电平与饱和

- 16 位输出：滤波后的 24 位做饱和/四舍五入到 16 位，不能直接截断；
- 24 位输出：保持 24 位满幅，不再经过 16 位饱和；
- 两条输出的峰值/响度用同一段测试音测量，差值应只来自量化噪声，不应有 5 kHz 以上的频响差。

## 5. 为什么首版不加压缩/前瞻

- 首版只衰减，峰值不会超过当前；现有 0.75 FS、4:1 软限幅仍是最后一道，不需要额外的节目压缩。
- 不加 1 ms 前瞻，避免 47×16 bit 延迟线和额外时序；延迟保持现状。
- 不加双段动态，避免抽吸和额外调参。
- 代价是整体电平降低；如果听感上“高音不尖但整体太轻”，再把主音量移位从 3 调到 2，或加固定 makeup，而不是恢复低音提升。

## 6. 资源估算

| 项 | 首版 |
|---|---|
| 键控曲线 | 16 断点 + 插值，约 100–150 LUT6 |
| 增益系数 | 9 位寄存器/声部，8×9 bit |
| 乘法器 | 复用现有共享 18×18；+0 |
| BSRAM | +0；总 40/46 |
| 低通 | 24 位状态 + 25 位差分；+0 乘法器 |
| 延迟 | 键控 0；低通 1 个采样；无前瞻 |
| Fmax | 与当前 33.7 MHz 接近；需 PnR 复核 |

## 7. 验证

1. **宽度断言**：仿真中断言 `vel_amp ≤ 127`；`vel_variant` 与原始力度逐位一致；吉他 p/mf/f 变体不因衰减改变。
2. **等响扫描**：C2–C7，力度 64/100/127；C2–C4 电平不变，C5 约 −3 dB，C6/C7 约 −6 dB（钢琴）/−5 dB（吉他）。
3. **16/24 一致性**：同一段测试音分别从 `sample_out` 和 `sample_out24` 采集，5 kHz 以上频响差 ≤1 dB；峰值差只来自量化。
4. **和弦**：8 个高音、8 个低音、混合；限幅触发次数不高于当前（首版只衰减，理应更低）。
5. **回归**：`tb_top_pitch8`、`tb_top_switch`、`tb_guitar_bank` 保持通过。
6. **A/B**：确认高音变柔、低音不变；整体变轻是可接受代价。

## 8. 将来要低音提升时

必须同时满足以下条件，不能只改曲线：

- 增益系数进入 >1 区间，系数至少 9 位（Q1.15 更稳妥）；
- 每声部乘积/累加扩到 24/32 位，在求和前保留余量，不能依赖后级限幅；
- 加节目压缩 + 1 ms 前瞻限幅，控制低音和弦峰值；
- 重新做 8 音低和弦最坏情况和 Fmax 签核。

在这些条件满足前，首版坚持“低音保持、高音衰减”。

## 9. 结论

首版是一个**只衰减的逐声部键控高音搁架**：低音 0 dB、高音渐降到 −5/−6 dB，增益折叠进 `vel_amp`（≤127），复用现有乘法器，不增加压缩/前瞻/双段；16/24 位输出共用声部增益，低通统一到 24 位公共节点或双份同系数实现。它不会让低音更响，但能以最小资源代价消除高音尖锐，并为后续低音提升留下明确的宽度与余量条件。
