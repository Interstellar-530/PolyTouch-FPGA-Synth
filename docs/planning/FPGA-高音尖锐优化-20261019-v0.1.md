# 高音区尖锐优化

日期：2026-10-19；对象：AKWF 电钢琴 + Karoryfer 吉他统一档。

## 现象

高音区（约 C5 以上）钢琴和吉他都偏尖锐；低音区正常。

## 判断

- 两套表的**相对谐波**并不异常（表内 FFT 重心约 2.4 个谐波），但高音的基频高，3–8 次谐波直接落在 3–8 kHz，听感上就是“尖”。
- 主混合之后没有任何低通，DAC/耳机链路也偏亮；高音区能量完整保留。
- 低音区 3 kHz 以上能量很少，因此可以在主混合后统一低通，低音受损很小。

## 修改

在 `top.v` 主混合 `mixed_shared` 之后加一级**一阶低通**：

```verilog
mix_lp_y <= mix_lp_y + ((mixed_shared - mix_lp_y) >>> 1);
```

- 系数 a=0.5，采样率 46.875 kHz → 截止 **≈5.2 kHz**；
- 只用移位，不新增乘法器；
- 正系数凸组合，不会产生新的过冲/削波；
- 对低音区（谐波多在 3 kHz 以下）影响很小，主要压高音。

频率响应（一阶）：5.2 kHz 处 −3 dB，10 kHz 约 −6.7 dB，15 kHz 约 −9.6 dB。

## 回退/微调

- 如果高音仍偏尖：把 `>>> 1` 改为 `>>> 2`（a=0.25，fc≈2.5 kHz），但会明显变闷。
- 如果变得太闷：改用 a=0.6875（`diff - (diff>>>2) - (diff>>>4)`，fc≈8.7 kHz），保留更多空气感。
- 更精细的做法是按音区做键控低通；当前全局一阶是最小改动版本。

## 边界

全局低通会同时压掉低音区少量 5 kHz 以上成分；这是有意的折中。完整 `run_simulation.ps1` 未跑（按用户要求跳过长验证后烧录）。
