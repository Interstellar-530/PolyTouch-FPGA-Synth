# 键控响度混音设计

日期：2026-10-19；范围：设计思路与大致方案，不含 RTL 实现。

## 1. 目标与约束

- 低音区自动增大响度，高音区自动降低响度，使 C2–C7 在相同力度下听感更接近等响。
- 不破坏现有 8 声部、钢琴/吉他切换、5.2 kHz 主低通和软限幅。
- 不新增 BSRAM（当前 40/46），乘法器预算宽裕（当前 1/48）。
- 低音提升不能导致 8 音低和弦削波；高音衰减不能把音色压闷。
- 目标延迟仍 ≤10 ms。

## 2. 总体架构

```text
每声部：
  note/vel ──> 键控增益 G(note, instrument) ──> vel_amp
  table × env × vel_amp ──> 声部样本
  8 声部求和
      ↓
  节目压缩（慢速，只衰减）
      ↓
  可选：双段动态响度（低/高段缓慢平衡）
      ↓
  前瞻软限幅（1 ms）
      ↓
  DAC
```

关键点：**键控增益在声部求和之前做**，否则不同音高共用同一个增益，低音和弦里高音会被一起放大；节目压缩和限幅在求和之后做，只负责峰值安全。

## 3. 键控响度曲线

以 C4（MIDI 60）为 0 dB，按半音线性下降，两端限幅：

```text
G_db(note) = clamp(0.208 × (60 - note), -5.0, +5.0)
```

| 音 | MIDI | 钢琴 G | 吉他 G |
|---|---:|---:|---:|
| C2 | 36 | +5.0 dB | +3.5 dB |
| C3 | 48 | +2.5 dB | +1.5 dB |
| C4 | 60 | 0 dB | 0 dB |
| C5 | 72 | −2.5 dB | −2.0 dB |
| C6 | 84 | −5.0 dB | −4.0 dB |
| C7 | 96 | −5.0 dB | −4.0 dB |

- 钢琴低音需要更多补偿，因为基频能量低、等响曲线下降更陡；吉他本来中低频更足，提升少 1.5 dB，避免闷。
- 曲线用 **16 个断点 + 线性插值**即可，不需要 128 项大表；断点约每 3 个半音一个，误差 <0.3 dB。
- 线性增益 `g = 10^(G_db/20)`：+5 dB≈1.78，−5 dB≈0.56；用 Q8（1.0=256）存 0.56–1.78。
- 可加一个 **comfort 参数 0–100%** 缩放曲线（0=直通，100=完整补偿），通过串口 `K<0..100>` 调节，不重烧位流。

## 4. 每声部增益的实现方式

不能直接改 `vel` 再送引擎：吉他的 `vel[7:5]` 还负责选 p/mf/f 采样变体，改 vel 会连带换音色。正确做法是**分离两路力度**：

- `vel_variant`：原始力度，只给吉他选 p/mf/f；
- `vel_amp`：`clamp(round(vel × g(note)), 1, 254)`，只给幅度缩放。

`vel_amp` 最大 254，仍可放在 8 位通路里（127×1.78≈226；+6 dB 才到 254），不需要加宽到 9 位。每个声部在**起音/重起音时算一次**，之后保持不变：

- 128×8 的增益表（钢琴/吉他各一份）放在 LUT 里，约 2 kbit，不占 BSRAM；
- 或用 16 断点 + 插值，约 100–150 个 LUT；
- 起音时一次乘法（`vel × g`），可用现有共享乘法器分时完成，不增加每采样乘法。

如果不想改引擎接口，退一步可以先做**全局低音音符增益**：取当前最低音（bass note）查曲线，在求和后乘一次。成本最低，但低音+高音和弦只能折中；建议作为第一版试听，再升级到每声部。

## 5. 动态余量：压缩 + 前瞻限幅

低音 +5 dB 后，8 个低音和弦的峰值会明显上升；只靠现有 0.75 FS、4:1 的无记忆软限幅会产生失真。建议两级：

### 5.1 节目压缩（慢速，只衰减）

- 检测求和后的短时包络（attack 5–10 ms，release 200–300 ms）；
- 阈值约 0.70 FS，压缩比 2:1，软拐点 3 dB；
- 只做衰减、不做补偿增益，避免和键控曲线打架；
- 目标：低音和弦最多压 4–6 dB，单音基本不触发。

### 5.2 前瞻软限幅（安全网）

- 1 ms 前瞻（46.875 kHz 下约 47 个样本），延迟线 47×16 bit≈752 bit，用寄存器/LUTRAM；
- 阈值 0.85 FS，释放 80 ms，瞬时 attack；
- 放在压缩之后、DAC 之前；
- 1 ms 延迟对总延迟影响很小，远低于 10 ms 目标。

这样键控增益负责“听感平衡”，压缩/限幅负责“峰值安全”，职责分开，调参不会互相破坏。

## 6. 可选：双段动态响度

如果静态曲线仍不够（例如某些和弦低音太薄、某些高音仍尖），可在压缩前加一个**慢速双段平衡**：

- 低段：250 Hz 一阶低通；高段：3 kHz 一阶高通；
- 各自包络（10 ms/200 ms），计算低/高能量比；
- 与目标比例比较，缓慢调整低段/高段增益，范围 ±3 dB，时间常数 200–500 ms；
- 只做缓慢修正，不做逐音符动作，避免抽吸。

这一级是“内容自适应”，能补静态曲线覆盖不到的和弦；但会增加两个滤波器、两个包络和两个增益，建议第二阶段再做。

## 7. 资源与延迟预算

| 项 | 估算 |
|---|---|
| 键控表 | 2×128×8 bit，LUT 约 256 个 LUT6；或 16 断点插值约 120 LUT |
| 乘法器 | 起音增益 1 个 + 压缩 1 个，共 +2（当前 1/48） |
| BSRAM | 0（表放 LUT）；总 40/46 不变 |
| 前瞻延迟 | 47×16 bit≈752 bit 寄存器/LUTRAM |
| 延迟 | 键控 0 + 压缩 attack 5–10 ms + 前瞻 1 ms，总 <2 ms |
| Fmax | 增益/压缩加流水后预计 30–33 MHz；当前 33.7 MHz，需 PnR 复核 |

## 8. 验证方案

1. **等响扫描**：C2–C7，力度 64/100/127，测 A 计权或 LUFS；目标各音偏差 ≤±2 dB（而不是原始 RMS 平直）。
2. **和弦最坏情况**：8 个 C2、8 个 C6、低+高混合；记录压缩/限幅增益衰减，目标 <6 dB、无削波。
3. **切换/起音**：快速重复、音色切换、松键；无可闻抽吸或台阶。
4. **客观频谱**：高音区 5–10 kHz 能量下降，低音区 60–250 Hz 提升；与听感对照。
5. **A/B**：comfort=0/50/100 三档盲听；确认低音不浑、高音不闷。
6. 现有 `tb_top_pitch8`、`tb_top_switch` 等回归必须保持通过。

## 9. 分阶段落地

| 阶段 | 内容 | 风险 |
|---|---|---|
| 1 | 全局 bass-note 增益 + 现有软限幅 | 最低；先验证听感方向 |
| 2 | 每声部 `vel_amp` 键控增益（保留 `vel_variant`） | 中；改引擎力度接口 |
| 3 | 节目压缩 + 1 ms 前瞻限幅 | 中；延迟/时序 |
| 4 | 双段动态响度 + comfort 参数 | 较高；抽吸/调参 |

建议先做 1 + 2，确认“低音变大、高音变柔”的方向正确，再加 3 兜峰值；第 4 阶段按听感决定是否值得。

## 10. 风险

- 等响曲线与**回放音量**有关；固定曲线只是折中，comfort 参数是必要的。
- 低音提升会增加互调失真；压缩/限幅只能保峰值，不能消除低频互调，提升上限建议 +5 dB。
- 高音衰减过多会失去吉他的空气感；建议高音最多 −5 dB，并保留现有 5.2 kHz 主低通作为第二道。
- 每声部增益如果误用 `vel` 选变体，会改变吉他 p/mf/f 音色；必须分离 `vel_amp` 与 `vel_variant`。
