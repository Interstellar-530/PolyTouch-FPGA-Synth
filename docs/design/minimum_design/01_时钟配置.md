# 时钟配置

## 1. 模块目标

建立单一 12.288 MHz 时钟域，产生 48 kHz 采样使能、标准 I2S 所需的 3.072 MHz BCK/48 kHz LRCK，以及板载 PT8211 调试所需的 1.536 MHz BCK/48 kHz WS。Dock 3714 的板载 27 MHz 不作为标准 I2S 主时钟。

## 2. 算法逻辑

外部 3.3 V CMOS 有源晶振输出 12.288 MHz，接到 GW2A-18 的 GCLK 可用脚。12.288 MHz 直接作为 `sys_clk`，不使用 PLL。用一个 8 位自由计数器 `sys_cnt[7:0]` 对 256 个系统时钟循环计数：

| 信号 | 生成方式 | 频率 |
| --- | --- | --- |
| `sample_tick` | `sys_cnt == 0` 时拉高一个周期 | 48 kHz |
| `i2s_bck` | 对 `sys_cnt[1]` 取反或每 2 个系统时钟翻转 | 3.072 MHz |
| `i2s_lrck` | `sys_cnt[7]` | 48 kHz |
| `pt_bck` | 对 `sys_cnt[2]` 取反或每 4 个系统时钟翻转 | 1.536 MHz |
| `pt_ws` | `sys_cnt[7]` | 48 kHz |

I2S 每帧 64 个 BCK、256 个系统时钟；PT8211 每帧 32 个 BCK、256 个系统时钟，两者可以共用同一个 256 计数相位。上电复位用约 1 ms 的计数器产生 `rst_n`，在 `rst_n` 释放前保持音频输出为 0。

3714 的核心约束是全局时钟脚。GW2A-18 的 GCLK 脚包括 H11（Bank 0，板载 27 MHz）、K14/K15（Bank 1）、N10/M11（Bank 2）、T7/R8（Bank 3）、L2/M1（Bank 4）、J1/J3（Bank 5）、C8/A8（Bank 6）、A9/C9（Bank 7）。Bank 0、1、7 默认 3.3 V；3714 原理图显示 K14/K15 和 A9/C9 已连接到 HDMI/Ethernet 相关网络。PMOD 是否把它们同时引出，必须在板卡到手后用 3714 原理图加万用表确认；Sipeed 下载站的 `03_Bit_number_map` 只有 3709 版本，不能直接当作 3714 的点位图。若 4 个 PMOD 中没有空闲的 3.3 V GCLK 脚，最低实现的顺序是：先焊到空闲 GCLK 测试点或 SODIMM 对应脚；若仍不可行，则退回 27 MHz + 板载 PT8211 的调试通路，标准 I2S 输出方案暂不作为可提交版本。

27 MHz 不能通过高云 rPLL 的整数分频得到 12.288 MHz，因为 12.288/27 = 512/1125，IDIV/FBDIV 的整数组合无法表示这个比值。可以把 27 MHz 用于 PT8211 的近似调试，但不应把 PCM5102A 标准 I2S 锁定建立在它上面。

## 3. 例程参考

Sipeed 官方 `PT8211/src/top.v`、`pt8211_drive.v`、`gowin_rpll/gowin_rpll.v`、`gowin_clkdiv/gowin_clkdiv.v` 展示了 27 MHz 到近似音频时钟的完整路径，可作为板载调试输出参考。高云 UG286《时钟资源用户指南》解释 rPLL、CLKDIV、DCS 和 GCLK 的用法；SUG940 说明 SDC 时钟约束写法；SUG935 说明 CST 物理约束写法。PCM5102A 数据手册说明 48 kHz 下 SCK/BCK/LRCK 的允许关系。

## 4. 函数解释

建议实现 `clock_reset` 模块，端口包括 `clk_12m288`、`rst_n_in`、`sys_clk`、`sample_tick`、`i2s_bck`、`i2s_lrck`、`pt_bck`、`pt_ws`、`clock_ok`。内部用一个小型组合函数 `clk_ce()` 判断计数边界，用 `power_on_reset()` 计数器产生同步复位。CST 模板为：

```tcl
IO_LOC "clk_12m288" <GCLK_PIN>;
IO_PORT "clk_12m288" IO_TYPE=LVCMOS33;
```

SDC 模板为：

```tcl
create_clock -name clk_12m288 -period 81.38 [get_ports {clk_12m288}]
```

若同时保留 27 MHz 调试域，再为 27 MHz 单独建时钟，并在两个域之间只使用异步 FIFO 或双触发器同步器，不能直接跨域组合逻辑。

## 5. 后续优化方向

后续可以用高云 `CLKDIV`/`DCS` 替代手工计数器，降低时钟偏斜；可以增加外部时钟丢失检测，在 `clock_ok` 为低时自动静音；可以增加 24.576 MHz 时钟选项支持 96 kHz，但赛题按“活跃振荡器数 × 实际采样率”计分，过采样不额外加分，最低实现仍应保持 48 kHz。若以后更换板卡，优先选择已经引出 3.3 V GCLK 的 PMOD 版本。

## 6. 最小验收

示波器或逻辑分析仪确认 12.288 MHz、3.072 MHz BCK、48 kHz LRCK、48 kHz `sample_tick` 同时存在；PCM5102A 能锁定并输出测试单音；PT8211 调试口能独立发声；拔掉外部时钟后音频进入静音而不是随机噪声。

## 7. 3714 PMOD/GCLK 落地核查步骤

1. 用万用表确认 4 个 PMOD 的 3.3 V 和 GND 脚，再从 3714 原理图的 SODIMM 引脚表追踪哪些网络被引到 PMOD。
2. 在候选网络里寻找 A9/C9（Bank 7）、K14/K15（Bank 1）或其他 GCLK 脚；3714 原理图显示这些网络同时连接到 HDMI/Ethernet，但 PMOD 可能并联引出，必须实测确认。
3. 找到 GCLK 脚后，先用 12.288 MHz 有源晶振输出接 100 Ω 串联电阻和 100 nF 去耦，再接到该脚；用示波器确认上升时间、过冲和频率。
4. 在 Gowin CST 中只给 `clk_12m288` 分配该 GCLK 脚；综合后用 PnR 报告确认它进入 GLOBAL/PRIMARY 时钟资源，而不是普通布线。
5. 若没有任何空闲 3.3 V GCLK 脚，先尝试从 SODIMM 空闲 GCLK 测试点焊接；仍不可行时，最低实现退回到 27 MHz + 板载 PT8211 调试通路，标准 I2S 版本暂停，直到解决时钟输入。
