# 最小实现算法设计包

本目录包含 Tang Primer 20K Dock 3714 上电子乐器选题的最低实现算法设计。

| 文件 | 内容 |
| --- | --- |
| `00_总览与最小实现边界.md` | 最低指标、总体算法链、资源边界 |
| `01_时钟配置.md` | 12.288 MHz、48 kHz、I2S、PT8211 和 GCLK 约束 |
| `02_信号生成与处理.md` | DDS、波表、ADSR、混音、饱和和输出数据 |
| `03_模块间信息传递.md` | 事件格式、声部分配、握手、UART 和同步 |
| `04_硬件控制信号.md` | 引脚、I2C/SPI/I2S、初始化、CST/SDC 和器件配置 |
| `05_第二轮复查与补充.md` | 第二遍审阅发现的遗漏和补充结论 |
| `06_硬件调试说明书.md` | 上电、时钟、音频、触摸、ADC、复音、延迟和故障排查 |
| `07_PDF_MD_工具链与技能更新.md` | MarkItDown/Pandoc/Tesseract 链路、MCP 配置和 PDF 技能更新 |
| `AGENT_HANDOFF_PROMPT.md` | 可直接交给任何智能体的完整项目交接提示词 |

最低实现按 4 声部、两个 512 点音色、12 键触摸加 1 路压力、标准 I2S 输出设计。第一轮完成后按第二遍审阅补充了 3714 PMOD/GCLK 核实、MPR121 地址和上拉、PCM5102A FMT/FLT/XSMT、PT8211 固定引脚、BSRAM 块数计算、4 声部资源预算、UART 协议、测试模式和验收清单。第二版压缩包视为完整产物；`05_第二轮复查与补充.md` 记录了本轮发现的遗漏、修订位置和仍未闭合的板级事项。
