# 高音区多带波表优化

原bright波表固定包含16次谐波，在48kHz下从MIDI91起出现越过Nyquist的谐波；正向两半音弯音会把风险提前到MIDI89。生产引擎现按弯音后的实际相位增量选择16/8/4/2/1次谐波的五级512点波表，并在相邻级间连续混合。每一级的丰富波表在其最高谐波到达Nyquist之前逐步退出，切换边界相邻两侧收敛到同一张表。相位、包络、力度和外部接口不变。

原16谐波表逐值保留，其余表从原表DFT截去高次频率后重建，保持同一基波幅度，不逐表归一化。生成脚本为 `tools/gen_bandlimited_prom.py`，没有导入第三方代码。三个1024×16 Gowin pROM装入五张bright表，另用一块sine ROM，综合确认为4BSRAM、1MULT18X18；当前5558 Logic、2200FF，相比上版增加332 Logic、63FF及2BSRAM。单路4BSRAM，未来双路波表8BSRAM，仍需为状态存储单独核算。五级峰值分别32767、31187、28456、24204、18632。

共享乘法器增加每声部一次第二波表插值和一次带间混合。四声部引擎108拍/40次乘积，加全局混合后113拍/42次乘积，48kHz配置每帧256拍，余量143拍。整机1183个I2S帧、四键音色扫动及1047次相位连续检查通过。两个真实工程建立/展开、五项旧数值兼容回归、声部重按/窃声与混合输入整机回归通过。独立模块默认关闭带限，旧数值接口继续逐值一致。

波表原语通过2560个交错地址读取、CE保持及同步复位检查。两个引擎配置分别使用本地和外部共享乘法器，42370帧均与独立Python整数模型逐值相同，覆盖随机参数、频带边界、127个MIDI音高及负/零/正弯音。
