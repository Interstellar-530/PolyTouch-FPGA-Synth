# 第五项波表复用与音质审核

2026-10-21。结论：资源优化有效，吉他复用可以按无损通过；钢琴复用是小幅有损近似，不能按“音频完全不变、音质必然不下降”验收。本轮未发现主要谐波明显损失，幅度与相位变化很小，但存在可测的低电平高频成分变化，尚未做人耳盲听或实机录音。原说明中“听不见”“低于 16 位噪声”“只是舍入噪声”的结论已直接更正。

审核基线为第四项已归档的 `FPGA-20261021-v0.6`，并核实原实现提供的 `banks_before` 与该基线逐样本相同。比较覆盖完整的 36 张钢琴逻辑表和 36 张吉他逻辑表，不只比较挑选的六音乐句。当前 pROM 的全部 6144/15360 个初始化字也与对应新 HEX 一致，采样深度仍为 512 点、数据仍为 16 位、9 位地址及插值精度不变，没有发生错表或额外截断。

| 音质检查 | 结果与解释 |
|---|---|
| 吉他 | 原 36 张逻辑表经新映射后全部逐位相同；低频两组确为重复数据，所有力度变体保留，复用不造成音色或音质损失 |
| 钢琴保留区 | 原 zone 0 与 zone 5 的 12 张表逐位保留；zone 5 的带限表没有被低音区表替代 |
| 钢琴被替换区 | zone 1–4 的 24 张表被 zone 0 的阶段表替代，均存在数据变化，属于近似复用 |
| 最差钢琴单表 | zone 4、stage 5，相对 RMS 差 −60.73dB，约 0.092%；误差 RMS 14.79 个表采样单位、峰值 79，不能统一称为 1 LSB 舍入差 |
| 主要谐波 | 对旧表中幅度不低于最强非直流谐波 −60dB 的成分，最大幅度变化 0.0314dB、最大相位变化 0.0965°；表级最佳拟合增益变化不超过 0.00569dB，未出现主要谐波被明显删去或整体响度明显变化 |
| 全相位插值上界 | 穷举每张逻辑表的 512 地址 × 512 插值分数，生产 F=2 精度下单声部查表峰值差不超过 79 个原表采样单位；阶段混合权重不变 |
| 高频风险 | 旧表在不同音区设置的截止谐波为 170/85/57/33/21/10；共用第一组会带回原来去掉的弱高次成分。在 MIDI 0–95 对应音高上，受影响区的 Nyquist 以上残差能量最差约 −63.8dB，相对原表频域能量。这是带外风险指标，并非最终 PCM 或 DAC 失真实测，不能据此声称新增混叠精确等于该值 |

复用没有降低琴槌到琴体的阶段数量，也没有删除吉他力度变体；主要差别在钢琴音区带限细节。低电平误差不自动等于不可闻，误差小也不等于零。是否能听到还取决于音区、音色档、回放音量、耳机和环境，本轮不以一个固定 dB 门槛替代听音验证。

为确认差异没有被映射或整数运算放大，运行了一次前后实际 RTL 配对检查：104 个配置、6656 帧，使用 8 声部配置、生产 F=2 精度与键控增益，单独激活一声部。钢琴覆盖 7 个音高和 5 档音色，吉他覆盖 6 个频段及 11 个力度边界，另含通用音色。全部帧的 valid 时序、正弦输出一致，吉他 4224 帧与通用音色 192 帧逐位相同。钢琴 2240 帧最大差 58 个 Q2 单位，即 14.5 个原表采样单位；本次最差配置 RMS 差约 −68.94dB。阶段等待从 5859 缩短为 8 帧以快速覆盖阶段，这些短帧不是完整音符录音，不能把它当作完整听感或多声部整机测试。

原试听的软音色六音乐句，重新回读 WAV 后确为 −77.64dB 相对 RMS，绝对差 −88.32dBFS，约 1.26 LSB RMS，峰值 22 LSB；它只代表该乐句。原回放工具还缺整数舍入、用 8192 代替生产阶段长度 5859，并且吉他低音区力度分档不同，不能作为实际 FPGA 音频输出证明。已更正这些工具问题并保留旧文件，另生成较亮音色、力度 127 的钢琴模型 A/B，回读差约 −71.39dB 相对 RMS，峰值 62 LSB；吉他模型前后仍精确相同。新 WAV 仍使用合成包络，不含生产 F=2 增益路径、主低通和 VCA，仅作听音辅助。`diff.wav` 额外放大 40dB，不能把它的响度当作正常回放差异。

资源和时序记录均与当前 192 个输入、整组摘要、工具版本及位流 SHA256 匹配。`debug8usb` 从 40/46 降到 25/46 BSRAM，省 15 块；Logic 11392、Register 3702、DSP 1.75/24。Fmax 从 39.408 降至 37.890MHz，setup +10.645ns、hold +0.208ns，负裕量端点 0，仍满足 27MHz。本轮没有重复综合、完整长门禁或烧录；正式 `standard27` 和模拟音频外设不在本次 PnR/实测范围。

保真优先时，建议仅保留吉他完全相同表的去重，钢琴恢复原 36 表。按现有模块块数推算，BSRAM 为钢琴 18＋吉他 15＋明亮 3＋正弦 1＝37/46，可省 3 块并使本项的波表替换逐位无损；这是备选方案的资源预算，尚未切换或做 PnR。本轮保留现有第五项实现并标明有损性质，不擅自替换其资源/音质取舍。

本轮更正范围限于试听脚本、生成脚本的说明、对照脚本的固定电平文本及项目文档，没有改生产 RTL、ROM 或数据格式。更正前快照和补丁随归档保留，撤回这些审核更正不会影响现有位流。初次 RTL 夹具因 Windows vvp 无法打开中文路径停止，改用工作区 ASCII 临时目录后通过；准备阶段失败没有计为功能通过。证据在 `docs/evidence/FPGA-优化05审核-20261021-v0.1`，归档为 `archive/FPGA-20261021-v0.7`，含源码、WAV、位流、复现命令、MANIFEST 与 SHA256。临时编译和改名的参考模块在证据保留后清理，原始素材、运行环境及历史构建保留。

检索参考了开源 [osc_gen 波表生成工具](https://github.com/harveyormston/osc_gen)；本项目已有可复现的 HEX 和回放脚本，本次复用本地工具，没有引入第三方代码或新增依赖。
