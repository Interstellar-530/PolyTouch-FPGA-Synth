# 保留小数位与24位输出优化

生产路径在波表插值、包络及力度缩放中保留两个额外小数位，内部单声部结果为18位，分量和扩为21位。新增参数 `EXTRA_FRACTION_BITS` 默认0，独立模块默认公式逐值兼容；生产顶层选择2。新路径在包络、力度及全局固定余量边界就近舍入，VCA乘积直接量化到24位I2S输出。原16位输出仍从24位饱和结果取高16位，供PT8211和16位I2S配置使用。

这里的24位是数值输出宽度，不能当作24位模拟有效位深。波表仍是512点16位，主要的逐声部运算保留18位；压力VCA乘积中剩余的小数也能进入输出低位，因此压力降低不会再额外丢掉两个整数位。满幅波形和低电平音符仍受源表、18位中间量及最终DAC噪声限制，64声部阶段需要继续拓宽并重新核算。

全局混合保留单个18×18乘法器：分量差的高位用移位加法修正；VCA输入超过18位时也保存高位修正，避免在公共模块的全范围输入上回绕。8192组独立64位整数模型覆盖正负极值、音色/压力/静音变化、饱和与削波判定，本地和共享乘法路径均逐值通过。引擎42370帧独立整数模型验证、全音域/弯音及带限回归通过。默认旧路径五项回归和7168帧旧余量回归通过。

真实RTL的两个完整共享引擎及主VCA分别运行旧16位、新18位路径。每种条件捕获8192帧，合计65536帧；频率439.453125Hz、力度100、正弦音色、固定除以4，理想参考由源正弦表的DFT基波系数构造，保留直流偏置及增益误差，不作拟合消除。下列数字是时域数值误差SNR，与此前报告中拟合去DC/基波的残差口径不同，不能横向混用。

首轮只保留小数位但继续截断时满幅为88.17dB；新路径加入舍入后达到92.39dB，超过本轮自定92dB目标。原始首轮和最终捕获分别保存在 `before-rounding` 与 `master`。输出低8位有55582帧非零，不是简单补零。

生产整机1183帧音色测试保持113拍/42次乘积，压力整机1446个串行帧、3664次独立主混合检查通过；压力T90为2571.242微秒、强弱RMS比3.935558。I2S整机8721个帧的24位数据逐字正确，A4频率、BCK/LRCK/填充时序检查通过。重按/窃声/取消/静音整机回归及标准/调试两种工程展开通过。没有完整门禁、PnR或烧录。

最终综合为5809 Logic、2242FF、4BSRAM、1MULT18X18，较前版增加251 Logic与42FF，没有增加BSRAM或物理乘法器。原始报告及层级资源表在 `resources-rounded`。相同配置首次截断版为5634 Logic/2242FF，最终舍入版以5809为准。
