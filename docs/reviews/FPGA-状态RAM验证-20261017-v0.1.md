# 声部状态RAM基础单元

新增 `voice_state_ram`，用一块Gowin SDP实现512×32位状态存储，每拍独立读一个字、写一个字，读结果及read_valid同步产生；CE关闭保持读数据。上电及运行时复位先清输出，再顺序清512个字，ready在最后清写完成后置1，初始化期间外部写入不会混入状态。49.152MHz下清空约10.417微秒；当前模块尚未接PLL或生产声部。

厂商GW2A模型中，DP真双口最大16位，SDP简单双口可32位。本模块采用SDP的READ_MODE=0，地址取AD[13:5]；写端ADA[3:0]必须为1111，因为这里是四个字节写使能，不能作为普通补零。这个细节已由真实厂商模型逐字验证，避免只在便携模型正确的实现。

便携模型与本机高云SDP模型各自通过512地址全32位、8192个随机周期、读CE保持、不同地址同时读写及两次512拍复位清空检查，每个模型共6166次读结果对照。双口同址读写的结果不作假设，后续调度器必须仲裁，本模块在仿真中检测该情况。状态RAM的读口和写口应供一个共享声部引擎顺序使用，事件写入安排在空闲窗口。

孤立综合确认56Logic、11FF、**1BSRAM、0DSP**，包含清空计数及ready/read_valid，没有把数组展开成大量寄存器。标准/调试两种真实工程建立及展开通过。模块进入工程清单与未来仿真门禁，但未接生产音频链；生产资源仍是5796Logic/2363FF/4BSRAM/1MULT18X18。没有完整门禁、PnR或烧录。

下一步复用现有带限时分核心，改为RAM读取每声部相位/参数，再接24位拆积。双路波表8块、每路状态1块、每路双银行频率缓存1块，初步预算共12BSRAM；余4块用于后续端口/事件需要。此为调度预算，不是64声部整机测量结果。回退可独立移除此模块及测试/清单项。
