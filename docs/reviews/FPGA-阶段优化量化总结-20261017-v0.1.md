# FPGA 阶段优化量化总结（2026-10-17，v0.1）

本阶段按用户要求停止新增优化，保存并推送已完成的实现与验证。标准/调试生产入口仍采用四声部；64声部是已经验证计算、主混合、PLL及I2S的原型，事件分配、ADSR、重按过渡和弯音缓存尚未接入该原型。不能把计算原型称为完整64声部乐器。

## 已接入生产的改进

| 指标 | 优化前/参考 | 已验证结果 | 测量范围 |
|---|---:|---:|---|
| 满包络时域SNR | 76.662 dB | 92.390 dB，提升15.727 dB | 实际RTL，包含DC与增益误差，未拟合 |
| 八组弱压力/尾音精度 | 原16位中间量 | 提升15.727–30.075 dB | 共65536帧，18位中间量和24位VCA输出 |
| 三组高音残余 | −12.462/−7.947/−2.336 dBc | −84.747/−91.011/−94.005 dBc | MIDI96/108/127附近，带限及舍入后的数字频谱 |
| 弯音误差上界 | 全4096个控制码对照 | 0.032741193音分 | 独立比例参考，三段流水 |
| 静音过渡 | 直接阶跃 | 高频能量降低40.73 dB，最长2.667 ms | 受控阶跃的5–20kHz导数频谱 |
| 重按/窃声过渡 | 直接切换音高/相位 | 高频能量合计降低32.02 dB，最长增加1.333 ms | 16组音频；单组16.65–36.56 dB |
| 压力控制响应 | 滤波重复消费旧样本问题 | 最差2.870 ms，单次毛刺峰值0 | 两配置八相位，ADC至内部VCA响应 |
| 四声部计算预算 | 每帧256拍 | 使用114拍、42次乘积，余142拍（55.47%） | 12.288MHz/48kHz |
| 四声部资源 | 资源优化后综合 | 5796 Logic、2363 FF、4 BSRAM、1个18×18乘法器 | 标准生产配置，综合结果 |

已修复力度帧快照、UART/GPIO同音来源所有权和ADC新样本调度。所有权独立检查2060事件通过，真实顶层混合输入五类情形通过。四声部固定增加1位衰减后，总归一化为除4，满幅四声部测试无削波。保持标准板级接口和原有控制功能。

以上SNR、残余和瞬态能量均为数字RTL结果，不能替代DAC模拟端THD+N、动态范围或整机听感实测。压力响应也不是触摸到扬声器的端到端延迟。

## 64声部原型及本次PLL收尾

64路在48kHz下对应每秒307.2万次声部更新，为最低四声部数量的16倍。64个不同频率同时工作，8192点捕获中各基波幅度误差−0.000127至+0.000019 dB，非预期总功率相对全部基波为−98.5496 dB。该结果来自纯正弦受控测试，尚不包含完整事件/包络前端。

| 指标 | 已验证结果 |
|---|---:|
| 计算架构 | 两条共享通路，合计4个物理18×18乘法器 |
| 完整计算与主混合预算 | 870/1024拍，余154拍（15.04%） |
| 时钟及串行接口 | 内部PLL49.152MHz；I2S仍直接使用12.288MHz参考，48kHz、24位 |
| PLL测试封装布局布线资源 | 2733 Logic、1364 FF、10/46 BSRAM、4 MULT18X18、1 rPLL |
| 约定的BSRAM预算 | 当前10/16，尚余6块；未来状态/缓存新增资源需再次综合 |
| 布局布线计算时钟Fmax估计 | 69.611MHz，相对49.152MHz目标高41.62% |
| 最差建立时间余量 | +5.980ns；全局setup与hold违反端点均为0 |
| 请求到样本提交最差延迟 | 17.986µs，比20.833µs帧周期提前2.847µs |
| 厂商原语组合验证 | 606计算帧、606提交、606串行解码通过；含复位、重锁定及静音 |
| 独立跨时钟桥 | 16时钟相位，各128次交付，变量1–900拍计算；最差18.556µs |
| 空声部运算活动 | 指定512帧64路随机负载减少39.39%乘法请求；不是实测功耗 |

首次STA出现25个hold端点，逐条定位为24位保持采样总线和结果标签首级同步器。约束现在仅豁免两个标签首级的跨域路径，以及保持采样总线的同沿hold检查；采样总线setup检查及后级同步器仍保留。总线在同步标签到达后至少两个参考周期才采样，下一帧前保持不变，16相位自检增加了此稳定窗口断言。修正后重新布局布线，setup/hold均为0，未对整组时钟使用false path。

PLL分频核对Gowin UG286-2.0.2E公式与DS102-2.7.8E的C8/I7参数：输入12.288MHz，反馈4、输入除1、输出除16，VCO786.432MHz；符合500–1250MHz范围。官方来源：[UG286](https://cdn.gowinsemi.com.cn/UG286E.pdf)、[DS102](https://cdn.gowinsemi.com.cn/DS102E.pdf)。本机SUG940-2.0E第69–70页用于核对精确时序例外语法。第三方手册不随项目发布。

## 验证入口及剩余工作

本阶段新增或保留的可复现命令如下，Python使用本机已配置运行环境。所有脚本均不烧录硬件。

```powershell
python tools/verify_audio_pll.py
python tools/verify_transients.py --out evidence/2026/10/FPGA-PLL时钟-20261017-v0.1/bridge tb_audio_frame_bridge
python tools/verify_ram_audio.py --out evidence/2026/10/FPGA-PLL时钟-20261017-v0.1/refactor
python tools/verify_build_profiles.py --setup-only --out evidence/2026/10/FPGA-PLL时钟-20261017-v0.1/build-profiles
python tools/build_pll_probe.py
```

本次沿用已通过的相关回归，额外完成8/32/64路计算模块抽离后的I2S复核、四项工程配置/展开检查、厂商PLL组合仿真和真实布局布线。依照用户要求没有运行完整门禁，没有烧录。PLL测试顶层仅为固定64音自测封装，不是生产烧录入口；新增PLL测试可由专用脚本复现，尚未加入完整门禁清单。

下一阶段的关键工作是将真实事件分配、ADSR/窃声过渡、双银行弯音缓存接入64路RAM调度，然后重新测量峰值事件负载、资源及时序。当前Fmax来自固定音测试封装，不能直接套用未来完整控制器。硬件接入前仍需板上PLL锁定、I2S波形及模拟音频实测，不能声称已达到硬件极限。接线方案原PDF保持原样。
