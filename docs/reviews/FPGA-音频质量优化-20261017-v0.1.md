# FPGA 音频质量优化，2026-10-17 v0.1

本次接续单乘法器架构的收尾，处理四声部余量、弯音比例精度和 ADC 复位一致性。没有增加硬件或演奏功能。用户已明确同意整机增加一位固定衰减。验收范围是相关 RTL 仿真、两种配置的工程检查和标准配置综合，不运行完整门禁，不烧录。

## 实现与指标

| 项目 | 修改前 | 当前实现与证据 |
|---|---|---|
| 四声部主音量 | 混合后右移一位，满幅同相可能削波 | 整机右移两位，响度降低约 6.02 dB；7168 帧覆盖全部 256 个权重、可达有符号极值、实际波表同相及随机相位，削波为零，峰值绝对值 32640 |
| 默认中心弯音比例 | 五锚点并先量化到 Q8，4096 码最大误差 1.227809 音分 | 直接按 ADC 分成 32 段，Q16 锚点及舍入插值；4096 码对独立指数函数，最大误差 0.032741193 音分，最差码 960 |
| 控制与 ADC 复位 | 原始采样及控制分频状态未统一清零 | 复位清控制分频、启动、通道和旧压力，弯音回中点；两个音频配置各覆盖三个事务中复位相位及空闲复位 |
| Logic | 4460 | 4408，减少 52 |
| 寄存器 | 1736 | 1738，增加 2 |
| 音频计算资源 | 1 个 MULT18X18、2 块 BSRAM | 保持 1 个 MULT18X18、2 块 BSRAM，MULTALU36X18 为零 |
| 帧内调度 | 81 拍、34 次乘法请求 | 保持 81 拍、34 次乘法请求；48 kHz 标准配置每帧 256 拍，余 175 拍 |

无削波的边界针对四路有符号 16 位声部、权重和为 255、压力增益不超过一倍。两条分量和各在 -131072 至 131068 内，混合及除以四后最大绝对值为 32640。独立模块 `global_crossfade` 的默认衰减仍是一位，整机 `top` 显式选两位；原有独立模块数值口径保留。实际旧衰减在相同测试集中会有 2370 帧超出 16 位范围。

精度表存放控制系数，波形仍由原有 Gowin pROM/BSRAM 读取。插值乘法用七项移位相加，复用音频乘法器的调度无需改变。对 8、16、32、64 段的数值研究，最大误差分别约为 0.201455、0.067268、0.032741、0.026171 音分；选择 32 段是因为继续翻倍仅改善约 0.00657 音分。单个 ADC 码对应约 0.0977 音分，最终仍需处理硬件噪声和中心校准。非默认 `ADC_CENTER` 保留旧算法并逐码验证一致。

这里的精度指标是弯音比例相对连续 ADC 映射的误差，不包含电位器非线性、ADC 噪声、晶振误差及 DDS 基频量化。新比例在控制 tick 更新，未发生 tick 时保持。端点 Q16 值为 58386、65536、73562，完整 32 位相位增量乘积也经独立 64 位参考检查。

## 修改边界、回退与剩余工作

修改范围为 `top` 的固定衰减及 ADC 包装状态、`global_crossfade` 的衰减参数、`pressure_bend` 的默认中心比例函数，以及对应测试和生成工具。板级引脚、UART 命令、波形表和共享乘法调度保持原有定义。需要回退时可单独撤销本次提交；若只恢复旧响度，将整机 `MASTER_VOLUME_SHIFT` 改为 1 即可，但会失去四声部满幅保证。

后续硬件样品仍需验证布局布线时序、实际 ADC 中心与噪声、FSR 标定、模拟输出幅度和本底噪声。本次只有综合，不能据此承诺布线后最高频率或真实功耗。继续减少逻辑需依据综合层级报告选目标；目前已没有多余的并行音频 DSP，继续扩大查表精度收益很小。任何烧录前仍需运行完整仿真门禁。

工作目录清理范围仅为本次新建的六组测试/综合临时目录和所导入工具的 Python 字节码。报告、CSV、生成脚本、源文件、归档和已有工具依赖保留。
