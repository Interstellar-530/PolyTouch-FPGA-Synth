# 第二项优化效果审核

2026-10-21。审核结论：**构建内容绑定与可复现生成的核心效果通过，第二项可以标记为功能完成。** 本轮没有修改被审构建脚本、生成算法、RTL、约束或硬件。

输入身份已从大小和时间戳切换为路径与 SHA256。构建前后、自动选择位流的烧录入口都调用内容比较；位流也有独立 SHA256 校验。现有自检的 11 项输入检查和 16 项构建入口检查覆盖等长且保留时间戳的源码修改、仅更新时间戳、构建期间输入变化，以及失败构建不留下成功凭据。审核对照了这些测试的实现、日志和当前代码，没有重复运行整套检查。

审核中发现的两处说明已直接更正。构建 README 已明确工具版本用于追溯，当前没有工具版本不一致时拒绝烧录的检查。优化说明已区分普通构建与再制表：普通构建使用入库 ROM/HEX，无需重新下载素材；电钢琴与采样吉他重新制表仍需要原 WAV 或 Samples，可以通过新参数指定来源。以上更正不改变实现或本项通过结论。
