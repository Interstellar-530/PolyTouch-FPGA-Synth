# 重按与窃声过渡修复

在分配器与音频计算之间增加独立的渲染状态。逻辑音符所有权仍即时更新，旧声部的音高和力度保留，包络按启动时幅度的 `ceil(env/64)` 步长淡出；达到零后才在同一采样边界提交新音高、力度和相位重启。最大64帧，即48 kHz下1.333 ms；闲置声部首次起音直接启动，没有这段等待。原ADSR模块和分配规则保持原样，没有增设第二振荡器或波形表。

过渡期间的新事件覆盖待启动目标，不重新延长旧声尾；新音符在淡出结束前松开时取消启动并清除隐藏ADSR尾部，避免“幽灵音符”。Panic与复位沿用原语义，复位立即清状态。包络和相位在切换边界同步，因此不能只改ADSR清零行为而保留即时音高切换。

验证包含独立状态机自检和真实UART顶层：同音重按、四键保持、第五键窃取最老声部、淡出中Note Off、取消后的声部复用及静音恢复。实际波表链对比原硬切路径，共16个相位/音色条件，捕获16384帧、实际运行50456帧，5–20 kHz汉宁窗差分频谱的合计能量下降32.02 dB，各条件下降16.65–36.56 dB。测试音为正弦C4转E4、亮音色C3转G3，其预期谐波未进入被统计频段。该指标用于比较受控数字切换，不等于任意音色、任意音高的模拟噪声或所有情况至少降低20 dB。

最终标准综合为4999 Logic、1997FF、2BSRAM、1MULT18X18。相对静音修复版增加597 Logic、225FF，未增加音频乘法器或存储。音频帧仍为81拍、34次乘法请求。两个Gowin工程实际建立并经Icarus展开，13项配置/模拟下载选择检查通过，没有实际下载。

相关顶层回归包括音色、模式/UART、按键、压力及标准I2S。模式台过去强制sample_tick持续为高，会制造非法的重叠音频帧并触发共享乘法冲突；现改用缩短歌曲时长参数来加速，保持合法音频节拍和冲突断言。没有修改生产调度去绕过断言。新模块已加入构建清单和相关完整门禁源列表；本轮没有运行完整门禁、PnR或烧录。
