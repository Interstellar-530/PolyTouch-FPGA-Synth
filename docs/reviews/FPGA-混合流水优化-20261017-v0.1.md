# 全局混合输入流水优化

弯音流水完成后，综合瓶颈转移为音色权重的步进比较、分量差高位修正和基值求和。生产主混合器现先快照两条分量和及本帧实际权重，再用下一拍装入共享乘法器操作数与修正基值；压力增益仍在原update沿捕获，防止多推进一步。新增 `REGISTER_MIX_INPUTS_ENABLE` 默认0，旧独立模块时序不变，生产设1。

本项只增加一个内部时钟，四声部计算从113变114拍，仍为42次乘积，标准帧256拍中余142拍。I2S仍在相同后继帧边界接收结果，因此没有增加一个完整采样帧的输出延迟，数值及舍入位置不变。

8192组主混合器参考检查覆盖全范围有符号分量、音色/压力/静音步进和饱和；额外在update之后立刻反转分量、权重、压力与静音，结果仍与原帧64位整数模型逐值一致。旧共享混合器回归保持数值和时序。真实顶层1183个音色帧通过114拍/42乘积及1047次相位检查；压力顶层1446个I2S串行帧、3664次独立主混合检查通过，RMS比3.935558、T90为2571.242微秒。两种真实工程配置建立/展开通过。

最终综合5796Logic/2363FF/4BSRAM/1MULT18X18，相比上一版增加48Logic、43FF。相同默认约束的综合估算最差到达由19.958降至19.295ns，新路径为声部过渡fade_env到引擎频率快照，逻辑级数24。时序是布线前估计，当前负slack仍对应默认10ns分析，不能据此宣称PLL配置或49.152MHz已通过布局布线。

本项没有修改波表和精度，因此不重复运行上一项65536帧SNR捕获；8192组逐值数值对照与真实串行数据检查直接覆盖此次修改。未运行完整门禁、PnR或烧录。下一阶段在已批准的2–4乘法器、16BSRAM预算内设计24位拆积和状态RAM，避免继续复制逐声部寄存器。回退可撤销本项提交或关闭REGISTER_MIX_INPUTS_ENABLE。
