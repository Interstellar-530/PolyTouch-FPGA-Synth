# 静音与恢复过渡修复

M0/M1 原先直接把任意相位的最终样本切成零或立即恢复。现在静音目标进入现有全局VCA，沿用每帧32/4096的增益步长，最大128帧到零，48 kHz时为2.667 ms。恢复从当前增益向当前压力目标变化；静音期间压力变化不会重新发声。复位仍立即清零，声部、曲目和I2S时钟继续运行。未增加板级端口或UART命令。

新增参数 `MUTE_SLEW_ENABLE` 默认关闭，使既有独立模块的结果保持原样；生产顶层开启它。静音输入只在开启时使用，复用了原有压力乘法及共享调度，没有额外音频乘法。标准实际综合为4402 Logic、1772FF、2BSRAM、1MULT18X18，较前版增加54 Logic，FF及音频存储/DSP不变。整帧仍为81拍、34次乘法请求。

新增自检覆盖1056帧：压力开启/关闭、局部/共享乘法、静音时压力改变、快速反复切换及精确整数参考。固定24902 LSB测试信号的阶跃从24902降为每帧至多195 LSB；该受控数字过渡的差分频谱中，5–20 kHz能量降低40.73 dB。这不是模拟DAC底噪或任意乐曲的听感测量。

真实顶层回归通过：音色测试1184帧，压力测试保持3.935558响度比，标准I2S测试解码8721帧并验证M0最终归零和M1恢复。M0验收等待调整为140帧，以覆盖128帧斜坡及串行缓冲，避免继续按即时硬切的旧行为验收。未运行完整门禁、PnR或烧录。
