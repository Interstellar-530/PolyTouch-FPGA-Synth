# FPGA 硬件搭建交叉核查

日期：2026-10-22，版本 v0.1。核查身份：FPGA 音频系统与硬件集成工程师。范围：GitHub 最新分支、现有 RTL/CST、本地聊天中的明确选择、原厂资料与已有构建证据。结论限于设计和已有软件证据，没有接触实物、测电压、重新综合或烧录。

## 核心结论

硬件主链路合理且有条件可行：普通 USB 键盘 → CH9350L → FPGA；FSR402 与弯音电位器 → MCP3208 → FPGA；FPGA 标准 I2S → PCM5102A → 有源音箱。普通键盘负责音符，FSR 负责独立连续表情，符合既定二维演奏设计意图；普通键盘没有每键力度数据，竞赛是否认可这些控制维度仍应按正式评分条文确认。本次不作竞赛合规认证。

**远端 881a11c 的两份最新硬件文档不能直接作为当前 USB 键盘整机的唯一装配依据。** 它们重新把 12 个机械键作为主输入，搭建指导选择 standard＋外部晶振，而本地明确授权的主路线是键盘直接插 CH9350L。它们还带回了旧 CH9350L 接线。建议保留其中新订单、电源分配和 ADC/DAC 接线内容，以本报告明确的主路线重新定版；本次保留原文快照，不覆盖或暗改队友文件。

## 可用于首轮装配的接口基线

下面是现有 standard27 接口的整理和单向模式接法说明，没有修改公共接口。上电前仍应确认排针 1 脚与每个模块实物网络。J5/J6/J14 的 1、2 为 3V3，3、4 为 GND，已复看 Dock 原图 PNG。

| 功能 | FPGA 端 | 外设端 |
|---|---|---|
| 键盘输入 | J5-5 / L9 | CH9350L TXD，3.3V TTL；模块 RXD 接本模块 GND |
| 键盘返回 | J5-6 / N8 | 留空，当前 FPGA 输出恒高 |
| ADC CS | J5-9 / N6 | MCP3208 芯片 10 |
| ADC CLK | J5-10 / D11 | MCP3208 芯片 13 |
| ADC MOSI | J5-11 / A11 | MCP3208 芯片 11 / DIN |
| ADC MISO | J5-12 / B11 | MCP3208 芯片 12 / DOUT |
| DAC BCK | J6-5 / B12 | PCM5102A BCK |
| DAC LRCK | J6-6 / C12 | PCM5102A LCK/LRCK |
| DAC DATA | J6-7 / B13 | PCM5102A DIN |
| DAC XSMT | J14-12 / P6 | 首轮模块已确认固定高时，本脚留空 |
| 外部晶振 | standard27 下 T7 留空 | 未来板级 48kHz 方案独立定版后，才评估 J14-10/T7 接入 |

MCP3208 的 16/VDD、15/VREF 接 3.3V；14/AGND 与 9/DGND 就近共地，电源与参考各去耦。CH0 接“3V3—FSR—节点—10kΩ—地”的节点，CH1 接 10kΩ 电位器滑臂。没有旋钮时用等阻分压给 CH1 中位，避免悬空。原厂引脚图已视觉核对；当前 SPI 默认约 250kHz，19 时钟一转换约 76µs，适合控制采样，不参与逐样本音频查表。FSR 分压源阻抗、采集误差和滤波响应仍需实测。

PCM5102A 配置为 FMT 低、SCK 低、DEMP 低，FLT 记录实际配置，XSMT 高。三线 BCK PLL 是原厂支持的模式；原厂频率表明确列出 48kHz/3.072MHz，而 46.875kHz/3.000MHz 的实物锁定本轮仍无证据，不能由“支持 I2S”直接推导已验收。若这档不锁定，先保留 PT8211 调试，再完成带 CH9350L 的 48kHz 板级档，不临时把 standard GPIO 位流当 USB 版本。

DAC 芯片资料不能代替 CJMCU 模块电路。核对稳压器型号、输入/输出网络与焊桥后才定电源；二极管档读数不能证明某端可接 5V。DAC 输出接 R18T 的实际 AUX/LINE IN。R18T 型号及供电本轮未独立确认，不接无源喇叭，不从 3V3 排针取大电流。

## 时钟、资源与功能可行性

| 路线 | 已有证据 | 本轮判断 |
|---|---|---|
| standard27＋USB＋8 声部 | 4536e07 分支记录：Logic 11406、FF 3674、25/46 BSRAM、DSP 等效 1.75/24；27MHz 下 Fmax 38.557MHz，setup +11.102ns、hold +0.211ns，违例端点 0 | 软件与实现层面可行；数据来自另分支保存的报告，未在当前 HEAD 重建，未实测整机 |
| 12.288MHz＋PLL 73.728MHz＋32 声部 | 当前集成归档 v0.2：Logic 5361、FF 2627、26/46 BSRAM、2 个 MULT18X18、1 个 rPLL；Fmax 74.451MHz，setup/hold 违例端点 0 | 音频原型可实现；报告 Physical Constraints File 为 ---，无完整板级接线，不能烧录 |
| WS2812B＋ST7735S | 10/20 提出 E15 灯带与 6 个屏幕信号，当前 standard27 封装未引出这些输出 | 器件方案可行，尚无整机驱动/引脚实现证据，暂不能列为完成 |

32 声部采用共享/时分 ROM，并非 32 路复制两套 1024 点表。当前有 20 块 BSRAM 余量；2 个乘法器与报告的 1 个 DSP 等效资源单位是不同口径，不能混报“1 个乘法器”。最新修复后的每声部 19 周期、渲染末周期 672，含配置最坏末周期 702；73.728MHz/48kHz=1536 拍/帧，按该测试有 834 拍余量约 11.31µs，未包含未来效果和整机控制成本。

新增显示和效果仍需重新核算。128×160×16bit 全帧为 327680bit，按每块 18432bit 的容量下界需要 18 块 BSRAM，26+18=44/46，已经非常紧，实际映射还可能更高；应利用屏幕自身显存，FPGA 只保留小行缓冲和状态。全屏 15Hz 的纯像素 SPI 带宽至少 4.9152Mbit/s，再加命令开销，宜局部刷新。WS2812 的 16×24bit 在 800kbit/s 下发送约 480µs，再加所购批次规定的复位间隔，可用独立发送器，不应阻塞音频调度。AHCT125 适合 3.3V→5V 单向灯带信号，5V 输出不回 FPGA。

键盘 Boot 报告只有 6 个普通键槽位，控制键可能占槽；8/32 声部并不意味着键盘可同时报告 8/32 个琴键。11 字节 UART 帧按 115200、8N1 约需 0.955ms，另有键盘扫描/USB/FPGA/模拟滤波延迟，尚不能声明整机 ≤5ms 或 ≤10ms。32 声部可以通过独立事件序列验证，但应与用户实体和弦能力分别记录。

不建议把全部资源都填到 95% 作为装配验收条件；当前设计未达到该数值。LUT、BSRAM、乘法器的使用率分别统计，评分提升应由实际音色、控制和效果收益证明，不能用无用复制耗尽资源。

## 电源与现场验收

12V/3A 的标称输出为 36W。降压模块“3A/5A”未核对前，不把 3A 当成已保证的连续能力；须测输出、负载电流和热情况。若按 5V×3A、效率 85% 举例，12V 输入电流约 1.47A，余量还要分给 Dock 和其他负载；85% 只是预算假设。16 颗灯按每颗 60mA 保守估算为 0.96A，实际批次和限亮策略另核。灯和音箱电流各自回电源分配点，模拟参考地不承载大电流。不同稳压输出不硬并联；信号共地。

现场先核对电源与焊接，再依次接通正式 DAC、CH9350L、ADC/FSR、旋钮，最后接灯屏。每次改线断电。需留下的证据是：实际电压和极性、CH9350L 完整按下/松开/长按/拔出帧、ADC 原始码与中位、I2S 的 BCK/LRCK/24 位解码、单音和弦录音、一次冷启动。未得到实物拔出通知前保留 Esc/S3 清音，不把长按修复解释为断线识别完全解决。

烧录前按项目规则通过完整 RTL 仿真门禁，构建收据与位流 SHA256 对上，时序和引脚约束齐全。文档里的“仅定向自检”不授权跳过这一烧录前提。本轮没有改 Verilog，也没有触发烧录，无须为文档核查重跑长门禁。
