# UART与GPIO同音来源修复

原16位事件只包含开关、音高和力度，分配器合并同音后，任一来源的Note Off都会撤销gate。真实顶层测试先按UART C4，再按住GPIO C4，UART松键时重现了仍按着实体键却释音的问题，修复前自检退出1。

新增 `note_ownership` 放在事件仲裁之后、分配器之前。UART保存128个音高的持有标志，GPIO保存实际12键的标志；同音只有最后一个来源释放时才转发Note Off。Note On仍保留原有重触发语义，未修改16位事件格式、UART命令或板级接口。被消费但不转发的Note Off仍正常从FIFO弹出，不会堵塞队列。Panic和模式切换清除持有状态，演示事件直接通过而不污染手动来源记录。

独立自检通过2060个事件，包含两种松键顺序、重复Note On/Off、随机序列、清理和演示旁路。真实UART/GPIO顶层通过两种按键/释放顺序、最后释放、Panic及重武装五个情形；声部过渡顶层回归也通过，二者能共同处理待启动音符。模式/UART回归和两个真实工程的建立/展开检查通过，没有重复运行模拟下载选择测试。

实际标准配置综合为5226 Logic、2137FF、2BSRAM、1MULT18X18，相对前版增加227 Logic及140FF，没有增加音频乘法器或波表。事件不增加额外寄存流水延迟，音频调度未改。正式硬件混合演奏仍需实测；本轮未运行完整门禁、PnR或烧录。
