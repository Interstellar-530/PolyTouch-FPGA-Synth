## 至少五个可优化方向

以下 8 项是后续任务，未在本轮实现。按用户最新要求，优先级先看外设依赖：第 1—6 项现在即可在本机完成代码、仿真、数值分析或 PnR；第 7—8 项的最终结论依赖外设。32 声部放在无外设任务的最后，先稳住现有 8 声部和可复现构建。涉及架构、接口或新外设的方案实施前仍需确认。

| 执行顺序与依赖 | 方向与当前代码依据 | 建议动作与验收标准 |
|---|---|---|
| **1，立即；无外设** | **力度边界与增益位宽**：`shared_wavetable_engine.v` 的输入力度为 8 位，`key_a` 只有 15 位，乘积截为 `[14:0]`。系数 256 时力度 128 会截为 0 | 明确定义 0..127 输入并钳位，或重新核算加宽路径。遍历全部 256 个输入、键控系数和旁路，检查零点、单调性、饱和与合法范围逐位兼容；当前固定力度 100 等合法输入不触发此问题 |
| **2，立即；无外设** | **构建内容绑定与可复现生成**：`profile_helpers.ps1` / `build.ps1` 的输入检查仍以大小和时间戳为主；`gen_epiano_bank.py` 等再制表脚本含绝对工作区/临时 WAV 路径 | 在构建凭据加入源码、约束、ROM、工具版本和位流 SHA256，保留现有入库 HEX 无下载构建路径。测试等长且保留时间戳的内容变动能被识别，并让再制表脚本可显式指定来源目录；`gen_piano_prom.py` 的当前 ROM 重建能力已验证，不再列作已知缺陷 |
| **3，本地实现/仿真；无外设** | **脱机键盘控制补齐**：`hid_keymap.v` / `host_kbd_input.v` 目前提供音符、F1–F5、移调、清音，缺少 Host F6 音色切换和主音量事件 | 先用 CH9350L UART/帧模型接入现有统一控制状态，保持 UART 命令兼容。顶层仿真覆盖首键、和弦、F6、音量边界、清音；切换时不残留旧声部。本地开发不等待实体键盘，最后的实际操作确认放到外设阶段 |
| **4，仿真＋PnR；无外设** | **事件仲裁关键路径**：本次 STA 最差路径从手动 FIFO 读指针到分配器音符使能，21 级逻辑，setup 余量 4.820ns | 评估事件预取、注册化 ready/valid 与优先级计算。用满 FIFO 同拍读写、模式切换首键、Note Off、Panic 验证不丢不重，再对同一 profile 对比 PnR；不能只优化音频乘法而忽略此控制路径 |
| **5，频谱/资源评估；无外设** | **波表空间与带限配置**：实际使用 40/46 BSRAM，仅余 6 块；ROM 是声部共享的，仍需同时容纳钢琴/吉他/基础表 | 先用入库 HEX 比较音区和阶段的频谱、重建误差与资源代价，再决定删减、压缩或复用。保持 Gowin BSRAM ROM，逐次记录块数；添加合唱/显示/更多音色前同时核算 RAM 与 18×18/36×18 运算资源。实际模拟输出听感留到外设阶段，不阻塞本地筛选 |
| **6，完整原型仿真；无外设** | **32 声部的完整调度与精度预算**：生产共享引擎仍是 4/8 路，32/64 路 RAM 核心是独立原型；本次还有一个 MULTALU36X18 | 第 1—5 项收敛后，在完整事件、ADSR、窃声和重按路径中做周期预算，再评估额外流水或独立乘法。验收最坏 32 路在每帧期限内完成、音高不串路、松键/窃声正确，且完整顶层资源和时序通过；不能只改 `VOICES` 参数 |
| **7，需 CH9350L 实物帧定案** | **长按与断线策略**：`host_kbd_input` 默认 `WATCHDOG_MS=2000`，解析器超时会清音；若实际 CH9350L 长按时不周期发帧，可能误清长音 | 现在可先准备“有周期心跳/无事件静默/拔线”模型及可配置策略；实体模块到位后捕获真实长按、空闲、拔线帧再确定默认策略。验收长按至少 10 秒不误释放，真实断线能按约定恢复；该风险是条件推断，本轮未作实物复现 |
| **8，需触摸/压力/音频外设** | **完整自研交互与延迟证据**：当前生产顶层输入是 GPIO/UART/HID，MPR121 尚未集成；FSR 使用预设 ADC 标定常数 | 现在可先准备 MPR121 接口与仿真模型；实物阶段按最低要求接入 12 路触摸，完成压力标定，测实际音频起点延迟。逐键、和弦、松键、压力渐变、噪声和小于 10ms 目标分别留证，HID 演奏成功不能代替触摸验收 |

立即执行顺序为：力度边界 → 构建哈希/可复现性 → HID 控制仿真 → 仲裁时序 → 波表资源评估 → 32 声部完整原型。真实 CH9350L 策略定案和触摸/压力/音频整机验收在外设阶段接续。第 7—8 项的模型准备可以提前做，实物验收不能由模型结果替代。32 声部需要单独通过资源与每帧调度评审，本轮没有擅自改架构。

## 交付与边界

本地候选版本为 v2.0.1，关键归档为 `archive/FPGA-20261021-v0.1`。源码、目标调试位流、复现命令、证据、变更说明、MANIFEST 和 SHA256 一起保存。任务产生的编译、捕获空目录和故障夹具在证据保存后清理；本机运行时、Gowin/Icarus、既有工程与用户原文件保留。没有 GitHub 推送、远端分支更新、硬件烧录或未验证的完整门禁通过结论。
