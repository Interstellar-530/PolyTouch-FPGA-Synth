# 第一项：压力新采样与滤波修复

生产基线为 `c2dfdb7`。原先控制节拍为2 kHz，两路交替采集使每路新数据仅1 kHz，中值历史却推进2 kHz，一笔异常值会被重复消费。现在每500微秒先采CH1、再采CH0，整组完成后产生一个时钟宽的新数据使能，滤波只推进一次。滤波公式、板级引脚和压力音量映射保持原样。两个事务之间预留至少1微秒的CS高电平，满足MCP3208的最小间隔要求；复位同步清除组状态及间隔计数。

| 验证 | 最终结果 |
|---|---|
| 标准配置采样 | 每路2000 Hz；226组、452笔事务与独立滤波参考一致；单笔满幅异常后滤波峰值0 |
| 调试配置采样 | 同上；两种配置均检查CH1/CH0顺序、新数据使能宽度和CS高电平至少500 ns |
| 8个压力阶跃相位 | 标准配置内部VCA的90%响应最慢2839.592微秒，调试配置2868.633微秒 |
| 两种配置复位 | 各覆盖三个事务中复位相位与空闲复位，共8例，旧数据未泄漏 |
| 真实顶层压力与I2S | 压力高低响度比3.935558；固定相位内部增益响应2568.638微秒；另核对8621个I2S输出帧 |
| 标准实际综合 | Logic4348、FF1744、BSRAM2、MULT18X18为1、MULTALU36X18为0 |

六项相关仿真通过，未运行完整门禁、PnR或烧录。压力响应测量终点为内部增益，不是物理控制到模拟DAC输出；8个相位不代表连续所有相位的数学最大值。综合相对基线减少60 Logic、增加6 FF，仍保留一条音频乘法数据通路。

证据在 `evidence/2026/10/FPGA-新采样滤波-20261017-v0.1`。旧缺陷观察探针要求峰值3071，修复后不再适合作为正向验收；新 `tb_control_sampling` 断言峰值为0，并核对新采样节拍和响应。已同步加入完整门禁列表，但本轮只执行相关测试。
