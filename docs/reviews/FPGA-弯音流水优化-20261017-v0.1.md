# 弯音系数流水优化

此前弯音ADC码寄存器到共享引擎比例快照包含控制系数查表及连续移位加法，最新综合估算最差到达22.028ns、26级逻辑。为后续49.152MHz内部PLL架构留出余量，生产路径现使用三段寄存：第一段查出区间基值、斜率与小数；第二段并行计算低三位/高四位部分和；第三段合并并舍入。每拍可接受一个新ADC码，输出有效信号同样流水。原比例公式、32个区间及端点没有变化。

`pressure_bend` 新增 `PIPELINE_FINE_RATIO_ENABLE`，默认0保留旧接口时序，生产顶层设1。非默认ADC中心继续使用原映射。三段流水从输入有效沿到结果经过两个完整时钟间隔；若含等待第一个接收沿，标准12.288MHz保守不超过3拍、0.245微秒。这里没有增加控制滤波或改变压力路径。

独立参考向量由指数函数生成33个区间锚点后做整数插值，4096码正向连续、反向间断及随机更新/复位共10195次有效输出逐值正确，空闲保持和有效脉冲也检查。原解析弯音精度测试仍为最大0.032741193音分；默认/非默认中心旧公式、随机32位相位乘积及共享引擎回归通过。两个真实工程建立/展开通过，标准及调试档真实MCP3208采样/复位和整机音色回归日志保存在证据目录。

标准配置综合由5809Logic/2242FF变为5748Logic/2320FF，4BSRAM、1MULT18X18不变。相同默认10ns约束下的综合估算，最差到达从22.028降至19.958ns，逻辑级数26降至24；新最差路径为全局音色权重寄存器到主混合器共享基值寄存器。工具估计的负slack对应默认10ns分析关系，不能解释成当前12.288MHz配置的硬件失败，也不能用19.958ns直接宣称49.152MHz布线后通过。
