# 第三项优化效果审核

2026-10-21。第三项“脱机键盘控制补齐”在审核修正后通过。F6 可切换钢琴/吉他，Up/Down 每次调整 5% 主音量并限制在 0..100，UART 命令和 Esc 清音正常。本轮没有接实体键盘或烧录。

发现并直接修复了一个实际操作问题：F6 触发 `instrument_change` 后，`flush` 清空去重记录，并中止当前报告提交。同一个持键报告再次到达时，F6 会再次切换，仍按住的音符也可能重新起音。独立短测试在修改前明确失败，第二次报告已出现 `count=2 note_ons=2`，与“持键不连发”的设计不符。

修正仅调整 `hid_keymap.v` 内部清音处理：清队列和音符归属时保留最新物理按键身份，优先采用同拍报告、待处理报告或正在扫描的报告；松开后才允许再次触发。断线通知和超时仍彻底清空身份。外部接口、波表、音频计算与 UART 协议没有变化。已有顶层测试加入重复 F6 和键位重排断言；键盘链路测试补充普通清音后的持键抑制和松开重按，门禁注释同步更正为 Up/Down。

| 检查项 | 实际结果 |
|---|---|
| 独立复现与修复 | 修改前重复 F6 报告触发失败；修改后重复、重排、松开重按、方向键持键、清音后持键抑制和设备通知后重按均通过 |
| `tb_top_host_ctrl` | 真实 CH9350L state-2 串行帧驱动顶层，首键、和弦、F6 双向切换及重复报告、音量步长与 0/100 边界、斜坡到零、UART 共存、Esc 清音通过 |
| `tb_host_kbd` | 既有链路检查及新增普通清音后持键检查通过 |
| 构建内容绑定 | 222 个输入与成功凭据逐个内容一致，输入摘要、位流 SHA256、工具版本与报告一致 |
| 新构建资源 | Logic 11537，寄存器 3689，BSRAM 40/46，DSP 1.75/24 |
| 新构建时序 | 27MHz 约束下 Fmax 31.938MHz，setup +5.727ns、hold +0.319ns，负裕量端点均为 0 |

相对第三项原实现，修正增加 195 个 Logic，寄存器、BSRAM 和 DSP 不变。满足当前器件和时序约束；本次布局布线的时序结果更好，不据此宣称关键路径已经优化，第四项分配器路径优化仍有价值。

验证采用三个相关短测试和一次修正后的 `debug8usb` 构建，没有重复完整长门禁，也未重跑此前无关的历史失败台。`debug8usb` 为 PT8211 调试档，正式 `standard27` I2S 档本轮未做 PnR，实体键盘与整机听音留待外设接通后确认。
