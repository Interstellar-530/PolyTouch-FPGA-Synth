# 多声部宽乘法通路

为已批准的双通路24位内部架构增加 `split_audio_multiplier`，支持19–35位有符号样本/频率字乘18位有符号控制量。低18位按无符号乘，高位按有符号乘，精确重建 `low_product + (high_product << 18)`；输出无舍入。两个乘法同时完成一个寄存沿，CE关闭保持，复位同步清零。每路占两个18×18，后续两路共四个，满足已授权上限。

实现显式实例化高云MULT18X18，使用ASIGN分别指定低位无符号和高位有符号、BSIGN指定控制量符号，OUT_REG=1。原始推断实现虽然数值正确，综合却生成一个MULT18X18加一个MULTADDALU18X18，等效1.5个DSP宏，超出每路一个宏的预算，已放弃。资源解析器现计入MULTADDALU18X18、MULT36X36和ALU54D，避免后续只看普通乘法器数量漏计。超预算报告保存在inferred-before。

同一测试以24、33、35位分别运行32768个事件，每种模型共98304次宽乘积检查，覆盖全符号极值、低18位符号边界、正负控制、空闲保持和随机复位。纯RTL仿真与本机Gowin GW2A厂商模型各自对独立64位整数乘法参考逐值通过，实际原语没有借用便携模型。厂商源码作为本机工具依赖只读调用，没有复制进仓库。

孤立综合24位和33位通路均为**两个MULT18X18、零BSRAM、零额外DSP算术宏**。包围单元的输入/输出寄存器用于建立寄存器间路径，连同这层测试外壳分别为24Logic/84FF和33Logic/102FF。报告中的3.345/3.662ns路径为原语输出到外层输出寄存器的重建路径，不代表整个DSP内部时序、生产架构或49.152MHz布局布线已经通过。
