# CH9350L 代码核对

2026-10-26，核对当前 codex/v2.1.1-integration-20261022 工作区。结论：项目当前 standard27 所需的 CH9350L 下位机、state 2、115200/8N1、单向 USB 键盘输入代码已经接通，可以提交和推送。这里的完成是代码实现和 RTL 自检通过，不代表实体模块、供电、键盘兼容性或模拟音频已经验收。本轮未修改生产 RTL，没有重新构建或烧录。

## 实现与连接

| 环节 | 实现位置与核对结果 |
|---|---|
| UART | rtl/audio/kbd_uart_rx.v：输入同步、起始位确认、8 位数据、停止位检查，27MHz 下分频 234 |
| 协议 | rtl/audio/ch9350_rx.v：解析 57 AB 01 加 8 字节 Boot 报告，检查 reserved 字节；跳过已知非键盘帧，截断 payload 超时重同步 |
| 键位 | rtl/audio/hid_keymap.v：双排 24 个音符键、按下/松开差分、重复报告去重、和弦、原音高松键、PageUp/PageDown 移调 |
| 控制 | F1—F5 为 T250—T254，F6 切钢琴/吉他，方向键上下每次调 5% 音量，Esc 清音 |
| 长按 | rtl/audio/host_kbd_input.v：默认 IdleOnly，持键期间不会因 2 秒静默而误清音；Strict 保留为显式兼容选项 |
| 顶层 | rtl/top.v：键盘事件进入手动 FIFO、首键退出演示、音色/音量/清音接入；原电脑串口仍可使用 |
| 生产入口 | build/isolated/top_std27_build.v：GPIO_KEY_ENABLE=0、HOST_KBD_ENABLE=1、TIMEOUT_POLICY 默认 1 |
| 引脚 | constraints/primer20k_i2s_27m.cst：L9 为 kbd_uart_rx，N8 为预留恒高输出；单向安装时模块 TXD 接 L9、模块 RXD 接地、N8 留空 |

代码协议与 [WCH 署名 CH9350L V2.3 手册](https://wiki.kamamilabs.com/images/b/bf/CH9350DS.pdf)的 state 2 键盘帧一致。本项目已有完整 RTL 接入，本轮检索到的第三方串口工具只作参考，未引入外部实现或新增依赖。

## 本轮验证

Host 三项全部通过，用时 56.92 秒：tb_host_kbd 覆盖按下/松开、去重、和弦、移调后松键、Esc、F1、截断帧恢复、rollover、FIFO 回绕和清除；tb_host_kbd_timeout 对照 IdleOnly 与 Strict，覆盖心跳、持键、超时和模拟 0x86 通知恢复；tb_top_host_ctrl 通过 UART 线输入验证原串口兼容、首键、和弦、F6、上下音量钳位和清音。

Quick 十九项全部通过，用时 63.83 秒，包含十三项正向检查和六项预期失败的 I2S 参数负例。上述 Host 三项也包含在 Quick 中，不能相加当成二十二个独立测试。长按测试本轮采用 100ms 持键、20ms 测试 watchdog，跨越至少三个测试超时窗口；生产 watchdog 保持 2000ms。本轮没有运行 Full 历史回归。

另做曲目时序和背压两项检查，全部通过；song_data.py 自检通过。当前曲目数据是 140 个旋律条目、320 个十六分槽，实际旋律发音 136 项，加和弦每遍共 256 个 note-on。本轮测试结果没有发现运行期间输入文件变化。原始日志及输入 SHA256 在 docs/evidence/FPGA-ch9350-code-review-20261026-v0.1。

## 使用边界

本版采用 Boot 键盘报告，最多六个普通键槽位，控制键也可能占槽；不是 NKRO 或 32 键同时输入。当前映射以两排 24 个音符键为准：源码注释提到的电脑 GUI A/F/K 旧别名并未在 HID key_offset/is_note_key 中实现，不计入本版 USB 键盘支持范围。

单向方案没有实现 FPGA 到 CH9350L 的键盘灯状态回传或握手，不需要接 N8。收到模拟 0x86 会清键，但手册将该通知标为 state 1 命令，不能把自检中的注入等同于 state 2 实物必然发送。IdleOnly 为避免长按误清音，在持键断电且没有通知时可能保留声音，可用 Esc 或 S3 清除；模块恢复后仍需实际按下/松开和重新插拔验收。

代码层面检查通过，实体模块 TXD 电平、Host 5V、实际帧、按键兼容、持键拔出恢复和声音听感尚未实测。独立 32 声部核心、灯屏等其他工作继续按各自状态文档管理，本次核对不把它们升级成整机已完成。
