# FPGA-20261012-v0.1 共享审查包

这是 2026-10-12 项目审查的 GitHub 交付副本。主报告记录 GitHub 进度、串口实测、ADSR 缺陷、资源账与月底方案；Excel 是 30 项外设/板载资源复查清单；[零外设任务](零外设可执行任务-20261012.md)按今天确认的板卡、USB 串口和到货状态更新了执行顺序。

本包附上可复查的原仿真门禁日志、ADSR 失败回归、PnR 资源报告、UART 协议回执及表格源数据。`tb_adsr_release_audit.v` 是针对现有缺陷的自检测试，当前基线运行**预期失败**。生产 RTL、约束、编程脚本和板上 Flash 都未因本次审查改变。不要把报告中的 32 声部预算当成已实现的资源用量。

本地完整归档仍在 `archive/FPGA-20261012-v0.1`（该目录按仓库 `.gitignore` 规则保留在本机），包含更多 PDF/USB 原始证据和隔离构建码流。隔离码流带有已知 ADSR 缺陷，**禁止用作交付烧录**；共享包不包含它，也不包含本机 USB 设备标识。复现方法见 [REPRODUCE.md](REPRODUCE.md)，文件清单和 SHA256 见 [MANIFEST.md](MANIFEST.md) 与 `checksums.sha256`。
