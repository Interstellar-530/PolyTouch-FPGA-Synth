# 硬件控制信号

## 1. 模块目标

定义 Dock 3714 上最低实现所需的外部器件连接、FPGA 引脚约束、I/O 电平、初始化顺序、复位/静音控制和构建配置，确保方案只使用板卡实际提供的资源，不把 3.3 V 外设接到 1.5 V Bank，也不占用已用于 DDR3 的引脚。

## 2. 算法逻辑

上电顺序是：外部 12.288 MHz 稳定 → FPGA 内部 1 ms 复位释放 → MPR121 复位和 I2C 初始化 → MCP3208 空读两次 → PCM5102A 时钟稳定后释放 XSMT → 板载 PA_EN 延迟拉高 → `init_done` 置位。在 `init_done` 之前，I2S 和 PT8211 数据都发送 0，避免上电爆音和随机噪声。

I2C 使用开漏 SCL/SDA，外部 4.7 kΩ 上拉到 3.3 V，MPR121 常用 7 位地址 0x5A，具体以模块 ADDR 跳线为准。SPI 的 MCP3208 使用 mode 0、0，SCK 约 1 MHz，CS 低有效，VREF 和 VDD 统一接 3.3 V，最低实现只用通道 0 采 FSR，其余通道保持悬空或接地。PCM5102A 的 FMT 脚按模块说明选择标准 I2S，FLT 脚可选低延迟滤波，XSMT 用于软静音，DEMP 在 48 kHz 下按模块默认关闭；PT8211 固定使用 `HP_BCK=N15`、`HP_WS=P16`、`HP_DIN=P15`、`PA_EN=R16`，右对齐 16 位格式，BCK 1.536 MHz。

3714 的固定音频网络和按键网络已经确认：Dock 3714 相对 3713 主要变化是 DVI 优化以及 SW0 与 KEY4 互换。设计里不要把 SW0/KEY4 用作上电模式选择；最低实现只使用 5 位拨码开关中的 1 位作为测试模式，其他按键不作为关键控制。I2C、SPI、外部时钟和 I2S 全部走 PMOD 或焊接排针，避免与 HDMI/Ethernet/RGB LCD 的 3714 网络冲突。

## 3. 例程参考

Sipeed `PT8211/src/pinmap.cst` 和根 README 的 “Audio DAC” 引脚表是板载音频连接的直接参考；`UART`、`WS2812` 和 `Lite-bottom_test_project` 是串口、板载灯和按键的参考。高云 SUG935 是 CST 物理约束手册，SUG940 是 SDC 时序约束手册，SUG284 是 IP Core Generator 手册，UG289 是可编程 IO 手册，UG285 是 BSRAM 手册，SUG100 是云源软件用户指南，SUG114 是 GAO 在线逻辑分析仪手册。外部器件依次参考 PCM5102A、PT8211、MPR121 和 MCP3208 数据手册。Dock 3714 原理图页面 `P003_Audio`、`P007_Things`、`P006_LCD`、`P004_HDMI`、`P005_Ethernet` 用于确认引脚占用；Sipeed 下载站的 3709 点位图不能直接当作 3714 点位图使用。

## 4. 函数解释

建议实现 `power_on_reset()` 产生约 1 ms 复位，`init_sequencer()` 产生 MPR121 复位和 PCM5102A XSMT 时序，`i2c_open_drain()` 控制 SCL/SDA 的三态输出，`spi_cs_gen()` 产生 MCP3208 片选，`i2s_tx()` 产生标准 I2S，`pt8211_tx()` 产生右对齐调试数据，`pa_enable()` 延迟拉高 PA_EN，`status_leds()` 显示 `init_done/touch_ok/adc_ok/clip`。CST 模板示例：

```tcl
IO_LOC "clk_12m288" <GCLK_PIN>;
IO_PORT "clk_12m288" IO_TYPE=LVCMOS33;
IO_LOC "i2c_scl" <PMOD_PIN_A>;
IO_PORT "i2c_scl" IO_TYPE=LVCMOS33, DRIVE=8, OPEN_DRAIN=ON;
IO_LOC "i2c_sda" <PMOD_PIN_B>;
IO_PORT "i2c_sda" IO_TYPE=LVCMOS33, DRIVE=8, OPEN_DRAIN=ON;
IO_LOC "i2s_bck" <PMOD_PIN_C>;
IO_PORT "i2s_bck" IO_TYPE=LVCMOS33, DRIVE=8, SLEW_RATE=SLOW;
```

SDC 最小模板：

```tcl
create_clock -name clk_12m288 -period 81.38 [get_ports {clk_12m288}]
set_clock_groups -asynchronous -group {clk_12m288}
```

工程设备配置必须选择 `GW2A-LV18PG256C8/I7`、器件版本 `C`，本机 Gowin Education V1.9.11.03 已经用这个参数完成过最小工程的综合、布局布线和 `.fs` 生成。波表用 IP Core Generator 生成 ROM，综合后检查 `.rpt` 中的 BSRAM、DSP、LUT、FF 和时序是否满足最低实现预算。

## 5. 后续优化方向

后续建议做一块 PMOD 转接小板，把 MPR121、MCP3208、PCM5102A 和 12.288 MHz 晶振固定焊接，减少杜邦线带来的接触不良和串扰；在 I2S 和 SPI 线上加 22～33 Ω 串联电阻，I2C 保留 4.7 kΩ 上拉，PMOD 加 ESD 保护。可以增加一个专用音频时钟发生器同时输出 12.288/24.576 MHz，为未来 96 kHz 预留，但赛题不因过采样加分，最低实现仍保持 48 kHz。可以加入硬件模拟静音开关或继电器，进一步消除上电/掉电爆音。若以后必须使用 1.5 V Bank，必须加电平转换，不能直接把 3.3 V 外设接上去。

## 6. 最小验收

所有引脚与 3714 原理图逐一核对，Bank 电压确认 3.3 V；I2C 能读到 MPR121 设备，SPI 能读到 MCP3208 12 位原始值，I2S 的 BCK/LRCK/DIN 有正确波形且 PCM5102A 能发声；PA_EN 上电顺序不产生明显爆音；综合报告显示 BSRAM 不超过 6 块、DSP 不超过 5 个、LUT 和 FF 有充足余量；断电重启 20 次都能进入 `init_done`。

## 7. PCM5102A 模块配置与电源

常见 PCM5102A 模块自带 3.3 V 稳压、FMT/FLT/DEMP/XSMT 跳线和 RC 输出滤波。最低实现只需确认三件事：FMT 选择标准 I2S；FLT 选择低延迟或普通滤波，二者都能满足 10 ms 延迟；XSMT 由 FPGA 或模块上拉控制，上电时先静音再释放。模块的 VIN 若支持 5 V，内部稳压输出 3.3 V 时，I2S 逻辑电平仍需确认是 3.3 V；若模块只支持 3.3 V，就从 Dock 的 3.3 V 取电并与 FPGA 共地。输出接有源音箱或有源功放，不要直接把 PCM5102A 线路输出接无源扬声器。12.288 MHz 有源晶振用 3.3 V 供电，电源脚旁放 100 nF 和 1 µF 去耦，输出串 22～100 Ω 电阻后再进 GCLK 脚。

## 8. 3714 引脚候选与待确认项

| 功能 | 已知/候选 FPGA 引脚 | 结论 |
| --- | --- | --- |
| 板载 27 MHz | H11（Bank 0，GCLKT_0） | 已知，仅作调试/近似时钟 |
| 板载 PT8211 | HP_BCK=N15、HP_WS=P16、HP_DIN=P15、PA_EN=R16 | 3714 原理图固定 |
| UART | TX=M11、RX=T13 | 官方 Dock 约束 |
| 复位 | T10 | 官方 Dock 约束 |
| 外部 12.288 MHz | A9/C9（Bank 7，3.3 V）或 K14/K15（Bank 1，3.3 V） | 3714 原理图显示已用于 Ethernet/HDMI，需确认 PMOD 是否并联引出 |
| PMOD I2C/SPI/I2S | 从 3714 原理图 SODIMM 引脚表选择 3.3 V Bank 的空闲脚 | 实物到手后用万用表确认连通性 |

如果 PMOD 没有引出空闲 GCLK 脚，最低实现不能直接进入标准 I2S 版本。此时优先保留 4 声部 DDS、ADSR 和混音逻辑，先把音频出口切换到板载 PT8211 做算法验证；标准 I2S 引脚问题解决后再恢复 PCM5102A 输出。不要为了赶进度把 3.3 V 外设接到 1.5 V DDR3 Bank，也不要把 BL702 当作音频控制器。
