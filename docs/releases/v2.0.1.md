# PolyTouch v2.0.1 早期候选记录

日期：2026-10-21。基线为 `2d3db6c1700e6628341965af5bdee70d8134c526`。本轮 `git fetch origin --tags` 后，GitHub `main` 与该基线相同，吉他/USB 分支最新推送已经合入，不存在新的前向提交需要再次合并。本版是既有合流的验证入口修正版，尚未提交、打标签或推送。

保留 v2.0.0 的功能组合：远端贡献的 `debug8usb`、演示模式松键消费、精确静音和亮表顺序修复；本线的 8 声部、电钢琴/吉他、键控响度、24 位公共低通和主 VCA。其他两条旧分支有 6 个提交尚未进入本地提交历史；其中 ADC、混音、波表与大多数测试内容已通过后续源码整合保留，未机械合并旧顶层与归档。

实际代码增量只有 `source/sim/run_simulation.ps1`：缺失任一注册测试台或 I2S 参数负例台时立即退出 1；把已有 `tb_engine8_pitch`、`tb_top_pitch8`、`tb_top_switch`、`tb_top_guitar`、`tb_guitar_bank` 纳入门禁；显式跳过音频捕获时不再输出完整门禁许可。没有修改生产 RTL、约束、引脚、数据格式或公共接口。回退可反向应用归档中的跟踪文件补丁，或从上述基线恢复门禁脚本和入口说明。

本轮发现并更正两处说明：`debug8usb` 封装使用 `AUDIO_IF=0`，输出为 PT8211；`standard27` 才是 PCM5102A 标准 I2S 档。`gen_piano_prom.py` 可直接从入库 HEX 重建 ROM，除首行来源注释外与入库 Verilog 相同。

本轮实际通过 9 个原始定向台：`tb_key_gain`、`tb_host_kbd`、`tb_top_pitch8`、`tb_engine8_pitch`、`tb_mute_slew`、`tb_wide_master`、`tb_piano_bank`、`tb_bright_banks`、`tb_guitar_bank`；另通过短窗口 `tb_top_switch`（三处等待 1500 帧改为 16 帧，原断言与真实 UART 保留）、两档顶层展开、缺失台拒绝通过负例与 ROM 重建。原 `tb_top_switch` 达 60 秒限时后停止；短窗口结果只证明切换控制，不能替代长时间音频验收。按用户要求中止完整门禁，未宣称其通过。

`debug8usb` 使用 Gowin V1.9.11.03 Education 完成综合、PnR 和位流生成：Logic 11379/20736，寄存器 3686/16173，BSRAM 40/46，DSP 1.75/24（MULT18X18、MULT9X9、MULTALU36X18 各 1）。27MHz 约束下 Fmax 31.039MHz，最差 setup +4.820ns、hold +0.214ns，建立/保持负裕量端点均为零。位流 7,264,154 字节，SHA256 `1C82DECA9630547F7BD9DFF4C8DFB8AF7CCFC25322D091134457F8E48A7FC0F1`。`standard27` 本轮只编译展开，不能引用此处的调试档资源作为其本次实测结果。

位流没有烧录，长音、模拟听感、实体 CH9350L/FSR/PCM5102A、端到端延迟与冷启动未验证。完整门禁仍是以后烧录脚本的默认前置步骤。本轮没有跳过烧录门禁或修改硬件。

差异与后续 8 个优化方向见 [复核报告](../reviews/FPGA-Git差异与优化方向-20261021-v0.1.md)。按最新要求，先安排不依赖外设的力度边界、构建哈希、HID 控制仿真、仲裁时序、波表评估和 32 声部原型；实体长按/断线策略与触摸/压力/音频验收后置。复现和日志见 [证据入口](../evidence/FPGA-合流复核-20261021-v0.1/README.md)。交付归档为 `archive/FPGA-20261021-v0.1`，包含源码快照、调试位流、命令、证据、变更说明、MANIFEST 与 SHA256。
