# FSR 持续按压断触修复

本文保留当天早期2/40样本确认方案的过程记录。最终版本已改为独立快速中值判定与2/6确认，并补充IdleOnly误清音修复、完成Flash写入；以[快速更新说明](FPGA-延音踏板快速更新-20261030-v0.1.md)和[每日发布包](../../releases/FPGA-20261030-v0.1/README.md)为准。

当前 32 声部路径中，FSR 是手动延音踏板。用户反馈持续按压时偶尔断开。检查发现 `fsr_mute` 原来只做 512/256 ADC 阈值回差；滤波压力有一次低于松开阈值就撤销踏板，`sustain_pedal` 随即补发此前暂存的 Note Off。短时掉压因此可能造成无法追回的释音。尚未采集现场 ADC 曲线，不能据此认定接线、供电、传感器状态或 ADC 是唯一根因。

本次保留现有阈值与中值/IIR 滤波，在 `instrument32_top` 的踏板检测实例中启用 2 个连续高值样本确认按下、40 个连续低值样本确认松开。ADC 配对采样率为 2 kHz，确认窗口约为 1 ms 和 20 ms。只有新样本 `update` 才推进计数；松开计数期间压力恢复到 256 以上就清零，避免多个不连续低谷累积成松开。完整物理动作至状态变化还包含原有滤波和采样对齐延迟，因此实际响应略长于确认窗口。

没有改变 ADC SPI 时序、弯音映射、声部、波表和音频运算。模块新增参数默认均为 1，历史 4/8 声部消音路径维持原行为；32 声部实例明确启用新的确认时间。所增逻辑为一位按下计数器和六位松开计数器，不增加 BSRAM 或乘法器，实际逻辑资源与时序仍需后续实现报告确认。

自检新增 `tb_fsr_sustain` 并纳入 Quick/Full：覆盖阈值边界、连续计数边界、回差区恢复、暂停更新、禁用/复位，以及真实压力滤波接延音模块后的 12 次 5 ms 掉压与一次真正松开。测试用 `$fatal` 自检。另以旧的一次低值松开行为做负面对照，同一测试能触发 `FSR_DROPOUT_RELEASED_NOTE`，证明测试能够识别这类缺陷。生产顶层测试加入 ADC 模型产生的 5 ms 低值和恢复，最后检查真正松开能释放目标音符；等待时间和测试超时按新增确认窗口调整。

验证结果：三项FSR定向自检通过。Quick在17台通过后因未改动的演示曲五声音阶断言失败停止；单独运行的32声部顶层仿真达到180秒主机时限，未取得通过证据。按用户要求不追加不必要门禁，未宣称整套Quick通过。

本次不直接烧录。软件自检只能验证设定的短时低谷场景；若现场连续低值超过窗口仍会被判为真实松开。后续按常规门禁构建、下载 SRAM 后，应连续按压 FSR、轻压与松开反复试听，并观察踏板标识。如果仍断触，读取压力原始值及滤波值，再定位传感器受力、接触、电源与 ADC 输入电路。

复现、证据和回退源码归档于 `archive/FPGA-20261030-v0.2`；该归档编号接续同日流程图归档，不表示软件发布版本号。外部核查参考 [Microchip MCP3208 官方资料入口](https://www.microchip.com/en-us/product/mcp3208)。已检索同类开源实现，本修复复用项目已有滤波/回差模块，未引入外部代码或依赖。
