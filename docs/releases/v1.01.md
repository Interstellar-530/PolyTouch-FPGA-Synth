# PolyTouch v1.01：真实音频验证与 Flash 固件

按用户指定使用标签 `v1.01`。本版把已完成的 S1 验证工程收录为正式版本：真实顶层音频捕获、独立 PT8211 串行解码、PCM/WAV/FFT 分析、八个错误样例自检，以及包含新增测试的十项 RTL 门禁。生产 RTL、约束及 ROM 资产共16项与 v1.0.0 一致；板内 User Code 仍为 `0x5633`，音频仍是四声部、单512点正弦表、46.875kHz板载PT8211路径。S2 GPIO琴键、压力ADC、外置标准I2S及双音色没有在本版实现。

固件直接沿用 [v1.0.0 原始位流](../../releases/v1.0.0/instrument_sram_0x5633.fs)，SHA256为 `2C7C7001DD3EABF24D2A4ABC2FC93BE1DD441D76812E248B3B84A235DBD22675`。同一文件可写 SRAM 或外部 Flash；本次按用户要求写 Flash。Git 版本号描述代码、工具和文档的发布，器件 User Code 对应位流校验值，因此增加验证工具不会改变读码。不为更改版本号重新综合或修改生产逻辑。

## 增量与证据

新增 `tb_audio_capture` 使用真实27MHz时钟，通过UART引脚发命令，从BCK/WS/DIN独立解码数据。它检查采样使能单周期、每帧576时钟、每声道16位、左右一致及声部状态；不强制加速sample_tick，也不用发送器位计数器解码。完整捕获58880个立体声帧，A4稳态32768点，其余频谱窗口4096点；逐段PCM/WAV格式、全部释放/静音严格为零及M1恢复均验收。

S1首次验收得到 A4 约439.9999747Hz，误差小于1Hz；四个不同基频随逐个松键消失，保留音持续发声。频率先经Hann窗FFT定位，再对原始时域样本作连续最小二乘细化；FFT原始频点间隔1.430511Hz，结果只描述理想RTL数字采样。八个反例全部拒绝，包括偏音、丢声部、松键无效、静音非零和缺帧。[详细验收](../evidence/FPGA-S1-音频验收-20261014-v0.1.md)、[源数据绑定摘要](v1.01-validation.json)。

Flash采用Gowin Programmer操作37 `exFlash Erase,Program,Verify thru GAO-Bridge`，地址0、2.5MHz。前一轮完整写入/校验通过，重载和用户彻底断电验收得到 `0x5633/0x6020`；普通操作9曾校验失败，不能只凭退出码0判断成功。本次发布后的再次烧录结果保存到GitHub Release证据附件及本机归档，按实际日志记录；发布源码中的历史日志不冒充后一次结果。[Flash记录](../logs/FPGA_DEBUG_LOG_20261014_V1_FLASH.md)

## 复现

安装Icarus并按 [S1说明](../../tools/audio_capture/README.md) 配置独立Python运行时。Windows PowerShell 5.1在仓库根执行；选用一个没有旧日志的新输出目录。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/run_audio_verification.ps1 -OutputDir tmp/v1.01-verification
if ($LASTEXITCODE -ne 0) { throw 'RTL or S1 verification failed' }
```

可通过 `-Python/-Iverilog/-Vvp` 指定本机路径。普通RTL门禁只依赖Icarus/PowerShell；完整S1还需要NumPy/Matplotlib，均仅在电脑上离线运行。构建工具支持 `python tools/build_release_package.py --ref v1.01 --release v1.01 --output PolyTouch-v1.01.zip`，从已固定Git对象导出，逐文件核对SHA256和ZIP CRC，避免打包运行时及缓存。

## 使用与限制

电脑演奏、ASCII协议和操作方法沿用 [v1.0.0说明](v1.0.0.md)：115200 8N1，`D0`手动等待，`D1`重启演示，`N/O`按下/松开，`M0/M1`数字静音/恢复。耳机输出底噪和物理响应需另行实测，不能由仿真PASS认定改善。四音的4096帧窗口中有11个样本触及满幅，混音增益与削波处理仍在S6待办。

回退代码可检出v1.0.0；生产位流本来相同，用户演奏行为不会因此改变。回退到更旧Flash程序需要经完整门禁后主动重写归档位流，断电不会自动回退。烧录后保留原电脑演奏窗口的使用方式；新外设及S2须另行授权开始。
