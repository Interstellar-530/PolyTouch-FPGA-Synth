# USB 键盘 F7 切换演奏模式

通过 CH9350L 接入的 USB 键盘现在用 F7 切换手动弹奏与自动演奏。上电仍自动演奏；按一次 F7 停止自动曲目并进入手动，按音符键演奏；再按一次 F7 清除手动音符，并从头播放自动曲目。自动演奏中直接按新的音符键，仍会进入手动。

F7 必须松开后重新按下才会再次切换。模块重复上传同一报告、长按或报告中的键位槽顺序变化都不会反复切换。F7 与音符同帧时优先切换模式；同帧已经按住的音符会被清除并抑制，松开重按后才会发声。F6、上下音量、Esc、移调和原 UART D0/D1 继续有效。

## 修改依据与范围

hid_keymap 在完整 Boot 报告入口识别 HID 0x40（F7），早于逐键扫描，避免同帧音符先退出自动后又被 F7 反向切回。新增内部 mode_toggle 脉冲，经 host_kbd_input 接入 top，复用原 D0/D1 模式状态、清队列、清声部和播放器重启逻辑。顶层外部端口、引脚和 16 位音符事件格式没有改变，也不需要额外接线。

F7 编码对照 [Microchip HID 键码表](https://onlinedocs.microchip.com/oxy/GUID-49CD424A-D8EB-4F60-95E5-12E07036AA34-en-US-4/GUID-70C4159D-8412-4C45-A6F8-9824A327EF6E.html)与 USB HID Keyboard/Keypad 用法表。现有项目已有模式实现，本轮没有引入外部代码或新依赖。

只增加报告比较和控制寄存器；没有新增声部、波表、BSRAM ROM 或乘法运算。尚未重新综合/PnR，不把结构上的资源判断当作新的实现资源报告。本轮没有重新生成或烧录位流，板上 Flash 仍是此前 0x000063DC，不含 F7 新功能。

## 验证与回退

先新增 tb_top_host_ctrl 的 F7 断言，在旧 RTL 上得到预期失败：F7 did not enter manual mode。实现后该台通过；使用 AUDIO_IF=2、27MHz、真实 115200 串口，只有测试曲单位缩短为 32 个采样。覆盖双向切换、重复报告、槽位重排、同帧 Q/F7、最后槽位 F7、旧音符清除、重新起音和音符键接管自动，并保留原 F6、音量、Esc、串口和模拟拔出通知断言。自动播放检查的是声部事件，没有声称测到模拟输出。

另外验证 tb_host_kbd、tb_host_kbd_timeout、tb_mode_uart、tb_gpio_top，核对原键位、长按策略、D0/D1、旧 GPIO 模式路径。完整结果在 docs/evidence/FPGA-keyboard-mode-20261026-v0.1；失败必须由 $fatal 产生非零退出。本轮不运行 Full 历史回归。

共享工作区的曲目文件在初次验证后发生了其他修改，初次通过结果不作为最终整版源码绑定。最终交付采用已提交的 b15ff7c 基线，加本次四个功能/测试文件的固定快照；五项测试在快照中复验，结果以 frozen/gate-result.json 为准。原工作区曲目修改保留，不纳入本次功能补丁。
