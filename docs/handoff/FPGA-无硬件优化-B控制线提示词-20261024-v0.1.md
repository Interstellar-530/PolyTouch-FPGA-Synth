# B 控制线执行提示词

你负责本项目无硬件优化的 B 线。先阅读 `docs/planning/FPGA-无硬件双人并行优化清单-20261024-v0.1.md` 和适用 AGENTS。团队目前不能做实体立体声/可视化核验，没有测量设备。全部交付使用 Icarus、Python 和行为模型验收，不以连接板卡为前提。

先向主集成人确认共同基线和接口约定，再执行 B1 调度事件确定性、B2 表情数值优化、B3 纯 HDL 自动演奏/32音测试模式。B4 一键数字核查贯穿开发，复用已有脚本，不搭新平台。当前 32 声部完整控制与主要流水优化已实现，不重复开发这些功能。

你拥有 `voice_sched32.v`、`ram32_control_front.v`、`pressure_bend.v`、`bend_ratio_pipeline.v` 与新增 `S/rtl/control_ext/`。A 的音频引擎、ROM/HEX/元数据、wide_master、顶层、build、constraints、公共 run_simulation.ps1 对你只读。新增测试与脚本分别放 `S/sim/opt_b/`、`tools/offline_opt/b/`，证据放 `docs/evidence/offline-opt/B/`，临时内容放 `tmp/offline-opt-b/`。

冻结现有事件与 cfg 宽度和语义、bank 编号与同步 ROM 延迟。用一个可施加背压的配置接收模型开发，对每个已接受事件维护独立预期状态；不用等 A 的改动。不得覆盖等待中的 Note Off，不得靠停止包络或表阶段更新减少配置写入。持续弯音/压力不得重起 ADSR，跨域继续整束快照。接口、bank 编码和公共语义的变更先协商。

压力/弯音先用边界、全 ADC 范围、阶跃/斜坡/尖峰和固定种子模型核对；已有中值/IIR只在明确收益时修改。无实测 FSR 数据时参数化，不冒充实物标定。自动演奏只存事件、实时合成音频，支持四音/32音和逐个释放；CH9350L 当前只有六个普通键码槽，不把实体32键齐按当作验证方法。

参考计算独立于被测 RTL，检查器注入错符号、丢样、双拍tick、错ROM后必须失败。新增测试在登记公共门禁前用本目录独立runner，提供给 A 精确源文件清单和执行命令；不要直接修改公共注册表。声称模型音频或RTL解码音频时标明来源，电脑试听可选，不需要外接音频设备。

每项小批交付代码、参考、短自检、结果和回退说明。主线不做立体声、显示或硬件FFT。P0收口后才考虑独立第三维或琶音器。结尾给出完成内容、证据、清理和限制，按项目规则归档及生成SHA256。
