# 延音踏板快速更新

2026-10-30，按用户“小于5ms更新”的要求，32声部顶层将踏板状态判定从中值/IIR平滑通路分离。新增 `fsr_pedal_conditioner` 使用原始压力采样的三点中值、512/256回差阈值和按下2点/松开6点连续确认，仅新样本推进。原有 `pressure_bend` 的IIR用于平滑显示，原 `fsr_mute` 默认接口和历史行为保持。

真实2kHz更新节拍下，24组阈值、压力幅值与相位测试中，按下最长约1.5ms、松开最长约3.5ms。7项定向RTL自检与真实ADC/32声部顶层附加验证均通过，共8项；顶层包含从压力输入切换到踏板状态释放小于5ms的断言。算法验证阶段未执行完整Quick/Full；随后已构建并完成SRAM及Flash写入校验、重载标识核对，User Code为0x00002626，详见[Flash记录](../logs/2026/10/FPGA_FLASH_FAST_PEDAL_20261030.md)。

本版覆盖2ms短掉压保持，持续5ms低值按松开处理。小于5ms指踏板状态更新；ADSR自然余音和实际模拟声音的整机延迟需另行测量。IdleOnly空闲超时保持音乐状态、明确断开及紧急清音保护沿用当天修复。
