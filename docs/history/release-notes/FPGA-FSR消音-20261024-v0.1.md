# FSR 改为按住消音

本次按用户“FSR 改为延音或消音中的一个”的要求选择消音。按住 FSR 时静音，松开时恢复声音，演示曲和手动演奏都有效。曲目、相位和包络在静音时继续运行，不暂停播放或重新触发音符。电位器保持原先的全局 ±2 半音弯音，原串口演奏协议保留。

FSR 不再连续控制音量。主音量继续由电脑界面或 V0..V100 设置；串口 M0 和 FSR 消音取逻辑或，只有两者都解除时才有声音。因此松开 FSR 不能取消 M0，M1 也不能覆盖仍按住的 FSR。板载 N16 指示灯在任一消音条件生效时常亮。

接线不变：FSR 接 MCP3208 CH0，旋钮中间脚接 CH1，ADC 与 DAC 仍使用当前 standard27 引脚。CH9350L 不需要到货，T7 不接外部晶振。

## 实现与阈值

新增 rtl/audio/fsr_mute.v，读取原有中值＋IIR 滤波后的压力值，在每次有效 ADC 组采样时更新。默认按下阈值为 512，松开阈值为 256，两者之间保持上一个状态，避免临界点抖动。这些是 12bit ADC 码，不是牛顿值，也不是传感器实物标定结果。需要调整时修改该模块的 PRESS_ADC 和 RELEASE_ADC，再仿真、构建。

顶层停止使用压力模拟增益，FSR 与 UART 合并后进入原有静音渐变链路；低通的零状态收敛也使用合并条件，保证最终数字静音为零。渐变沿用每帧 32/4096 的增益变化，完整渐变为 128 帧，46.875kHz 下约 2.73ms，另加 ADC 采样与滤波延迟。原 PRESSURE_ENABLE 名称保留，用来启用/旁路 FSR 消音；旧压力增益参数保留作源码兼容，当前产品路径不再采用它们做力度映射。

## 验证入口

tb_fsr_mute 验证阈值、滞回、更新使能、复位与旁路，并加入默认 Quick。tb_pressure_top 保留历史测试名，改为当前 8 声部、27MHz、UART＋ADC＋标准 I2S 的集成自检；仅缩短测试曲单位时长，音频、UART 和 ADC 时序保持生产值。它检查演示/手动消音、持续时钟、左右声道、精确零、两种消音来源的优先级、弯音及不重触发音符。

tb_control_sampling 保留独立 ADC 采样、通道轮询、滤波、单转换尖峰抑制和八个相位的响应检查，将旧 VCA 响应断言改为 FSR 消音响应。tb_mute_slew 继续核对原静音增益变化。默认音频测试的压力输入改为“未按下”，避免把测试默认值 2048 当成按住 FSR。

复现：运行 sim/run_simulation.ps1 -Tests tb_fsr_mute,tb_pressure_top,tb_control_sampling,tb_mute_slew；生产构建用 build/build.ps1 -Profile standard27；烧录用 build/program_sram.ps1 -Profile standard27，默认重新运行 Quick。本次新 RTL 需要重新验证，前次用户对旧位流重烧的跳门禁要求不作为新 RTL 已验证的证据。

## 回退与边界

回退资料保存在 archive/FPGA-20261024-v0.4/rollback 与 artifacts/before-standard27.fs。旧位流仍是 0x0000BF87、SHA256 8f70f54bb4cb95b68aeb41ca8180283ebaa33b21b282d88165867af2239723af。恢复旧源码后需删除新增模块/测试及其清单入口，或按归档清单逐项恢复；再次烧录仍按所选源码执行门禁。没有改写外部 Flash，SRAM 配置断电会丢失。

此前用户已反馈 CJMCU 音频恢复；这是用户试听反馈，不是仪器测量。本次新功能的实物按压阈值、舒适力度和听感仍需要用户操作确认。实际测试、构建和下载结果以配套 evidence/README.md 为准。
