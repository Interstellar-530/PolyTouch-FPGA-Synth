# 演示曲 F8 暂停与播放

CH9350L USB 键盘按 F8 暂停演示曲，再按一次从暂停位置继续。F7 仍切换手动/自动演奏，进入自动时从头播放并解除暂停。F8 在手动模式不生效；自动或暂停期间按新的音符键，仍可进入手动。

长按、重复上传和报告键位槽顺序变化都只触发一次，需松开再按。暂停冻结曲目节拍、剩余时值与待发送事件，通过原淡出逻辑消音；继续时恢复事件发送并淡入，不重置曲目。音频合成与 I2S 时钟继续运行，不是逐采样保存合成器状态。原 UART 静音和 FSR 消音仍各自有效。

修改三处内部键盘/顶层 RTL，外部端口、引脚和音符事件格式不变，没有新增声部、波表或乘法器。按用户要求跳过复杂门禁，仅运行 tb_top_host_pause 一项短检查，17.52 秒通过；覆盖进度保持、重复按键、数字静音、恢复音频、I2S 时钟持续和 F7/手动兼容。不运行 Quick、Full 或 PnR，不构建或烧录。
