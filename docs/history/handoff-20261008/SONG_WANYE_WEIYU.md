# 测试曲《晚夜微雨问海棠》副歌的转写与用法

日期：2026-10-24

## 为什么换曲

《兰花草》是四声部阶段的测试信号，旋律简单、句长固定。现在要测的是正式音频链和烧录后的整机试听，需要一段听得出来、又足够长的熟悉旋律。选《晚夜微雨问海棠》（镜予歌 / 喧笑 / 陈亦洺）的副歌“爱恨此消彼长”，一是副歌一开口就能辨认，二是它的十六分音符、附点八分和切分比《兰花草》密，能同时压到节拍网格、气口和四声部同时发声。FPGA 里仍然只存音高、力度和时值槽，运行时逐采样算波形，不播任何录音。

## 曲谱来源

| 来源 | 网址 | 用途 |
| --- | --- | --- |
| 弹琴吧《晚夜微雨问海棠 C调无歌词高潮》 | https://www.tan8.com/yuepu-119727.html | 主依据：C 调、4/4、四分音符 81，旋律与分句 |
| 琴谱123《晚夜微雨问海棠和弦弹唱版》 | https://www.qinpu123.com/qiyue/gangqin/655679.html | 副歌和弦走向：F G / Am / C / Dm Em |
| 极网吉它谱《晚夜微雨问海棠》 | https://www.jitapuji.com/6465.html | 交叉核对：原调降 E、C 调指法、约 80–81 BPM、93 小节 |
| 简谱之家《晚夜微雨问海棠》 | https://www.jianpujia.com/jitapu/276860.html | 交叉核对：4/4、80 BPM、C 调指法 |

原曲是降 E 调。上面两份 C 调谱都用变调夹或移调写成 C 调，测试曲沿用 C 调读法（比原调低小三度），这样旋律落在 A4–C6，正好避开波表最低音区。转写只用了副歌，没有用主歌。

## 速度和长度

三份谱面/资料给的速度是 81、81 和 80 BPM，按 93 小节 4:39 反算也是 80 BPM，因此取 **四分音符 81**，与谱面一致，不做任何拉伸。

| 项目 | 数值 |
| --- | --- |
| 最小单位 | 十六分音符（4 个单位一拍） |
| 一个单位 | 46875 Hz 档 8681 采样（185.17 ms）；48 kHz 档 8889 采样（185.19 ms） |
| 一遍 | 10 小节 = 160 个单位 = 29.63 秒 |
| 全曲 | 两遍 = 20 小节 = 320 个单位 = **59.26 秒** |
| 板上档位 | 1x（默认，原速）/ 2x / 3x / 4x，S2 循环 |

上电默认档从原来的 2 倍改成 **1 倍**（`tempo_sel = 0`，L14、L16 都灭）。这是这次换曲必须改的地方：旧曲用 2 倍是因为 72 BPM 听着拖，新曲再乘 2 就成了 162 BPM，和原曲速度不一致。

## 旋律与节奏

每个音后面的数字是它占用的十六分音符槽数，`0` 是休止。每小节合计 16。节奏按钢琴谱上每个音符的横向位置逐小节量化到十六分格：附点八分、十六分对、连音线合成一个长槽；句尾的保持音单独给长槽。

| 小节 | 旋律（音名 × 槽数） |
| --- | --- |
| 1 | 0×2 A4×2 A4×2 E5×2 D5×2 C5×2 B4×2 C5×2 |
| 2 | E5×6 F5×2 E5×4 D5×2 E5×2 |
| 3 | A5×2 G5×1 E5×2 D5×3 A5×2 G5×1 E5×2 D5×3 |
| 4 | D5×2 E5×1 G5×2 D5×2 E5×5 D5×2 E5×2 |
| 5 | 同第 3 小节 |
| 6 | D5×3 E5×3 G5×1 E5×1 E5×4 D5×2 E5×2 |
| 7 | A5×2 G5×1 E5×2 C5×2 D5×5 D5×2 E5×2 |
| 8 | C6×4 B5×1 A5×2 A5×5 C5×2 C5×2 |
| 9 | D5×2 C5×1 D5×1 D5×1 E5×2 C6×3 B5×1 B5×2 G5×3 |
| 10 | G5×2 A5×1 A5×1 A5×12 |

每小节第一个发声的音取力度码 7（127），其余取 5（104）。第 1 小节起拍是八分休止，所以“爱恨”落在第二拍的后半拍上，和原曲的弱起一致。

2026-10-26 修版：旧版在每个音后面切掉四分之一槽（最少一个十六分），81 BPM 下就是每个音后固定空 185 ms，听感发卡；同时把谱面上没有休止符的延长音误写成了“短音 + 自造休止”。现在每个音都占满自己的槽，只在明确写出的休止处静音。随后又按钢琴谱上每个音符的**横向位置**逐小节重算格位，修正了几处读谱错误：

- 第 6 小节“为你闯一趟”：原谱是 D5 附点（3）＋E5 连音（3）＋G5 十六分（1）＋E5 十六分（1）＋E5 长音（4）＋D5（2）＋E5（2）。旧版把 G5 当八分、把连音拆成两个音、少了一个 E5。
- 第 4 小节：E5 连音保持 5 格，后面 D5/E5 提前到 12/14。
- 第 8 小节：C6 四分（4）、B5 十六分（1）、A5 保持 5 格、末尾两个 C5 各 2 格。
- 第 9 小节：正拍直接 D5 起，G5 保持 3 格到小节线。
- 第 10 小节：G5 2＋两个十六分 A5＋附点二分 A5（12 格）。

## 和弦

和弦仍由播放器实时展开成三音，每个和弦占 8 或 16 个单位。两套进行都来自公开谱面，S1 切换：

| 套 | 来源 | 每遍走向 |
| --- | --- | --- |
| A（默认） | 琴谱123 副歌和弦 | F G / Am / F G / C / F G / Am / Dm Em / Am / F G / Am |
| B | 弹琴吧钢琴谱左手循环 | F G / Em Am，重复五遍 |

A 套是原曲副歌的功能序进（IV–V–vi–IV–V–I–ii–iii–vi），B 套是钢琴改编版自己的左手和声，两者都能配这条旋律，切换时和声色彩与音量一起变（A 力度 30，B 力度 46）。A 套里整小节的和弦拆成两个 8 槽的同名和弦，使两套的和弦表都是 40 项，共用一个 `CHORD_LAST`。

转位只用到根音位置：`F3 A3 C4`、`G3 B3 D4`、`A3 C4 E4`、`C3 E3 G3`、`D3 F3 A3`、`E3 G3 B3`。和弦音区压在 F3–E4，旋律在 A4–C6，两层不打架。

## 曲目 ROM 的格式变化

旧格式每项存“发声时长”，播放器再按 1/4 加气口，因此相邻十六分音符无法连奏，槽位总和也会被气口拉长。新格式每项存 **整个槽**：

```
旋律 16 位：{velocity_code[2:0], note[6:0], slot[5:0]}
和弦 16 位：{root[7:0], slot[5:0], quality[1:0]}
```

播放器在槽边界放键，不再提前切气口：每个音占满自己的槽，只有 `note=0` 的休止项静音。这样 `sum(slot)` 仍是精确的 320 个单位，十六分网格不会漂，长音也不会被切短。

| 表 | 深度 | 本次实际项数 | 地址位 |
| --- | --- | --- | --- |
| 旋律 | 256 | 138（其中 2 个休止） | 8 |
| 和弦 A/B | 64 | 各 40 | 6 |

旋律表仍用常量 `case`，综合成分布式 ROM（约 138×16 位），不占 BSRAM；和弦表 40×16 位。`GW2A-18` 的 BSRAM 预算不变。

## 生成、试听与校验

```powershell
cd source
python tools/gen_song_rom.py                  # 生成 song_roms.vh / song_expect.vh
python tools/render_preview.py ..\artifacts\wanye_chordA.wav A 1
python tools/verify_preview.py ..\artifacts\wanye_chordA.wav 1
python tools/render_preview.py ..\artifacts\wanye_chordB.wav B 1
python tools/verify_preview.py ..\artifacts\wanye_chordB.wav 1
```

`render_preview.py` 是按 RTL 逐模块等价的 Python 金模型（DDS → ADSR → 四声部 → 混音 → FIR），输出 16 位单声道 46875 Hz WAV。`verify_preview.py` 用 Goertzel 逐音确认预期音高是邻域里最强的。

仿真门禁仍按项目规则先跑：

```powershell
powershell -File sim/run_simulation.ps1
```

曲目表、节拍和指针对应的专项测试是 `tb_song_timing`（一遍必须正好 320×8681 个采样、256 个 note-on）和 `tb_song_backpressure`（事件在背压下不丢）。任何一项失败都不允许烧录。

## 烧录前注意

- 默认档必须是 1x；上电先看 L14、L16 都灭。若只亮 L14，说明烧的是旧的 2 倍默认。
- 整曲 59.26 秒，N16 每 59.26 秒闪一次；用秒表量两次闪烁的间隔即可判断时间基准。
- 板载 PT8211 调试档用 46875 Hz、单位 8681 采样；标准 27 MHz / PCM5102A 档用 48 kHz、单位 8889 采样，两档都由 `top.v` 的 `SONG_UNIT_SAMPLES` 自动选择。
- 本曲在 C 调读法下演唱，和原版降 E 调相差小三度；这是移调练习谱的常规做法，不是播放速度变化。

## 已知取舍

- 只转写了副歌，没有主歌和间奏；两遍副歌加终止小节刚好 59.26 秒。
- 第 24 小节前的“如梦几场”属于副歌导句，和弦是 E；本测试曲从“爱恨此消彼长”的 F–G 起拍，所以 E 没有进 A 套。
- B 套是钢琴改编谱的左手循环，不是原曲的另一版官方和声；它和 A 套并列是为了保留 S1 的可听差异。
