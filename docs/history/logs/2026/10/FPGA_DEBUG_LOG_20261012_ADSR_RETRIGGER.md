# 2026-10-12 ADSR 释放与声部重触发修复

本次完成零外设清单第一项。基线是 `157c3bed6a143a440688ce3afd1b0d6166666859`：松键后 `adsr.v` 每个采样节拍都再次写入 RELEASE，递减分支进不去。旧回归等待 2000 个采样节拍后仍得到 `env=45875、idle=0`。修复后同一回归得到 `env=0、idle=1`。

每个 Note On 现在由 `voice_alloc` 输出对应声部的一拍 `v_start`。`poly_voice` 保留这个脉冲到下一个采样节拍，使包络重新进入 ATTACK，并把 DDS 相位归零。连续按同一音符优先使用原声部，不再占用另一空闲声部；四声部都占满时仍按最老声部窃取，处于 RELEASE 的声部优先于仍按住的声部复用。旧 16 位年龄计数改成四个声部的相对次序，避免长时间演奏后回绕选错声部。原有 Note Off 在声部已窃取后也不会关闭新音符。

`run_simulation.ps1` 现在运行六个自检测试台。原节拍、歌曲、顶层测试保持通过；新增 `tb_adsr` 覆盖 ATTACK/DECAY/SUSTAIN 阶段松键、释放归零和快速重按，`tb_voice_retrigger` 覆盖同音重按、满声部窃取、释放声部复用、旧音符松键和相位重启，`tb_voice_order` 在 65538 次 Note On 后仍验证窃取次序。失败断言使用 `$fatal`，任一失败令门禁返回非零。最终门禁退出码为 0。此前归档的独立 ADSR 失败回归对当前 RTL 重新运行也已通过。

Gowin V1.9.11.03 Education 对 GW2A-LV18PG256C8/I7 重新综合及布局布线成功。资源为逻辑 4519/20736、寄存器 725/16173、BSRAM 4/46、DSP 宏块 6/24、MULT18X18 12/48。当前 27 MHz 约束下 Fmax 为 42.672 MHz，建立与保持违规端点均为 0。上一版审查基线分别是逻辑 4573、寄存器 789、Fmax 42.116 MHz；波表和乘法器占用未增加。这个时序结论只覆盖当前约束，不能代替板上听感和未来外部接口的测量。
