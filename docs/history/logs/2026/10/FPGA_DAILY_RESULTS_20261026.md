# 2026-10-26 本对话成果

本分支发布键盘、音量候选和延迟研究结果。起点为 b656b0d，已包含今天先前推送的 CH9350L 支持、F7 手动/自动切换及 F8 暂停/继续。本次仅纳入本对话明确修改的文件，未纳入其他智能体仍在调整的曲目、试听音频、render_preview、项目规划、共享 README 和 CURRENT_STATUS。

截至本对话上次核验，板上为 C452、standard27、8 声部、主混音 /8 的 F7/F8 版本。后续音量增强和完整键盘版本均未烧录。本分支源码构建入口是音量增强候选 /4，不代表板上版本已经更新。

演奏映射由 24 个扩展到 88 个物理键（80 个普通键及 8 个 modifier），默认 MIDI 21..108。报告最多提供 6 个普通键与 8 个修饰键身份，音源同时发声上限仍为 8，超出时使用既有声部窃取规则。保留原 24 键、F1..F8、音量及八度控制，Space 增加紧急清音。完整表见 source/tools/keyboard_layout.md，生成器为 gen_keyboard_layout.py。

32 声部仍为独立核心原型。默认包络、同架构 8/32 对照测得：音符请求到首个非零 I2S 为 0.068..0.083 ms，包含 UART 帧接收约 1.021 ms，32 音突发分配约 0.016 ms。未覆盖物理键盘扫描、USB 轮询和 DAC 模拟延迟，不能宣称整机已低于 3 ms。

低延迟及多声部编曲方案已保存，包含串口 300000 条件评估、PCM5102A 低延迟滤波、快速包络、板级 32 声部及直接传感器输入路线。约 2.8 ms 的完整键盘目标属于理论预算，没有实施硬件改动。

本发布树在 b656b0d 的源码上只叠加本对话文件，进行 tb_hid_full_keyboard、tb_top_host_eight、tb_ram32_latency 三项定向检查。结果及完整输入 SHA256 见 evidence/2026/10/FPGA-今日工作-20261026-v0.1/release-check。历史布局布线及测试来自当时工作区冻结快照，含其他任务当时的曲目状态；它们单独放在 historical-keyboard，不冒充本发布树的综合报告。本次发布未重新综合或烧录。

本地 archive/FPGA-20261026-v0.6..v0.11 保存完整位流、回退产物、冻结源码和证据，按项目既有规则不纳入 Git。Git 中保留功能源码、测试、方案、烧录记录及精简证据。没有上传工具环境、厂商手册、生成工程和其他任务临时文件。
