# 接线与引脚对应表（Tang Primer 20K + Dock 3714）

日期：2026-10-16　版本：v0.1　适用点流：`codex/s4-s6-integration`（`top.v`，`AUDIO_IF` 选择两档）

## 一、这张表是怎么来的

引脚不是抄规划文档，而是从底板原理图重新提取后再与规划交叉校验的：

- 球号与 Bank：`docs/references/boards/Tang_Primer_20K_Dock_3714/Tang_Primer_20K_Dock_3714_Schematics.pdf` 第 1 页的引脚表。该表每行形如 `<bank>/<IO site>/<球号>`、DFP 网络名、RGB_LCD 网络名、再一组 `<bank>/<site>/<球号>`（同一节点共用的 HDMI/LVDS 侧球号）。Dock 侧球号以 x≈774 那一列为准。
- 连接器逐脚：同一份原理图第 4 页是 J5 与 J6（`Conn_02x06_Odd_Even`，1/2 = +3V3、3/4 = GND、5..12 = 信号），第 9 页是 J14（同规格，引到麦克风阵列网络 MIC_*）。
- 板载音频：第 7 页 Audio 页，网络 `HP_BCK` / `HP_WS` / `HP_DIN` → PT8211-S 的 BCK(1)/WS(2)/DIN(3)，另有 `PA_EN`。
- 27 MHz 与核心板 Bank 配置：`Tang_Primer_20K_SOM-3961_Schematic.pdf`，其中 `H11_IOT27A_OSC_CK` 就是板载 27 MHz 晶振输入。

交叉校验结果：J5 八脚、J6 八脚、J14 八脚逐个与 `docs/hardware/FPGA-pinplan-20261013-v0.1.csv` 以及现有 CST/SDC 比对，**全部一致**，并额外确定了两个空闲脚的确切球号（J5-7 = N9、J14-11 = T6）。这两脚在原理图上分别是 RGB_LCD_R2 与 MIC_BCK。

## 三、外购件接线

### 3.1 12.288 MHz 有源晶振（3.3 V CMOS）

| 晶振引脚 | 接到 | 说明 |
| --- | --- | --- |
| OUT | 串 33 Ω → **J14-10**（球 T7，Bank 3，GCLKT_3） | 时钟输入；走线尽量短，不要与音频线并排 |
| VCC | **J14-1 或 J14-2**（+3V3） | 该脚旁放 100 nF + 1 µF 去耦 |
| GND | **J14-3 或 J14-4** | 与 FPGA 公共地 |
| OE / EN | 按所购型号接 VCC 或悬空 | 不要接 GND，否则无输出 |

T7 只用单端 CMOS 时钟。它与 J14-9（R8）构成时钟输入对，但本方案不启用差分时钟模式，R8 照常当普通琴键输入。

### 3.2 PCM5102A I2S DAC 模块

| 模块引脚 | 接到 | 说明 |
| --- | --- | --- |
| BCK / BCLK | **J6-5**（B12，Bank 7） | 3.072 MHz，可串 22–33 Ω |
| LRCK / LCK / WS | **J6-6**（C12，Bank 7） | 48 kHz |
| DIN / DATA | **J6-7**（B13，Bank 7） | 标准 I2S，MSB 比 LRCK 翻转晚一个 BCK |
| XSMT | **J14-12**（P6，Bank 3） | 高 = 解除软静音；本档 RTL 恒为高 |
| SCK | GND | 三线模式，时钟由内部 PLL 从 BCK 恢复 |
| FMT | GND | 选标准 I2S（Philips） |
| DEMP | GND | 去加重关 |
| FLT | GND | 正常群延迟 |
| VIN / 3V3 | +3V3（模块自带 LDO 时按其丝印） | 与 FPGA 共地 |
| GND | 公共地 | |
| OUTL / OUTR | 有源音箱或耳机 | 模块通常带 3.5 mm 输出 |

模块上的跳线要按实物核对：FMT 必须落在标准 I2S 一侧，SCK 必须接地，否则会出现左右声道错位或整帧偏移。

### 3.3 MCP3208 12 位 SPI ADC

| 模块引脚 | 接到 | 说明 |
| --- | --- | --- |
| CS / SHDN | **J5-9**（N6，Bank 3） | 低有效 |
| CLK | **J5-10**（D11，Bank 7） | 250 kHz 规划 |
| DIN | **J5-11**（A11，Bank 7） | FPGA → ADC |
| DOUT | **J5-12**（B11，Bank 7） | ADC → FPGA |
| VDD 与 VREF | +3V3（同一路） | 各放 100 nF，另加 1 µF |
| AGND / DGND | 公共地 | 单点共地 |
| CH0 | FSR 分压中点 | 压力维度 |
| CH1 | 电位器滑臂 | 弯音维度 |
| CH2–CH7 | GND | 未用通道，避免悬空 |

### 3.4 FSR 压力传感器

+3V3 → FSR → **分压节点** → 10 kΩ → GND，分压节点接 **CH0**。这样受力越大节点电压越高、ADC 码值越大。若实测方向相反，把 FSR 与 10 kΩ 对调即可，不用改 RTL。FSR 非线性且个体差异大，上板后要用 UART 观测 `pressure_level` 做标定。

### 3.5 弯音电位器（建议 10 kΩ 线性）

两端分别接 +3V3 与 GND，滑臂接 **CH1**，居中时约 2048，对应 0 半音；S5 复核确认的映射是 0 → −2 半音、2048 → 0、4095 → +2 半音。

### 3.6 12 路琴键

每键一端接对应引脚、另一端接 GND；12 根引脚各用 10 kΩ 上拉到 +3V3（低有效，按下接地）。C4→B4 依次对应：

| K1 | C♯4 | J5-6 | N8 | 3 |
| K2 | D4 | J14-5 | P9 | 3 |
| K3 | D♯4 | J5-8 | N7 | 3 |
| K4 | E4 | J6-8 | A14 | 7 |

### 3.7 输出

标准 I2S 档用 PCM5102A 的 OUTL/OUTR 接有源音箱或耳机。如果要用板载耳机口，就烧调试档（PT8211 路径），两档不能同时接。

## 五、注意事项

其一，点流互斥。调试档把 B12/C12/B13/P6 用作折叠观测 `clip_fold`，标准档把它们给 I2S 与 XSMT，两个档位不能同时接线。

其二，接口共用。J5 与 J6 的网络同时引到 RGB LCD 的 FPC 排线，J14 的网络同时引到麦克风阵列 FPC，所以接上 LCD 屏或麦克风阵列就会和本方案抢同一批脚。J14-6/T9 与板载 WS2812 的 LED 数据并联，本方案不要占用它。

其三，Bank 电压。Bank 3 由底板固定 3.3 V；Bank 1 与 7 按核心板默认 R5/R9 配置为 3.3 V；Bank 2 因承载 JTAG 被底板锁定 3.3 V；Bank 4（S1/S2/S3 三根）是 1.5 V，只作输入，不要把 3.3 V 器件接上去。上板前按到货流程复核一次实际 Bank 电压。

其四，供电与地。晶振、DAC 模块、ADC 模块、FSR 分压与电位器都取自同一路 3.3 V，并与 FPGA 单点共地；大电流外设用独立 USB 电源供电，避免地环路噪声。FSR 与电位器的走线远离时钟和 I2S 三线。

其五，本表仍是纸面结论。以下三点要上板核对：排针 1 脚位置（按实物方焊盘或丝印确认，不要按 USB 口方向猜编号）、FSR 分压方向与灵敏度标定、所购 12.288 MHz 晶振与 PCM5102A 模块的具体丝印和跳线。仿真与综合通过不等于实物已经验收。
