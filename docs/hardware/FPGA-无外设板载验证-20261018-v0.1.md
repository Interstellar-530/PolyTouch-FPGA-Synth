# 无杜邦线时的板载验证

本次只需 USB-JTAG/UART 数据线和接在 Dock 板载耳机口的耳机，外设排针保持空着。板载 27MHz、PT8211 和耳放完成音频路径。该路径不是 PCM5102A 标准 I2S 的实物验收。

## 已在现有固件上确认

读取到 GW2A-18C，ID Code `0x0000081B`，User Code `0x5633`；串口为 COM13、115200、8N1。`D0/M0/M1/N/O/X` 返回 OK，`T0` 返回 ERR，因此现有旧固件可做基础音频验证，但不能据此验收新增音色控制。

用户已现场确认：八秒单音稳定，松键后停止；四音和弦逐个减少，最后只剩低音并正常停止；持续音按 `M0/M1` 静音与恢复正常。上述为串口应答与人工听感记录，没有测量模拟频谱、音高误差、失真或端到端延迟。

## 无外设专用测试封装

普通生产 debug 入口仍会读取外接 GPIO 和 ADC。无外设时，应使用本轮独立的 `board_only_top` 测试封装：GPIO 固定为全部松开，ADC MISO 固定低，并将已有 `pressure_bend.ADC_CENTER` 参数设为 0，使采样稳定后弯音比率为 1。该封装只引出 14 个已有板载接口，不读取外部排针。

此封装复用当前生产 RTL，不改音频算法。它不验证 ADC、FSR、外部琴键或外置 DAC，也不能替代接线后的 debug/standard 档。之前接线手册中“今天用 debug”在排针完全空置时，具体应采用此独立裸板封装。

专用自检验证真实 UART 命令、8225 帧 PT8211 引脚解码、中性弯音、四声部、音色、静音和释音。Gowin 布局布线资源为 4533 Logic、1770 Register、4 BSRAM、1 MULT18X18；27MHz 约束下建立/保持违反端点均为 0，Fmax 估计 59.260MHz。这些不等于实物音频质量指标。

## 完整门禁与待验证项

烧录前仍执行项目完整门禁。旧 `tb_audio_capture` 的静音等待是 8 帧，现按生产 128 帧最大淡出增加到 140 帧并保留精确零输出、持续声部、58880 帧捕获和串行解码断言。只修改此测试时限与相应元数据，不修改生产音频行为。变更可单独撤回该测试文件。
