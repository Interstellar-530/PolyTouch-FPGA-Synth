# 27 MHz 单时钟方案与器件核查

日期：2026-10-19，版本 v0.1（对应方案 v0.3 的时钟选择修订：**不使用外部 12.288 MHz，直接用核心板 27 MHz**）。

## 1. 结论

| 项目 | 结论 |
|---|---|
| 27 MHz 来源 | 核心板有源晶振 U10，经 R20 22 Ω 到 **H11（GCLKT_0，Bank 0，3.3 V）**；不是 FPGA 内部 RC 振荡器 |
| 能否得到精确 48 kHz | **不能**。49.152/27 = 2048/1125，rPLL 的 IDIV/FBDIV 只能取 1..64 的整数，1125 不可实现 |
| 采用的音频格式 | **标准 I2S，BCK = 27e6/9 = 3.000 MHz，LRCK = 3.000e6/64 = 46.875 kHz，64 BCK/帧，24 位槽** |
| 为什么不用 48 MHz PLL | 27×16/9 = 48 MHz 可做到，但 48 MHz / 3.072 MHz = 15.625 拍/BCK，BCK 必须抖动；拒绝 |
| 音高是否受影响 | 不受影响。DDS 相位增量、UART 分频、ADC 节拍、曲目时值全部由 `AUDIO_CLK_HZ/AUDIO_FS_HZ` 推导 |
| PCM5102A 是否支持 | 支持。三线模式（SCK 接地）由 BCK 内部 PLL 生成时钟；BCK/LRCK = 64、Fs 46.875 kHz 在 8 k–192 k 范围内 |
| 综合/布局结果 | **Fmax 57.353 MHz**（约束 27 MHz，2.12× 余量），Setup/Hold 违规 **0**，Logic 6668/20736 (33%)，Register 2471 (16%)，BSRAM 37/46 (81%)，MULT18X18 1，**无 PLL** |
| 结论 | 27 MHz 单时钟可以承担完整生产链路；不需要购买 12.288 MHz 成品晶振，T7 留空 |

## 2. 时钟推导

```text
H11 27.000 MHz
  └─ /9  → BCK  3.000 MHz（高 4 拍、低 5 拍）
       └─ /64 → LRCK 46.875 kHz（每帧 576 个 27 MHz 拍）
```

- 27e6 / 9 / 64 = 46875，三步都是整数，无累加器抖动。
- 44.1 kHz 同样不可整除（27e6/44100 = 612.24），不在本轮选择内。
- 24 位数据 + 32 位槽：位置 0 为 0，位置 1..24 为数据，位置 25..31 补零，与现有 `i2s_tx` 一致。
- UART 115200：27e6/115200 = 234.375，取 234 拍/位，实际 115 384 baud，误差 0.16%；CH9350L 的 115200 8N1 可共用该分频。
- 2 kHz 控制节拍：27e6/2000 = 13 500 拍；ADC 组间隔 27 拍（1 µs）。


`program_sram.ps1` 的 `ValidateSet` 已加入 `standard27`；烧录前仍会先跑 `run_simulation.ps1`，任一测试失败即拒绝烧录。

## 4. 定向验证证据（2026-10-19）

| 测试 | 结果 |
|---|---|
| `tb_top_i2s_27m`（AUDIO_IF=2） | PASS：8271 帧解码，8272 个采样节拍；A4 过零周期 105.75 采样；A4 `inc=40315424`，理想 440·2³²/46875 = 40315427，差 3 LSB（0.07 ppm）；M0/M1、PT8211 三线恒低、XSMT 恒高均通过 |
| `tb_top_i2s`（AUDIO_IF=1，48 kHz） | PASS：与改动前同一组期望值（A4 108.54 采样，四音 `inc` 差 6/13/35/35 LSB），证明 12.288 MHz 档未回归 |
| `tb_tick_rate`（AUDIO_IF=0，PT8211） | PASS：186 个周期全部 576 拍 = 46.875 kHz，证明调试档未回归 |
| Gowin `standard27` 全流程 | 成功生成 `instrument.fs`；Fmax 57.353 MHz，Setup/Hold 违规 0 |

同源对照（同一 RTL，仅换时钟档）：

| 档 | Logic | Register | BSRAM | MULT | Fmax / 约束 |
|---|---:|---:|---:|---:|---|
| `standard`（12.288 MHz / 48 kHz） | 6771 | 2459 | 37 | 1 | 44.682 / 12.288 MHz |
| `standard27`（27 MHz / 46.875 kHz） | 6668 | 2471 | 37 | 1 | 57.353 / 27 MHz |

27 MHz 档比 12.288 MHz 档少 103 个 Logic、多 12 个 Register，BSRAM 与乘法器相同；没有因为改用板载晶振而增加存储或 DSP。Fmax 绝对余量从 3.64× 降到 2.12×，但仍远高于 27 MHz 且无违规。

按用户要求，本轮未跑完整 `run_simulation.ps1`（耗时门禁），只跑与改动直接相关的三个测试台。烧录前仍须补跑完整门禁。

## 7. 音响选型（CJMCU-5102 LINE OUT）

PCM5102A 是 **2.1 Vrms 线路输出**，只能接有源音箱的 AUX/LINE IN，或接耳机功放后再接耳机；不能直接接被动音箱、耳机、MIC IN、PHONO 或功放的扬声器输出。选型的第一硬条件是 **模拟 AUX/RCA 输入、无蓝牙、无 DSP 重采样**——蓝牙音箱的 100–200 ms 延迟会直接破坏 ≤10 ms 验收。

| 档位 | 推荐 | 参考价 | 接口/供电 | 说明 |
|---|---|---|---|---|
| 首选 | 漫步者 MR4 有源监听 | 约 400–500 元 | RCA 非平衡 + 6.35 mm TRS，AC 供电 | 频响较平、屏蔽较好、无蓝牙；用 3.5 mm 转双 RCA 线接 LINE OUT。体积较大 |
| 经济 | 漫步者 R1000TCN | 约 300–400 元 | RCA，AC 供电 | 经典 2.0，桌面占位小；老款底噪略高，验收时以实测为准 |
| 用现有耳机 | TPA6132A2 耳机放大模块 | 约 15–30 元 | 3.3/5 V，3.5 mm 进/出 | LINE OUT → 耳放 → 耳机；不要用 PAM8403 推耳机（D 类喇叭功放，底噪大） |
| 最低成本 | PAM8403 + 4 Ω 3 W 全频喇叭 | 约 30 元 | 5 V | 能响，但开关噪声/EMI 大，只适合临时调试，不作为音质验收 |

## 8. 仍需确认 / 未执行

1. **P0 选表语义修复未执行**：非钢琴音色（T0–T249）当前仍从 72 张钢琴表取 bank 0..4。按方案应恢复 6 级通用明亮表，代价是 +3 块 BSRAM（37→40/46），并会改变 T0–T249 的音色与 `tb_bandlimit_engine` 的黄金向量。需要确认是否接受该代价与重做基线。
2. **HID 键盘接口未接顶层**：协议已明确（state 2），但 L9/N8 要从 12 路 GPIO 键改为 Host UART，属于公共引脚变更；方案要求先评审接线表。本轮未改。
3. **实物验证未做**：PCM5102A 在 46.875 kHz 三线模式的 PLL 锁定/静音、CJMCU 电源路径、FSR 源阻抗、CH9350L 实际帧重复次数，都需要到货后用逻辑分析仪和万用表确认。
4. 完整仿真门禁按用户要求本轮未跑；烧录前必须补跑。
