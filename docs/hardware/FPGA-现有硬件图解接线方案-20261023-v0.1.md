# 01｜这次接什么，做到哪里算通过

本方案经用户确认：使用 **Tang Primer 20K＋Dock 3714、CH9350L USB 键盘模块、PCM5102A/CJMCU-5102、MCP3208、FSR402 和 10kΩ 弯音电位器**。音箱暂时无法接入，灯带和彩屏尚未到货。四脚直插、3.3V 有源晶振已到货，按提供的 DIP-8 外形图单独说明。

首轮使用 `standard27`：8 声部、板载 27MHz、46.875kHz 采样率、24 位标准 I2S、每帧 64 个 BCK。**本轮不接外部晶振到 T7。** 32 声部核心已通过 RTL/PnR，但正式板级顶层尚未集成；不能烧录无实体引脚约束的核心原型。

![主链路与模块边界](wiring-20261023-v0.1-assets/01-system.pdf){width=170mm}

| 验收层级 | 现在可做的检查 | 可以写出的结论 |
|---|---|---|
| 供电与焊接 | 万用表、断电通断、空载/带载电压 | 供电和连接核对通过 |
| 数字链路 | UART 帧、SPI 解码、I2S 解码 | FPGA 收发数字数据通过 |
| DAC 模拟输出 | 示波器，或已确认的高阻线路输入 | 模拟输出存在/频率正确；无设备则待测 |
| 真实听感 | 有源音箱 LINE IN 或独立耳放 | 音箱缺席，本轮不宣称通过 |

主接线图以**板上实际丝印**定位：Dock背面PMOD3/PMOD2/PMOD0及L9、N6、B12等标记，DAC用BCK/DIN/LCK/XMT等孔名。J5/J6/J14只作附录索引。ADC裸芯片脚号与未知转接板端子号不一定相同，必须通断确认。每次改线断开USB、适配器和仪器可能带来的电源。

# 02｜动手前：工具、材料与工作台

建议将 Dock、ADC 转接板、DAC 和传感器固定在绝缘底板上。先贴标签再接线：红色仅表示 3V3，橙色表示 5V，黑色为 GND；信号线两端使用同一 W 编号。颜色只是辅助，最终按端子和万用表核对。

| 类别 | 本轮所需 |
|---|---|
| 焊接与连接 | 匹配 MCP3208-CI/SL 的 SOIC-16 转接板、排针、10cm 杜邦线、热缩管、绝缘底板 |
| 小元件 | FSR 分压 10kΩ；备用 10kΩ 两只；100nF 陶瓷电容至少两只；约 1µF；备用 10kΩ CS 上拉 |
| 测量 | 万用表必备；逻辑分析仪建议 ≥24MS/s，I2S 优先使用更高采样率；示波器用于电源/时钟/模拟输出 |
| 电脑 | Gowin、Icarus、USB 数据线、可选 USB-TTL 接收工具；串口软件设置 115200/8N1 |
| 暂不安装 | 灯带、AHCT125、屏幕、机械键、MPR121；避免混用旧接线表 |

**先认方向。** ADC 的圆点/缺口标 1 脚，SOIC 顶视图沿逆时针编号；不要按转接板排针从左到右依次数。Dock 排针需先找 J 编号、1 脚/方焊盘，再用 3/4 脚到 GND 的通断确认。将未知板翻面时左右会镜像。

通断和电阻档只在断电时使用。上电后使用电压档，黑表笔先接 GND；为相邻芯片脚测量时使用细探针，避免探针短接两脚。测电流时表笔必须串入供电回路，不能把电流档直接跨在电源两端。示波器地夹接电路 GND，不夹未知节点或电源正极。

**以下情况立即断电：** 3V3 轨出现 5V/12V、极性相反、持续过流、器件迅速明显发热、闻到异常气味、重新接线后电源电压明显塌陷。先拆回最近新增的模块，恢复上一项通过状态。

# 03｜按你板背丝印找插针

下图使用你在2026-10-18另一对话上传的Dock背面照片。保持照片朝向：耳机口在上方、网口在左下、排针在右侧。**在正面插线时先认同一根针，不能照抄背面左右位置。** 可先断电通断确认并贴线号。

![用户Dock背面照片与实物丝印定位](wiring-20261023-v0.1-assets/12-board-photo.pdf){width=170mm}

PMOD3位于照片右下，负责键盘和ADC；PMOD2位于它上方，负责DAC；PMOD0位于右上MIC ARRAY附近，T7/P6本轮留空。找到名字对应的格子后，沿同一行认两根针，不能将标注格中的文字当成焊孔本身。

照片中每组排针最下面一行为`3V3 / 3V3`，上一行为`GND / GND`。按丝印取电，不套用普通PMOD习惯。中间PMOD1/DVP本轮不用；RGB LCD和MIC ARRAY的FPC口保持空置。板载S1/S2/S3为1.5V按键域，不外接3.3V/5V；T9/RGB LED共用通路也留空。

# 05｜阶段一：电源、地与板卡单独上电

![供电支路图](wiring-20261023-v0.1-assets/05-power.pdf){width=170mm}

首轮沿用已经正常使用的Dock `JTAG UART` USB口，使用支持数据的USB线；不要误插`USB2 OTG`口。暂不同时接板上`DC INPUT`和其他主电源。若以后改用DC INPUT，先核对12V适配器、中心正极和插头尺寸；板上标注范围不能代替插头和供电电路核验。

断电时先确认面包板电源轨是否中断；用短跨线把需要共用的区段连接。ADC 的 AGND/DGND 在转接板附近短接，FSR、电位器和去耦回地接在这里。键盘、DAC 共地；未来灯带大电流回路直接回电源分配点，不能串过 ADC 地线。

| 步骤 | 操作 | 通过表现 |
|---|---|---|
| 1 | 所有外设先拔掉，确认3V3/GND无明显持续短路 | 不出现稳定近零电阻/持续短路；充电过程读数变化单独判断 |
| 2 | 仅给Dock上电，黑表笔接PMOD3的GND | PMOD3/PMOD2/PMOD0的3V3约3.3V；可用3.14至3.47V作首轮工程检查窗 |
| 3 | 外部降压模块独立空载测量，再接已知小负载 | 目标5V时约4.75至5.25V，无明显压降和异常发热 |
| 4 | 核对各模块供电入口，再逐个加入 | 接入后3V3仍稳定，模块无异常发热 |

上述电压窗为装配检查目标，不替代各器件供电范围。若CH9350L单独供电，确认 Host USB口的 VBUS 为5V。**VCC 能接3.3V不等于 USB键盘能得到5V。** DAC 电源见第08节，未确认前不接。

避免外设已上电而 FPGA 断电时仍向 IO 输入高电平，以免从保护结构反向供电。先接地、后供电/信号；断电改线。通电时只测电压，不用通断档。R18T/其他音箱尚未接入，暂不设计它的电源接法。

# 06｜阶段二：MCP3208 芯片与 SPI

![MCP3208完整脚序与去耦](wiring-20261023-v0.1-assets/06-adc.pdf){width=170mm}

芯片顶视图：缺口在上，左侧从上到下为1至8，右侧从下到上为9至16。实物 MCP3208-CI/SL 是SOIC-16，先焊接到匹配转接板，用通断档建立“芯片脚→转接端子”的对应。电源脚一旦镜像最容易误接。

| 芯片脚 | 功能 | 实际连接 |
|---|---|---|
| 16 | VDD | P01／3V3，近端100nF＋约1µF到AGND |
| 15 | VREF | P01／3V3，近端100nF到AGND |
| 14、9 | AGND、DGND | 近端短接后回P02／GND |
| 10 | CS/SHDN | W03；可加10kΩ上拉到3V3，避免FPGA配置时片选悬空 |
| 13、11、12 | CLK、DIN、DOUT | 分别接W04、W05、W06 |
| 1、2 | CH0、CH1 | FSR节点、电位器滑臂 |
| 3至8 | CH2至CH7 | 未用时接AGND，不能误当作数字输出 |

**调试方法。** 先不接FSR和旋钮，用两个10kΩ串联分压产生约1.65V，依次将CH0/CH1接GND、中点、3V3。逻辑分析仪以CS下降沿触发，SPI mode 0、MSB first；SCK约250kHz，一次事务19个时钟，约76µs。用Start/单端/通道选择识别当前采样通道，再提取12位结果，不能直接把19位整体当ADC数值。

**通过表现。** 三点输入对应约0、2048、4095码，数值随输入上升。首轮可用满量程±2%作为接线筛查标准，中点约1966至2130；精度验收需另扣除参考误差、仪表误差和芯片误差。固定全0先查DOUT/时钟/供电，固定全1先查DOUT悬空、CS和地。当前固件不保证向串口自动打印ADC原始码，不能把没有日志当作ADC损坏。

# 07｜阶段三：压力与弯音模拟前端

![FSR与电位器接线](wiring-20261023-v0.1-assets/07-sensors.pdf){width=170mm}

FSR402 无正负极。上端接3V3，下端形成 A01；A01 经10kΩ接AGND，同时进入ADC第1脚。施压时FSR电阻通常下降，分压电压升高。关系为 `VCH0 = VREF × 10k / (RFSR + 10k)`，ADC约为 `4095 × VCH0 / VREF`。

10kΩ线性电位器先断电识别两个固定端：两端阻值约10kΩ，转动时基本不变；第三端为滑臂。固定端分别接3V3、AGND，滑臂接ADC第2脚。顺时针方向不符合习惯时交换两个固定端，不能把滑臂与电源端随意交换。缺旋钮时两个等值10kΩ串联，中点给CH1。

| 检查点 | 方法 | 通过表现 |
|---|---|---|
| FSR静态电压 | 万用表依次测松开、轻按、重按A01 | 始终0至3.3V，受压总体上升，无断线跳变 |
| ADC对应码 | 解码CH0，记录三种压力各一组 | 与电压趋势一致，重复施压可重复 |
| 旋钮中位 | 调A02到VREF/2附近 | 约1.65V，ADC约2048，音高居中 |
| 两个极限 | 缓慢转动旋钮 | 从低到高连续变化；正常固件目标约±2半音 |
| 持续表达 | 持音后改变压力/旋钮 | 数字输出幅度/周期变化；无模拟设备时听感待测 |

VREF=3.3V时，当前压力映射参考码128和3200约对应0.103V、2.579V。它们是软件增益范围参考，不是FSR必须天然达到的力值。按到最重仍达不到高端时，先记录实际跨度，再决定分压电阻和软件标定；不要靠过大力量硬压。压力改变的是持续响度，不能当作普通键盘逐键敲击力度。

FSR下方加刚性背板，上方软垫使受力分散，尾线做应力释放；避免在感应区折弯或将力直接压在排线根部。首轮不加大电容；如噪声明显，可试10nF，但要重新观察响应速度。模拟线短、远离SPI、I2S和降压电感。

# 08｜阶段四：PCM5102A 实物孔位与模式

![用户CJMCU照片及丝印孔名](wiring-20261023-v0.1-assets/13-dac-photo.pdf){width=170mm}

按已有实物照片方向：3.5mm LINE OUT 插座在上方，左侧11孔自上而下为 **VCC、3.3V、GND、FLT、DMP、SCL、BCK、DIN、LCK、FMT、XMT**。这些是模块孔名，不是芯片脚号。芯片对照：BCK=13、DIN=14、LRCK=15、FMT=16、XSMT=17、SCK=12、FLT=11、DEMP=10。

| 模块孔 | 首轮接法 | 断电确认/上电目标 |
|---|---|---|
| VCC、3.3V | 先确认LDO网络，只选一路正确供电 | VCC如为LDO输入按该模块额定值；3.3V孔可能是稳压输出 |
| GND | P03／PMOD2的GND | 与ADC、FPGA共地 |
| BCK、DIN、LCK | 分别W07、W09、W08 | BCK与SCL/SCK不可混接 |
| FMT | 低电平 | 标准I2S；高电平为左对齐 |
| SCL／SCK | 低电平 | 选择三线BCK PLL；不是I²C时钟 |
| DMP／DEMP | 低电平 | 关闭去加重 |
| FLT | 固定低电平，先确认焊桥 | 正常延迟；不悬空 |
| XMT／XSMT | 确认网络后固定3.3V | 解除软静音；P6首轮不连 |

**电源确认步骤。** 断电观察并记录背面焊桥、LDO完整丝印和走线，确认VCC是否接LDO输入、3.3V孔是否接输出以及GND。不能用“通断没响”反推允许电压，也不能按模块名推断VCC必为5V。如果网络未确认，停在本页，不给未知端子送电。

如果控制孔已通过焊桥硬绑电平，先核对实际状态；不要再接相反电源或FPGA推挽输出。XMT固定高时PMOD0/P6始终留空。板上LDOO和VNEG属于芯片内部电源/电荷泵网络，不作为外设电源输出。

\clearpage

# 09｜没有音箱时怎样调 DAC

![I2S与无音箱测量连接](wiring-20261023-v0.1-assets/09-i2s.pdf){width=170mm}

先只连接DAC电源、地与模式脚，确认稳定后断电加入W07至W09。三根I2S线建议不超过约10至15cm，旁边带GND参考；连接前后拍照。不要为了消除噪声盲目堆电容或接长飞线。

| 阶段 | 操作 | 通过表现 |
|---|---|---|
| 空载数字时钟 | LA接BCK、LRCK、DIN和GND | BCK约3.000MHz，LRCK约46.875kHz，每帧64BCK |
| 标准I2S解码 | 24bit、32bit时隙，BCK上升沿采样 | LRCK翻转后延迟1个BCK才是MSB；左右声道对应 |
| 已知单音 | 按第11节发送测试命令 | DIN存在有规律的非零样本，松键/静音后回到零 |
| 模拟输出 | 示波器高阻探头接LINE OUT的L或R，地接音频GND | 单音周期正确；M0后交流输出显著下降 |
| 无模拟仪器 | 保存数字解码和接线记录 | 只通过数字链路，DAC模拟转换和听感记为待测 |

LINE OUT 是线路电平，**不直接驱动普通耳机或被动喇叭**。未来音箱到位后用立体声线接AUX/LINE IN，先低音量。若用USB声卡录音，必须确认有真实Line In及允许输入范围；麦克风口可能有偏置、电平和单声道限制，不能直接当Line In。

若需现在试听，可在断电后切换并重新构建 `debug8usb`，用Dock板载PT8211耳机口。核对该封装/CST与外设脚兼容后再烧录，先低音量；此结果只证明板载调试出口，不能代替PCM5102A验收。

当前46.875kHz/BCK PLL是否在所购模块上稳定锁定仍需实测。数字波形正确但模拟端无信号时，先查供电、XMT、FMT、SCL接地、输出接口，再考虑后续正式48kHz板级档；不要直接给standard27换晶振。

# 10｜阶段五：CH9350L 与 USB 键盘

![键盘模块单向连接](wiring-20261023-v0.1-assets/10-keyboard.pdf){width=170mm}

模块按下位机设置：**SEL高、S0低/S1高（state 2）、BAUD0/BAUD1高（115200，8N1）**。拨码ON/OFF究竟对应高低由实物电路决定，先断电核对或上电测逻辑电压，不能只看开关方向。模块电源按指定入口供电，Host USB口VBUS必须为5V；TXD接FPGA前测空闲高电平约3.3V。

键盘插模块USB Host口。W01为模块TXD→Dock PMOD3/L9；W02为模块RXD→模块GND；模块GND→公共地。**PMOD3/N8留空，不能接入RXD接地节点。** 若模块已经将RXD焊接到其他驱动源，先处理冲突再用单向模式。CH9350L成品板位置尚无可恢复实拍，按实物TXD/RXD/GND功能丝印找端子，不推断其左右孔序。

| 操作 | 观测/预期 | 故障先查 |
|---|---|---|
| 单独接LA/USB-TTL RX监听TXD | 115200/8N1；按键出现有效帧 | VBUS、下位机模式、波特率、共地 |
| 按Q再松开 | `57 AB 01`后8字节Boot报告；按下包含14，松开对应槽清零 | UART解码与模块状态；14为十六进制键码 |
| 按Q/E/T和弦 | 对应键码14/08/17同时出现 | 键盘无冲能力、报告槽数 |
| 长按≥5秒再松开 | IdleOnly固件持键不被静默超时清音 | 位流版本、策略、重复报告去重 |
| 拔键盘/拔模块TX线 | 若有拔出通知则清音；无通知可能粘音 | 使用Esc或Dock S3恢复，记录具体情况 |

监听时只接工具RX与GND，工具TX和VCC留空，避免两个输出驱动同一TXD或工具反向供电。11字节、115200/8N1的线传输时间约0.955ms，尚不包含键盘扫描和USB轮询。Boot报告只有6个普通键槽位，不能据此要求一次输入32个独立按键。

确认后再连FPGA。Q/E/T为C4/E4/G4，F6切钢琴/吉他，↑/↓调音量，F1至F5切档，Esc全松键，PageUp/PageDown变八度。切换乐器会清除当前声部，切换后重新按键。

# 11｜固件准备与整机接入次序

第一轮只用 `standard27`，默认长按策略 `IdleOnly`。每次烧录前运行Quick短门禁，核对构建收据、源码与位流哈希；不使用SkipSimulation绕过。下列命令是操作说明，本文件制作过程没有连接硬件或执行烧录。

```powershell

& "$src\sim\run_simulation.ps1" -Suite Quick
& "$src\build\build.ps1" -Profile standard27 -HostTimeoutPolicy IdleOnly
# 接线、实现报告和收据确认后才执行：
& "$src\build\program_sram.ps1" -Profile standard27 -HostTimeoutPolicy IdleOnly
```

烧录入口默认会再执行Quick并核对收据。源码有改动后必须重新构建，不能从历史目录随便挑一个FS文件。当前32声部 `ram32_clocked_wrap` 只有核心原型验证，不使用它的位流替代上述板级档。

| 顺序 | 本次只增加的部分 | 过关后再做下一项 |
|---|---|---|
| 0 | Dock单板、供电、下载与串口 | 无异常电压，配置成功，能收到OK回复 |
| 1 | ADC供电及固定三点输入 | 0/中点/满量程码正确；弯音输入先给中位 |
| 2 | DAC电源和模式脚，再加I2S | 数字I2S解码通过；模拟端按仪器条件验收 |
| 3 | 串口发已知音符 | 命令OK，DIN非零；M0后数字静音 |
| 4 | CH9350L和USB键盘 | 按下、松开、和弦、长按与清音恢复 |
| 5 | FSR、电位器 | 电压/码值趋势正确，持音时表情变化 |
| 6 | 固定线束、整机复查 | 冷配置后重复以上关键检查，保存记录 |

串口为115200/8N1，逐条发送ASCII命令，每条以回车或换行结束：`D0`（退出演示）→`M1`（解除静音）→`V100`→`I0`→`N60`。观察后发`O60`松键；`X`全松键，`M0`数字静音。每条应回复OK，等回复再发下一条；协议没有RTS/CTS，不持续灌入大量命令。

FSR松开时增益不是必然归零，因此以`M0`或`V0`测试精确静音。S3是板载设计复位键；不要把S0/T10配置保留脚或S4/重配置当作日常复位。SRAM配置断电丢失，冷启动验收要记录重新下载方式，不能写成Flash自动启动已完成。

# 12｜到货晶振：DIP-8 四脚，先独立确认

![依据用户提供尺寸图的晶振脚序](wiring-20261023-v0.1-assets/11-oscillator.pdf){width=170mm}

用户提供图为方形PXO DIP8有源振荡器，**只有四根引脚，但编号是1、4、5、8**。图示底视图为左上1、右上4、左下8、右下5；按供应商顶视图将定位圆点放左下时，顶视图为左上8、右上5、左下1、右下4。翻面后必须重新按定位点认脚，不凭面包板左右猜。用户确认供电3.3V，“8.000”只是外观示例，不证明实物频率。

| 引脚 | 用户图定义 | 独立测量/后续连接 |
|---|---|---|
| 8 | VCC/Vdd | 3.3V，近端100nF，可再加约1µF |
| 4 | GND | 公共地 |
| 5 | OUT | 先测输出；确认匹配档位后经约33Ω接PMOD0/T7 |
| 1 | 图中文字NC；表格NC或Tri-state | NC时留空；若确为使能，按型号手册给定义电平，不能盲接 |

**独立检查顺序。** 不接FPGA，确认脚序后给3.3V；用示波器或合适频率计测OUT频率、低高电平与稳定性。先确认是否是所需12.288MHz，再考虑接入。万用表显示中间电压不能证明起振或频率正确。若无输出，先查1脚功能、脚序和供电，不随意尝试5V。

**本轮结论：standard27的T7不接。** 未来USB＋32声部＋48kHz正式板级档完成CST/SDC、RTL和PnR后，才把已测12.288MHz接入。现有历史`standard`是GPIO键输入档，不能当作USB主线48kHz档。

# 13｜故障定位：先找哪一级不成立

| 表现 | 按顺序检查 | 重新通过的依据 |
|---|---|---|
| 模块一接入就掉电 | 断电拆最近模块，查镜像脚序、3V3与5V混轨、短路 | 单板恢复，模块单独供电正常，再逐线接回 |
| 键盘无任何报告 | USB Host VBUS、模式/SEL、波特率、TX电平、GND | LA先看到有效帧，再判断FPGA解析 |
| 键盘有帧但不发声 | 使用档位、L9接线、D0/M1/V100、是否触发音符 | I2S解码样本发生变化；无音箱不以耳听判断 |
| ADC总是0/4095 | VDD/VREF、CS与CLK、DIN/DOUT是否互换、共地 | 三点输入返回正确梯度 |
| 弯音一直偏到一端 | CH1悬空、滑臂识别、实际ADC中位、分压接错 | 中位约VREF/2，对应约2048码 |
| 轻按就满量程/压力不灵敏 | 分压方向、FSR受力、10k阻值和实际跨度 | 松/轻/重三组数据可重复，之后再标定 |
| BCK/LRCK不对 | 位流/profile、时钟源是否混用、CST | standard27约3MHz/46.875kHz，64BCK/帧 |
| I2S有数据，DAC无输出 | 电源轨、XMT、FMT、SCL/SCK、PLL、LINE OUT孔位 | 示波器看到对应单音，或Line In录音正确 |
| 有嗡声/触碰就变 | 地线、模拟线长度、降压噪声、仪器地回路 | 固定线束后噪声下降，信号不随触碰突变 |
| 拔线后粘音 | 模块未发通知，持音静默策略无法区分拔线 | Esc/S3恢复，记录通知与恢复过程 |

**仪器连接同样要核对电平。** 逻辑分析仪的“5V容忍”不能推广到FPGA；3.3V TX正常也不意味着同板所有接口都是3.3V。普通LA可能看见12.288MHz跳变却无法可靠测幅度/边沿；BCK 3MHz下建议至少约8倍采样用于基础解码，更高采样有助于发现边沿问题。

**机械与布线。** 保持I2S短线、ADC模拟节点短线，信号地紧邻；USB插拔的拉力由固定结构承受，不由排针承受。转接板背面绝缘，避免散落锡珠与金属底板短路。面包板适合首轮验证，最终展示应改为固定连接并做拉力检查。

**未来增强。** 灯屏尚未到货，本轮不接预留信号。MPR121和机械键属于替代输入，会与部分现用引脚冲突。不要沿用旧12键表混接；加入灯屏或32声部整机前重新核算BSRAM、DSP和电源，并重新确认引脚复用。
