# PolyTouch FPGA 硬件搭建指导

日期：2026-10-22，版本 v0.2。适用 Tang Primer 20K Dock 3714，GW2A-LV18PG256C8/I7，版本 C。

本版替代远端 881a11c 的 v0.1 装配指导。主路线按用户已确认的 USB 键盘直连恢复，保留 v0.1 的采购、电源和 ADC/DAC 资料。核查依据见[交叉核查报告](../reviews/FPGA-硬件搭建交叉核查-20261022-v0.1.md)，物料状态见[采购准备](FPGA-硬件采买与搭建准备-20261022-v0.2.md)。本版经过文档、源码和图纸核对，尚不代表外设已接通或实物验收通过。

## 1. 本次装配目标与档位

USB 键盘直接插 CH9350L 下位机 USB Host 口，FPGA 接收 UART 按键报告并实时发声；FSR402 和电位器经 MCP3208 进入 FPGA，分别控制持续响度和弯音；PCM5102A 线路输出接有源音箱。电脑用于下载、串口调试和记录。首轮以 8 声部主链路为目标，灯屏为增强项。

| 构建档 | 输入与时钟 | 音频出口 | 装配定位 |
|---|---|---|---|
| `standard27` | CH9350L＋UART，板载 27MHz | 外置 PCM5102A，46.875kHz，BCK 3.000MHz | 首轮主线；T7 留空，DAC 锁定需实测 |
| `debug8usb` | CH9350L＋UART，板载 27MHz | 板载 PT8211，46.875kHz | USB 键盘调试；不能代替正式 DAC 验收 |
| `standard` | 12 路 GPIO＋UART，外部 12.288MHz | 外置 PCM5102A，48kHz，BCK 3.072MHz | 历史机械键备选；没有启用 CH9350L |
| `debug` | 12 路 GPIO＋UART，板载 27MHz | 板载 PT8211 | 历史机械键调试 |

`standard27` 当前封装明确设置 VOICES=8、GPIO_KEY_ENABLE=0、HOST_KBD_ENABLE=1。不能把 `standard` 当成“USB 主线的 48kHz 档”，也不能只替换外部时钟便得到 32 声部。

32 声部双时钟原型已在 12.288MHz 参考、73.728MHz 计算档获得时序通过记录，使用 26/46 BSRAM、2 个 MULT18X18，Fmax 74.451MHz。该工程没有完整板级物理约束，未集成整机键盘与 ADC 接口，不能直接烧录。后续采用外部参考仍符合已确认方向，须单独完成板级顶层和约束。

## 2. 电源、排针方向与结构

J5、J6、J14 都为自定义 2×6 排针：1/2 是 3V3，3/4 是 GND，5—12 才是信号。逐个按丝印、方焊盘与 GND 通断确认方向。S1/S2/S3 属 1.5V 输入域，不接外设 3.3V/5V。每次改线断开全部电源；通断和电阻档只用于断电状态。

首轮保留原已工作的 Dock 正规供电入口。若 USB-JTAG 单独供板，先不同时接 J13；改用 12V 适配器前，先核对接口、极性与电压。图纸中 J13 为中心正极的 12V 网络，连接器型号标为 DC-036A-2.5A-2.0，**仅此标注不能确认内针和外径尺寸**。新购 5.5×2.5mm 分线须按连接器原厂图或实物匹配，不能靠外径相同判断兼容。

| 支路 | 供电安排 | 前置核对 |
|---|---|---|
| Dock | 原可用入口，或确认匹配的 J13 12V | 极性、可靠接触；首轮不并接多个主电源 |
| ADC、传感器、旋钮 | Dock 3V3 小信号支路 | 测 VDD/VREF；模拟地就近汇接 |
| CH9350L | 按模块指定输入，保证 USB Host VBUS 为 5V | TTL TXD 对 FPGA 应为 3.3V；模块 3.3V 供电能力不证明键盘有 5V |
| DAC | 由所购模块稳压电路决定用指定 5V 输入或指定 3.3V 输入 | 查稳压器型号、网络和焊桥；不同时送两路电源 |
| 灯带、AHCT125 | 独立已确认 5V 支路 | 大电流直接回电源分配点，不经 Dock 信号排针或 ADC 地线 |
| R18T | 以实物铭牌和原配电源为准 | 确认 AUX/LINE IN、电源接口及额定电流 |

所有信号设备共地，不同稳压器正极输出不硬并联。12V/3A 为标称 36W；降压模块持续电流存在 3A/5A 两种记录，未实测前不能保证任一数值。16 灯按每颗 60mA 保守估算约 0.96A；键盘、音箱等负载另计。先测空载输出，再按实际负载测压降和发热；不凭软件限亮代替电源预算。

MCP3208 SOIC-16 必须焊到匹配转接板并逐脚核对。四脚晶振需要独立匹配的封装转接方式，不能套用 SOIC16 板脚号。FSR 配刚性背板、软垫和尾线固定；板卡、DAC、电源与线束固定在绝缘底板上。

## 3. 主路线逐信号接线

以下编号为底板排针/FPGA 球号；ADC 编号是芯片本体脚号，转接板端子需要另行通断确认。

| 功能 | Dock 端 | 对端 |
|---|---|---|
| 键盘接收 | J5-5 / L9 | CH9350L TXD，3.3V TTL |
| 键盘返回 | J5-6 / N8 | 留空；当前输出恒高 |
| ADC CS | J5-9 / N6 | MCP3208 10 / CS |
| ADC CLK | J5-10 / D11 | MCP3208 13 / CLK |
| ADC MOSI | J5-11 / A11 | MCP3208 11 / DIN |
| ADC MISO | J5-12 / B11 | MCP3208 12 / DOUT |
| I2S BCK | J6-5 / B12 | PCM5102A BCK |
| I2S LRCK | J6-6 / C12 | PCM5102A LCK/LRCK |
| I2S 数据 | J6-7 / B13 | PCM5102A DIN |
| DAC 静音控制 | J14-12 / P6 | 首轮模块固定 XSMT 高时留空 |
| 外部晶振输入 | J14-10 / T7 | standard27 下留空 |

CH9350L 配置为 SEL 高（下位机）、S0 低/S1 高（state 2）、BAUD0/BAUD1 高（115200，8N1）。拨码 ON/OFF 与高低的映射按模块实际电路确认。**单向发送方式将模块 RXD 接模块 GND，N8 不连接该节点。** 此接法来自 WCH 手册第 6—7 页。不要把 N8 恒高输出同时短接到地。键盘插模块 Host 口，先确认其 VBUS；不把 USB 键盘直接接 FPGA 扩展排针。

报告解析期望 `57 AB 01` 后跟 8 字节 Boot 键盘报告。此链路只有 6 个普通键槽位，音色等控制键也可能占槽；演示先验证 Q、松 Q、Q/E/T 和弦及全部松开。UART 11 字节帧在 115200、8N1 下约 0.955ms，不包含键盘扫描、USB 轮询与音频输出延迟。

长按修复位于 `codex/optimization07-watchdog-20261022` 的功能提交 `4536e07`；本次文档修订所在集成分支仍未合入。装配前应选择完成合流、回归和构建绑定的固件，不要因文档更新就认为长按策略已改变。该修复默认持键期间不因静默超时清音，但持键拔线且设备不发通知时仍可能粘音，保留 Esc/S3 清音。

## 4. ADC、压力与弯音

MCP3208 16/VDD、15/VREF 接 3.3V；14/AGND 与 9/DGND 就近连接后回公共地。VDD、VREF 各就近放 100nF 去耦，VDD 旁再放约 1µF。未用 CH2—CH7 可接模拟地。SPI mode 0，现有默认约 250kHz，一次完整转换 19 个时钟约 76µs。

FSR 无正负极，接成 `3V3—FSR—节点—10kΩ—AGND`，节点进入 CH0/芯片 1。受压电阻下降，节点电压通常上升；松开、轻按、重按应始终在 0—3.3V 范围。首轮不在节点堆大电容，抖动明显可先试 10nF，再结合数字滤波和实测响应调整。

10kΩ 线性电位器固定端接 3V3、AGND，滑动端接 CH1/芯片 2。先断电识别两固定端，再上电调滑臂约 VREF/2；两端目标为约 ±2 半音，软件阈值按实际 ADC 码标定。旋钮缺席时用两个等值 10kΩ 电阻给 CH1 中位。压力是持续表情，不是普通键盘的逐键敲击力度。

## 5. DAC 与音箱

先核对 CJMCU-5102 的稳压器型号、输入/输出网络和背面焊桥，明确指定电源端后再上电。二极管档读数或模块名不能证明某孔可接 5V；模块孔号也不等于 PCM5102A 芯片脚号。

FMT 接低选择标准 I2S；SCK（某些板标 SCL）接低使用 BCK PLL 三线模式；DEMP/DMP 接低；FLT 使用已确认配置并记录，不能悬空。XSMT 首轮采用模块已确认的固定 3.3V，P6 留空。只有确认没有硬绑或其他输出驱动时，才可由 P6 独立控制，不能同时驱动。

standard27 为 24 位数据、每声道 32 位时隙、每帧 64 BCK，BCK=3.000MHz，LRCK=46.875kHz，MSB 相对 LRCK 翻转延迟一个 BCK。原厂明确支持三线 BCK PLL，48kHz/3.072MHz 有频率表依据；当前 46.875kHz 在所购模块上的锁定仍需实测。若不锁定，保留板载调试出口，后续完成 USB＋48kHz 板级档，不用 GPIO standard 位流冒充该组合。

I2S 三线宜短于约 15cm，旁有地参考，远离降压与灯带电源回路；边沿问题再评估源端小串阻。DAC 的 L/R/GND 接有源音箱 AUX/LINE IN，首次音量调低；不直接接被动喇叭或普通耳机，不把功放桥接输出当信号地。

## 6. 灯屏与历史替代方案

16 颗 WS2812B 经 5V 供电的 AHCT125 接 FPGA 3.3V 数据；拟用 J6-12/E15，缓冲后串约 330Ω 到首灯 DIN。AHCT125 所用通道 /OE 低、输入加 10kΩ 下拉，电源旁 100nF，灯带入口约 1000µF，未用输入固定。该分配尚未进入当前生产 RTL/CST，**固件实现及引脚核对前不连接信号**。

| ST7735S 拟用信号 | Dock / 球号 |
|---|---|
| CLK | J5-7 / N9 |
| DIN | J5-8 / N7 |
| DC | J6-8 / A14 |
| RST | J6-9 / B14 |
| CS | J6-10 / A15 |
| BL | J6-11 / D14 |

屏幕选明确支持 3.3V 逻辑的成品模块，BL 须为模块控制端，不把裸背光电源接 GPIO。使用屏幕自身显存，FPGA 只做窗口写入；128×160×16bit 全帧容量下界约需 18 块 BSRAM，与 32 声部的 26 块合计 44/46，不能随意增加全帧缓存。增加显示或效果前重新核算 BSRAM、乘法器与帧预算，报告实测资源。

12 个机械键与 MPR121 保留为替代方案，按对应历史接线表和 profile 使用。它们占用 USB、灯屏部分引脚：L9/N8 与 CH9350L 冲突，N7/A14/B14/A15/D14/E15 与拟用灯屏冲突。切换前断电拔掉冲突线，不把三套表混接。J7 RGB LCD FPC、J15 麦克风阵列共享相关扩展网络，保持空置。

外部 12.288MHz 有源振荡器是后续方向，用户已补充额定 3.3V；仍须确认实际脚序、CMOS 输出、OE 定义和转接板。仅在匹配档位下，经源端约 33Ω 接 J14-10/T7，并就近去耦；先单独供电测频率和幅度。不能把常见四脚排列当成未知型号的准确脚序。

## 7. 装配与验收顺序

先盘点实物、焊接 ADC 转接板、核对断电短路，再分别测 Dock、降压模块和外设电源。之后一次接入一个模块：PCM5102A、CH9350L、ADC/FSR、旋钮，最后灯屏。DAC 调试可通过既有 UART 发送音符；完成键盘后再做脱离电脑演奏。

| 检查 | 必须留下的结果 |
|---|---|
| 电源与极性 | Dock 3V3、ADC VDD/VREF、模块 VBUS、降压空载/带载值与供电方式 |
| 键盘 | 按下、松开、和弦、至少 5 秒长按、拔出帧记录；Esc/S3 可清音 |
| ADC | CH0 松开/轻按/重按原始码；CH1 两端与中位电压和码值 |
| I2S | BCK/LRCK 频率、64 BCK/帧、24 位标准 I2S 解码及模拟出声 |
| 演奏 | 单音、三音和弦、持续压力变化、弯音、F6 音色与音量控制 |
| 增强项 | 只验收已实现的灯屏状态；不把波形称为频谱 |
| 交接 | 源码提交、profile、构建收据、位流 SHA256、接线照片、演奏视频和一次实际冷启动 |

不安排与当前装配无关的重复老化。烧录前仍执行项目完整仿真门禁；定向测试或文档核准不能替代它。SRAM 断电会丢失，冷启动验收须记录实际加载方式，不能将 SRAM 演奏通过写成 Flash 自动启动完成。

机械键备选如需查上拉，断电测“信号→3V3”而不是“信号→GND”；按键触点另测“信号→GND”，板上并联通路会影响读数。普通键盘链路不装这 12 只上拉。

在仓库根目录，构建/烧录入口如下。只在接线、完整门禁、时序与构建绑定全部确认后运行烧录命令：

```powershell
& '.\output\handoff_milestone2_20261008\source\build\build.ps1' -Profile standard27
& '.\output\handoff_milestone2_20261008\source\build\program_sram.ps1' -Profile standard27
```

烧录脚本默认运行完整门禁；不使用 `-SkipSimulation` 绕过。切换 PT8211 调试前逐项检查目标封装/CST；旧 debug 的 clip_fold 会复用外置 DAC 信号脚，不能笼统认为所有 debug 档接线一致。
