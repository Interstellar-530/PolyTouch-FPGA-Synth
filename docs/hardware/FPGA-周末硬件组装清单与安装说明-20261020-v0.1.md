## 1. 周末要做出的整机

普通有线 USB 键盘直接插 CH9350L 下位机模块，FPGA 接收按键后实时合成声音。左手按琴键，另一只手按压力垫控制持续音量，旋钮控制弯音。外接 PCM5102A 输出到有源音箱。16 颗 RGB 灯显示演奏状态，1.8 英寸彩屏显示音色、压力、弯音、声部数和波形。电脑仅用于开发、调试和采集证据，演奏不依赖电脑软件音源。

你已确认采用上述直接连接方式，视觉配件按新增约 100 元以内安排。旧方案的 MPR121 触摸键、12 个机械琴键、MIDI 键盘和外部 12.288 MHz 晶振不列入本周采购。保留已有零件，不需要拆毁旧方案。

周末交付底线是“8 声部双音色＋键盘＋压力＋正式 DAC＋RGB 灯”；彩屏为推荐增强，32 声部为软件冲刺。未完成的增强功能不影响先装好主链路。当前只有电脑串口和板载耳机路径实际使用过；本文是经资料、源码核对的装配方案，不代表外设已经实测通过。

```text
USB 键盘 ──USB── CH9350L ──3.3V UART── FPGA
FSR 压力垫 ──分压── MCP3208 CH0 ──SPI──┤
弯音旋钮 ────────── MCP3208 CH1 ───────┤
                                         ├──标准 I2S── PCM5102A ──LINE OUT── 有源音箱
                                         ├──电平转换── 16 颗 RGB 灯
                                         └──SPI── 1.8 英寸 ST7735S 彩屏
```

## 3. 引脚基线与供电分区

本周以 `standard27` 为正式音频配置：板载 27MHz，实际采样率 46.875kHz，24 位数据、每声道 32 位时隙、每帧 64 个 BCK。当前 `debug8` 是 PT8211 调试配置，不能用于验证外接 DAC。新增灯、屏和键盘控制功能需要周五交付相应固件，现有位流不会自动获得这些功能。

下列现有信号与 `primer20k_i2s_27m.cst` 对照；新增显示信号是本次提出的分配，尚未写入 RTL/CST。底板 J5/J6/J14 的编号和球号按已转换资料及保留的原理图 PNG 视觉复核。J5、J6 的 **1/2 脚是 3V3，3/4 脚是 GND**，不能套用通用 Pmod 电源位置。按板上 1 脚标记和 GND 通断定位；球号是核对标识，不需要接触芯片焊球。

| 功能 | 底板排针 | FPGA 球号 | 对端 | 状态 |
|---|---|---|---|---|
| 键盘报告 RX | J5-5 | L9 | CH9350L TXD | 当前已有 |
| 键盘返回 TX | J5-6 | N8 | **本方案留空** | 当前输出恒高，单向方案不使用 |
| ADC 片选 | J5-9 | N6 | MCP3208 CS，裸片第 10 脚 | 当前已有 |
| ADC 时钟 | J5-10 | D11 | MCP3208 CLK，第 13 脚 | 当前已有 |
| ADC 发送 | J5-11 | A11 | MCP3208 DIN，第 11 脚 | 当前已有 |
| ADC 接收 | J5-12 | B11 | MCP3208 DOUT，第 12 脚 | 当前已有 |
| I2S BCK | J6-5 | B12 | PCM5102A BCK | 当前已有 |
| I2S LRCK | J6-6 | C12 | PCM5102A LCK/LRCK | 当前已有 |
| I2S 数据 | J6-7 | B13 | PCM5102A DIN | 当前已有 |
| DAC 静音控制 | J14-12 | P6 | 仅在 XSMT 未硬绑电平时连接 | 当前已有；首轮允许留空 |
| 灯带数据 | J6-12 | E15 | AHCT125 的 A 输入 | **拟新增** |
| 屏幕时钟 | J5-7 | N9 | LCD CLK | **拟新增** |
| 屏幕数据 | J5-8 | N7 | LCD DIN | **拟新增** |
| 屏幕命令/数据 | J6-8 | A14 | LCD DC | **拟新增** |
| 屏幕复位 | J6-9 | B14 | LCD RST | **拟新增** |
| 屏幕片选 | J6-10 | A15 | LCD CS | **拟新增** |
| 屏幕背光控制 | J6-11 | D14 | LCD BL | **拟新增** |

这里把灯带放在 J6-12，避免与 J14-6/T9 的板载 WS2812 数据网络共用。新增显示和灯带输出均按 LVCMOS33；Bank 1/3/7 必须维持本板默认 3.3V 配置。J7 RGB LCD FPC 和 J15 麦克风阵列连接器保持空着，它们与这些扩展网络共用。不要把表中 D11/A11/B11 与旧资料的 JTAG 位置混淆，3714 图纸中的 BL702 JTAG 使用另一组引脚。

供电分成三支：Dock 沿用已经工作的正规供电入口；3.3V 小信号支路供 ADC、压力分压和 LCD；独立 5V 支路供 CH9350L 模块的指定 5V 输入、RGB 灯和 AHCT125，DAC 供电取决于模块实际电路。所有信号设备共地，但不同电源的正极不互相硬并联。CH9350L 的 USB 键盘口必须有 5V VBUS，不能只给模块 3.3V 后假定键盘也能工作。

16 灯按保守的每灯 60mA 估算，全部白光约 0.96A，供电按此留量；程序把亮度限制到约 1/8。5V/3A 为外设预算起点，还需合计键盘等实际负载，不能用软件限亮替代电源设计。灯带正负电源直接回分线端子，不走 FPGA 信号排针、细杜邦线或面包板长电源轨。LCD 优先 3.3V 供电，以保持 3.3V 逻辑；若模块负载使 Dock 的 3V3 下跌，改用独立合格的 3.3V 稳压支路，只共地，不并联稳压器输出。

首次只给电源上电、暂不接信号，测量各支路。每次改线断开全套电源；电阻/通断档只在断电时使用。S1/S2/S3 的 1.5V 域不接任何外设 3.3V/5V 线。保留这些电气检查，能够避免周末直接损坏板卡。

## 4. CH9350L：键盘直接插模块

使用下位机/USB Host 模式，设置如下。表中的高低是芯片引脚电平，拨码 ON/OFF 与高低的对应要以模块说明或断电通断检查为准，不能统一认为 ON 就是高。

| 配置 | 要求 |
|---|---|
| SEL | 高，选择下位机 |
| S0 / S1 | 低 / 高，选择 state 2 |
| BAUD0 / BAUD1 | 高 / 高，115200bps |
| 串口格式 | 8 数据位、1 停止位、无校验 |
| TXD | 接 J5-5/L9；信号应为 3.3V TTL |
| RXD | **接模块 GND，启用厂商规定的单向发送方式** |
| FPGA J5-6/N8 | **留空，不能再接到已接地的 RXD** |
| 供电与地 | 按模块指定的 5V 输入供电，GND 与 FPGA 共地 |

此处修正了旧文档中“N8 恒高接 Host RXD”的建议。[WCH 原厂手册镜像](https://wiki.kamamilabs.com/images/b/bf/CH9350DS.pdf)第 6—7 页明确给出 state 2 拨码及下位机 RXD 接地的单向模式，本轮已转为 Markdown 并视觉核对。不要把模块 RXD 与 GND 短接的同时仍连接 FPGA 输出。

断电设置拨码并接线，再把 USB 键盘插模块的 Host 口，最后上电。FPGA 期望按键报告以 `57 AB 01` 开头，后续 8 字节，共 11 字节。115200bps 下发送这一整帧约 0.955ms，87µs 只是一个字节的时间；不能把它当整机演奏延迟。

首轮按 Q、松 Q，再按 Q/E/T 和弦、全部松开。持续按一个键 5 秒，确认不会在两秒附近误清音。原厂手册没有保证 state 2 每秒发送心跳，现有软件的“两秒无帧即断线”需要在周五前改为可配置，并以实物抓帧确定是否启用。默认不依据“静默”判断拔线；无可靠设备断开通知时，用 Esc 或板载 S3 清音，屏幕也不能伪造“已连接”状态。这个限制必须在最终演示说明中保留。

当前报告只有 6 个普通键槽位，控制键也会占用普通键位置。演示选不超过 6 键的和弦，并提前验证常用组合；“全键无冲”营销说明不代表此链路能够同时报告 8/32 键。32 声部评分测试由 FPGA 内部测试模式生成独立音符事件，声音仍实时合成。

## 5. 压力与弯音

MCP3208 采用 3.3V 供电和参考。裸片第 16 脚 VDD、第 15 脚 VREF 接 3.3V；第 14 脚 AGND 与第 9 脚 DGND 就近连接后回公共地。VDD、VREF 各放 100nF 到地，VDD 旁再放约 1µF。CH2—CH7 本轮不用，可接模拟地。模块版按信号名接，不能把模块端子序号当成裸片脚号。

```text
3V3 ── FSR402 ──●── 10kΩ ── AGND
                └── MCP3208 CH0（裸片 1 脚）

3V3 ── 电位器固定端 A
AGND ─ 电位器固定端 B
CH1 ── 电位器滑动端 W（裸片 2 脚）
```

FSR 无正负极；按压后节点电压通常上升。先用万用表确认“松开、轻按、重按”均在 0—3.3V，软件再标定，不把某个 ADC 码写成所有传感器通用值。首轮不在 FSR 节点加大电容；如抖动明显，可先试 10nF，再调整已有数字滤波，避免增加可感知延迟。

电位器先断电测出两个固定端和滑动端；转动时固定端之间阻值保持约 10kΩ。中位调到 VREF/2，默认对应不弯音；两端目标为 ±2 半音。没有装旋钮时，用两个等值 10kΩ 分压给 CH1 中位，不悬空、不直接接地。

压力垫安装在刚性底板上，上面覆盖柔软的受力垫，让压力落在有效感应区，尾线在感应区外做应力释放。首版把压力定义为“持续表情”，不声称普通键盘能检测每键敲击力度。软件安排以压力控制响度、旋钮控制弯音，两个物理输入互不替代；压力同时影响亮度时，也仍只算一个压力维度。

## 6. PCM5102A 正式音频出口

先核对模块背面的稳压器型号、原理图/卖家电源说明和实际网络。**不能只凭二极管档读到约 0.6V 就认定某脚可接 5V。** 已确认板载稳压且输入指定 5V时，接模块 VCC/VIN，3.3V 输出端留空；确认是直接 3.3V 供电板时只接指定 3.3V 输入。无法确认则先不送电，使用已验证板载耳机路径继续软件演示。

| 模块丝印 | 接法 | 说明 |
|---|---|---|
| BCK | J6-5/B12 | 3MHz |
| LCK/LRCK | J6-6/C12 | 46.875kHz |
| DIN | J6-7/B13 | FPGA 输出音频数据 |
| GND | J6-3 或公共地 | 与信号参考地一致 |
| SCK，某些模块标 SCL | GND | 三线 I2S 模式；不是 I2C 时钟 |
| FMT | GND | 标准 I2S |
| DMP | GND | 关闭去加重 |
| FLT | 首轮按模块已确认配置，通常低；可后续比较高电平低延迟模式 | 记录实际电平，不悬空 |
| XMT/XSMT | 首轮固定到模块 3.3V，P6 留空 | 若模块已硬绑，无需加线；不能用两个输出驱动同一节点 |

若要由 FPGA P6 控制 XSMT，先确认模块没有把该节点硬接固定电平，再改为只由 P6 驱动。固定高方式已经可以展示，周末不为此增加不必要改线。I2S 三线尽量不超过约 15cm，配近旁地线并远离灯带电源线；出现边沿振铃时再考虑源端小串阻。

PCM5102A 是线路输出，接有源音箱的 AUX/LINE IN，或正规线路输入耳放；不直接接被动喇叭或普通耳机，也不用蓝牙播放链路验收延迟。首次音箱旋钮调低，先单音，再三音和弦。[TI 产品说明](https://www.ti.com/product/PCM5102A)可用于核对线路输出及三线接口能力；46.875kHz 在本模块上的锁定仍要实测。

## 7. RGB 灯和彩屏

### RGB 灯的接线与画面

优先购买已焊线的 5V RGB 灯，不买 RGBW 或 12V 灯带。外部灯带输入从 J6-12/E15 经 AHCT125 单向缓冲，再串 330Ω 接第一颗 DIN；第二段灯条 DIN 接第一段 DOUT。灯条方向按 DIN/DOUT 或箭头核对。

AHCT125 的 VCC 接外设 5V，GND 接公共地，所用通道的 `/OE` 拉低，A 接 FPGA，Y 接灯带；A 端加 10kΩ 下拉以免 FPGA 配置期间浮动。未用通道输入固定、输出留空、使能置高，按所购成品板的端子标识接，不按未知转接板猜脚号。芯片电源边放 100nF；灯带输入处并 1000µF 电解，正极接 5V。AHCT125 的输出是 5V，绝不回接 FPGA。[TI AHCT125](https://www.ti.com/product/SN74AHCT125)、[NeoPixel 接线建议](https://learn.adafruit.com/adafruit-neopixel-uberguide/best-practices)。

周五软件应提供：前 12 灯显示 C—B 的音级，按住亮、松开随包络变暗；后 4 灯显示压力大小；电钢琴用蓝/青色、吉他用橙色；削波短闪红。多个八度的同名音用计数/最大包络合并，松开一个音不能把另一个仍在发声的同名音熄灭。首轮限亮约 1/8，不做与演奏无关的长开场动画。

### 彩屏的接线与画面

使用第 3 节表中 6 根显示信号，加 VCC=3.3V 和 GND，共 8 线。以模块丝印为准，不按线缆颜色猜线序。BL 是所选成品模块的背光控制端；不要把裸屏 LED 电源直接接到 GPIO。先显示色块与 ASCII 字，再打开压力条和波形。[微雪模块说明](https://docs.waveshare.net/1.8inch_LCD_Module/)。

屏幕只显示真正来自 FPGA 的状态：`EP / GUITAR`、当前八度、`ACTIVE 3/8` 或实际配置的声部上限、压力条、弯音中心、效果开关、小幅波形。波形不是频谱，压力条也不是音量频谱。没有实现 FFT 时不能写“实时频谱”；没有完成 32 声部集成时不能显示“32 VOICES”作为已实现指标。

显示刷新以 10—15Hz 为目标，音频、ADC 和灯带独立运行。屏幕用自身显存，FPGA 按窗口写入；本周不做中文全字库和全帧缓存。屏幕未按时完成时拔掉显示线，灯和声音仍应正常工作。

## 8. 两天的组装顺序

| 时间 | 你负责 | 队友负责 | 当场得到的结果 |
|---|---|---|---|

## 9. 只保留展示所需的短检查

不安排一小时/两小时老化或反复多轮盲听。保留上电前短路和电压核对；软件开发时按改动做定向自检，真正烧录前仍通过项目完整 RTL 仿真门禁。硬件侧用一次约 10 分钟的展示脚本检查单音、三音和弦、五秒长按、松键、压力渐强、弯音、音色切换，以及实际已实现的效果和灯屏反馈，验证 Esc 清音。最后一次真正断电再上电，记录位流加载方式；SRAM 断电会丢失，不能把手动重载写成 Flash 自动启动完成。

USB 键盘本身存在扫描和 USB 轮询延迟，不能仅测串口到 I2S 就宣称整机 ≤5ms。周末优先测清楚键盘动作到模拟输出或可定义的输入触发到输出；做不到完整物理起点测量时，保存分段结果并标明范围。

| 现象 | 优先检查 |
|---|---|
| 键盘完全无报告 | Host 模式、state 2、模块 USB 口 5V、TXD 方向、共地、波特率 |
| 长音约两秒自动停止 | 没有心跳时误触发旧 watchdog，不要先怀疑 FSR |
| 按压力无变化 | 是否误烧 `debug8`、是否仍在演示模式、CH0 是否接对、映射是否启用 |
| 整体音量偏低 | 先查主音量与 24 位低通增益，再调音箱；不要同时改多个增益 |
| 正式 DAC 无声 | 电源、XSMT/FMT/SCK、BCK/LRCK、固件是否为正式档 |
| 灯乱闪或音频随灯变吵 | 灯带供电回路、公共地、AHCT125、DIN/DOUT 方向、亮度 |
| 屏幕空白/偏移/反色 | 芯片型号、RST/DC/CS、初始化与窗口偏移，先不改音频 |
| 和弦少音 | 键盘矩阵冲突、6 键报告上限和实际声部数分别排查 |

## 10. 出门前的交接

给键盘贴两排音符与 F6/F7 等功能标签，底板贴电源电压和插头方向；把音色切换、效果旁路、Esc 清音、音量恢复写成一张操作卡。保存最终位流、SHA256、对应源码/波表、两张全景接线照片和一段完整演示。提交材料中区分“8 声部整机”“32 声部候选”“计算原型”，以周日实际结果为准。
