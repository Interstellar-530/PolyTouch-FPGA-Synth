# HDMI 显示与两首测试曲

本次生产源码在 `output/handoff_milestone2_20261008/source`。HDMI 档为板载 27 MHz、8 声部、PCM5102A 外接 I2S 音频，显示输出为 1280×720。HDMI 内没有音频，声音继续通过原 DAC 与功放输出。

上电默认《晚夜微雨问海棠》。板载 S1 短按并松开后，在《晚夜微雨问海棠》和《旷古回响》之间切换，并从选中曲目的开头播放；原 S1 短按切伴奏功能由切曲替代。切曲会清除旧事件与持音，退出暂停或手动模式进入自动演奏。S1 长按约 600 ms 继续选择音色；S2 保留速度档位；键盘 F7 保留手动/自动切换，F8 保留暂停/继续。原伴奏指示灯现在表示选曲：灭为第一首，亮为第二首。

《旷古回响》采用本地 `song_kuanggu.py` 的 13 小节 bridge 数据，100 BPM、208 个十六分音符单位，约 31.2 秒循环；高潮段尚未录入。旋律含 46 个发声音符，伴奏为 13 组三和弦。现有事件播放器在旋律换音处发送 Note Off/On，因此本地试听渲染里的连续换音和 50 ms 重叠没有完全复制到硬件。

## 显示屏接线

用户购买的是商品“树莓派显示屏4b显示器7寸屏幕HDMI 液晶屏 IPS带外壳 创客教育”的 7 寸 IPS 带触摸、有边框款。淘宝短链未能读取详细参数；用户确认的屏幕接口丝印为 HDMI、POWER、CTOUCH。当前不能仅凭该丝印确定供电电压、电流、USB 插头规格及支持的视频时序。

| 屏幕接口 | 接法 |
|---|---|
| HDMI | 用与两端插座匹配的 HDMI 线连接 Tang Primer 20K Dock 的板载 HDMI 口；不需接 PMOD，不使用 DSI/RGB 排线。 |
| POWER | 接屏幕配套电源，或严格按屏幕标签额定电压、电流选电源。若标签确认 5V，才使用相应 5V 电源；不要从 FPGA GPIO 或 PMOD 3V3 给屏供电。 |
| CTOUCH | 单独的触摸数据通道。当前固件尚未实现触摸解析，显示验证时可先不接。测试电脑识别时，用 USB 数据线接电脑 USB Host。 |

建议先在电脑上确认屏幕能显示 1280×720@60Hz，再接 FPGA；7 寸面板原生分辨率与 HDMI 接受的时序不一定相同。当前没有读取该屏 EDID，也没有确认它的缩放能力。接好屏幕后需要观察整幅画面、边缘文字、动态波形和切曲后的画面。固件布局布线通过不等于该商品已完成实机显示验收。

板卡接口参考：[Sipeed Tang Primer 20K 官方说明](https://wiki.sipeed.com/hardware/en/tang/tang-primer-20k/primer-20k.html)。同名商品检索记录仅用于确认商品名称：[商品索引](https://tao.hooos.com/goods_616266214049.html)，不将其他品牌显示屏参数套用到本商品。

## 复用现有 CH9350L 测试触摸

已从本地对话“这是到位的CH9350L模块，告诉我应该如何把它连接到开发板上”（2026-10-26，ID `01a177b9-ec94-7360-be5a-9db58086dd63`）重新查看正反面照片。模块是双层 USB-A 插座（上下两个口），五位拨码 SEL/BA1/BA0/S1/S0，背面丝印表写明 SEL = 1 下位机 / 0 上位机、S1/S0 = 工作状态、BA1/BA0 = 波特率（默认 115200）；芯片表面版本看不清。历史键盘接线记录是下位机、115200、state 2，模块 TXD 接 Dock L9（J5-5），RXD 接模块 GND，双方共地，N8 不接 RXD 接地点。供电排针在照片中被遮挡，不凭排针位置猜正负极。

厂商手册 V2.6 记载新增对部分触摸屏的支持，兼容性还取决于模块版本和屏幕 USB 报告格式。模块是**双层 USB-A**：上层丝印 `上层USB DM DP`（第 1 口），下层是 `HM/HP`（第 2 口），对应 CH9350L 下位机模式的两组 USB，键盘和触摸可以同时插、共用一条 115200 串口，靠帧命令字区分。触摸优先插下层；没帧再换上层，两个口都没帧说明是 HID 类别不匹配。第一步把 CTOUCH 插到键盘没占的那个口，抓取模块串口数据，检查点击、拖动、抬手是否有稳定且可区分的帧。屏幕仍按自身额定规格供电。

工程现有 `ch9350_rx.v` 只输出键盘 `0x01` 帧，尚未输出鼠标/触摸坐标。若兼容，应补对应帧解析、坐标缩放与方向校准、点击区域、按下/抬手去重，再将事件接入切曲、暂停和音量控制。先从单点触摸开始；多点触摸需要额外读取联系人数与 Contact ID，不能把它直接视为键盘按键。

完整的三条接入路径（CH9350L 直挂 / I2C 直取触摸控制器 / 外挂 MCU 当 USB 主机）、判据测试与
RTL 改动清单见 `docs/hardware/FPGA-7寸HDMI触摸屏接入方式-20261028-v0.1.md`。
