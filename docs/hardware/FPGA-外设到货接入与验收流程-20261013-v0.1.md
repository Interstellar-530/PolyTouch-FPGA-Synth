# 外设到货后的接入、调试与验收

适用 PolyTouch FPGA、Tang Primer 20K Dock 3714，器件 GW2A-LV18PG256C8/I7。开发板和外设集中在用户处，队友远程开发，仅 10/18 周日共同组装。本文件记录本项目后续逐件到货的处理方式，不把“采购/到货”认定为“功能已完成”。

## 每次到货如何报告

消息写明器件名称、实购型号/选项、数量、附带转接板/电源/线材和准备使用的接口；实物丝印、正反面端子或跳线与商品图不一致时，以实物照片和对应型号手册核对。额定电压、接口电平不清楚的器件先完成识别。已经连接哪些器件、当前固件版本也一并记录，避免多个模块占用同一引脚。

收到到货报告后，给出一份针对该件的说明：型号与电气核对；逐端子接线表和共享接口限制；当前固件是否具备驱动；单模块调试步骤、命令/测试模式与预期结果；仪器位置和验收数值；故障定位、回退及接入整机后的回归。缺驱动时先明确需要开发的 RTL 和自检，不假设仅接线就能工作。

状态依次记录为：已购 → 已到货 → 型号/电压核对 → 单模块接入 → 单模块通过 → 整机回归通过。每次保留日期、Git 提交/位流校验、接线照片、供电/负载、日志及原始仪器数据；不靠口述或单张成功截图判断验收。

## 当前已知状态与逐件验收方向

下列数值是方案/建议验收口径，待型号确认后细化。本次没有实装、烧录或新增 RTL。按键已到，其余器件未统一确认到齐；个别到货状态以用户之后逐件报告为准。

| --- | --- | --- |
| 12 路独立 GPIO 按键 | 按键已到；生产顶层尚无外接 12 键输入层 | 先一键，再 12 键；每次按/松各一个事件，抖动不重复触发；四键同按、Panic、模式切换后无遗留音 |
| MCP3208-CI/SL | SOIC-16 裸芯片；SPI 驱动待实现 | 转接板焊接/电源正确；3.3 V 参考；约 250 kHz 起调，CH0/CH1 注入零、中、近满量程读数顺序/位宽正确，误差与实测参考/噪声记录对应 |
| FSR402 | 型号已确认；压力滤波和映射待实现 | 接 ADC CH0；无/轻/重按相对值可区分、总体随压力增大而上升；保持同一音高能连续改变表情；固定安装后标定，不以牛顿值或单个 LSB 作硬性承诺 |
| WX112(050) 10 kΩ | 阻值已确认；持音弯音待实现 | 两端到 3.3 V/AGND，滑动端 CH1；测端点/中位；持音时转动能改变频率，包络不重新起音，端点限幅正确 |
| 7050 12.288 MHz 有源晶振 | 频率已确认，额定电压仍未知 | 完整型号/订单确认供电及 OE；先在转接板测起振、幅度和频率，再接已核对 GCLK；频偏按该件规格验收，不从封装猜电压 |
| CJMCU-5102 DAC | 商品称 PCM5102，A 后缀及跳线待核对；标准 I2S 待实现 | 确认 FMT/XSMT/SCK 和 3.3 V 接法；测 LRCK 48 kHz、BCK 3.072 MHz、每帧 64 BCK、一位延迟；线路输出能发正弦/和弦，数字静音与削波测试结果可记录 |
| P15W 功放 | DC 8-24 V 的扬声器功放，芯片/有线输入需看实物 | 独立合适电源及负载；先低音量有线输入再加大；无蓝牙抢源/供电掉压；输出不接耳机或示波器普通地夹，噪声和失真在给定条件下记录 |

## 通用接入顺序

1. 断电核对模块端子、电源、地、I/O Bank 和与现有器件共用的网络。Dock J5/J6/J14 为 2×6 自定义排针：1/2 为 3.3 V，3/4 为 GND，5-12 为信号；编号按丝印/方焊盘及图纸确认。当前 21 路引脚方案未写入生产 CST，接入时重新核对。[现有详细接线方案](FPGA-硬件连接与演奏操作-20261013-v0.1.md)
2. 单独检查新模块供电、转接板焊接和连续性。对未知晶振电压、固定 DAC 跳线或高电压功放不采用试接推断。ADC 模拟电压只进入 ADC，不直接进入 FPGA GPIO。
3. 核对所用驱动和测试固件，先通过新增自检及全部 RTL 门禁，再做综合/PnR 和 SRAM 单模块测试。转运断电会丢失 SRAM 临时固件；过去记录是 SRAM 0x5633、Flash 0xFCF0，收到板后先确认版本/恢复基线。串口号按当前电脑枚举结果选择，不固定假设仍为 COM13。
4. 先固定参数/单输入，测数字接口；再接真实传感器或模拟负载。每次只新增一件，保存接入前后的对照数据。
5. 单模块通过后接整机，复测和弦、松键/重按/窃取、演示/手动/Panic、采样率和削波；仪器采集由用户完成，队友依据原始数据远程分析。
6. 验证通过才更新状态和接线图。保留上一版本恢复包，最终稳定版本再更新 Flash 并验冷启动。整机基础最终还需证明二维独立输入、四声部、实时变调/ADSR、标准 I2S 和物理控制到 DAC 输出最坏 ≤10 ms。

PCM5102 系列为线路输出，模块上有 3.5 mm 座不代表可直接驱动低阻耳机。[TI 官方器件资料](https://www.ti.com/product/PCM5102A) MCP3208 的精确接口、输入范围与误差以对应手册和实测参考为准。[Microchip 官方资料](https://www.microchip.com/en-us/product/MCP3208)

后续到货时新增该器件的具体记录，当前不预填测量结果。此流程保存在工作区供后续对话使用，不创建自动监控或代替用户进行现场接线。
