# standard27 外设接口时序预算

适用：Tang Primer 20K Dock3714、GW2A-LV18PG256C8/I7版本C，27MHz系统时钟、46.875kHz/24bit I2S、250kHz MCP3208。该预算与primer20k_i2s_27m.sdc中的路径上界及实现报告一起使用，不将CST引脚分配等同于时序通过。

## 预算方法

I2S与SPI均由27MHz系统时钟的使能产生，未用输出时钟驱动内部寄存器。SPI事务从任意系统拍开始，不假设每次事务与全局周期分频相位固定。SDC对六个动态输出（i2s_bck/lrck/din、adc_cs_n/sck/mosi）施加0…20ns路径包络，对adc_miso输入到寄存器施加20ns最大路径上界，保留所有内部单周期检查。`adc_miso`不设置人为的最小路径约束，因为它不能代替外部器件保持时间分析，且会把内部时钟偏斜误报为端口保持违例。接口的建立、保持由下面的真实调度预算和延迟模型共同证明；不靠多周期或整块假路径隐藏问题。

板级假设：单向走线加连接器传播延迟不超过10ns；比较两个信号时按最坏20ns差异处理；另外保留10ns时钟/阈值/输入寄存器建立时间等保护额度。它们是工程假设，现场必须检查线长、负载、边沿和串扰。超过预算的线缆或电平转换器需重新核算。

| 项目 | 最短可用窗口 | 扣除项 | 剩余预算 |
|---|---:|---|---:|
| I2S DIN/LRCK到BCK上升沿建立 | 5×1000/27=185.185ns | 输出差异20＋板级差异20＋保护10＋需求20 | 115.185ns |
| I2S 上升沿后DIN/LRCK保持 | 4×1000/27=148.148ns | 输出差异20＋板级差异20＋保护10＋需求20 | 78.148ns |
| ADC MOSI建立/保持 | 54×1000/27=2000ns | 输出差异20＋板级差异20＋保护10＋需求50 | 1900ns |
| ADC CS下降到首个SCK上升 | 2000ns | 输出差异20＋板级差异20＋保护10＋需求100 | 1850ns |
| ADC MISO有效到FPGA采样 | 2000ns | SCK输出20＋往返板级20＋ADC有效时间800＋输入路径20＋保护10 | 1130ns |
| ADC 高/低脉宽 | 2000ns | 同输出边沿路径差异20＋保护10＋保守器件假设500 | 1470ns |
| ADC CS禁用间隔 | 顶层至少27拍=1000ns | 输出边沿差异20＋保护10＋需求500 | 470ns |

MISO保持的下一次可能变化发生在采样后的SCK下降沿，至少隔54个系统拍；即使外设最小输出延迟为0，仍有2000−20−20−20−10=1930ns保护后间隔。CS间隔预算仅使用生产top已经预留的1µs，不把额外启动状态机延迟算作收益。脉宽和命令位时序须同时由既有SPI/I2S自检确认。

## 器件依据与数值边界

[Microchip DS21298E](https://ww1.microchip.com/downloads/aemDocuments/documents/APID/ProductDocuments/DataSheets/21298e.pdf)第3页明确列出MCP3208的DIN建立/保持各50ns、CS建立100ns、CLK下降到DOUT有效最大200ns、CS禁用500ns及CLK高/低各250ns，但该页表头默认条件为5V。3.3V设计不把这些数值直接当作器件保证，而是在本项目预算中把DOUT有效时间放宽到800ns、CLK高低脉宽要求放宽到500ns。它们是保守工程假设，仍须用实物波形确认；若实际超过预算，应降低SPI频率或调整采样时机后重验。

[TI SLAS859C](https://www.ti.com/lit/ds/symlink/pcm5102a.pdf)第11页只列SCK与XSMT时序，没有给DIN建立/保持表。[TI技术支持答复](https://e2e.ti.com/support/audio-group/audio/f/audio-forum/1542019/pcm5102a-setup-hold-time)建议参考同类器件8ns；本项目为DIN/LRCK设置更保守的20ns设计需求，属于工程预算，不是从现行手册虚构出的保证值。46.875kHz下PLL锁定和模拟输出依然属于实物待验收。

## 异步输入与实现证据

UART RX、键盘UART RX和按键不能因为只有一个内部时钟就称为同步输入。键盘UART含两级同步采样；板载UART与按键按现有同步/消抖路径处理。首级同步触发器的亚稳态风险不由普通同步建立/保持分析保证，本修正没有对它们添加宽泛假路径，也不声明MTBF已量化。

新增SDC包络通过Gowin真实实现核对是否识别、是否覆盖目标端口及是否存在违例；若没有生成对应的受约束路径，不能仅凭零违例放行。最终候选说明记录原始路径结果、资源、内部时序、位流和参数收据。该组合是数字接口预算证明，物理引脚、电压、电源、模拟输出与线缆实测另验。
