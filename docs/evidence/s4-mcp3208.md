# S4 MCP3208 SPI 数字交付

本交付为独立的 MCP3208 mode-0 SPI 主机和引脚行为模型。主机文件为
`output/handoff_milestone2_20261008/source/rtl/audio/mcp3208_spi.v`，模型为
`source/sim/mcp3208_model.v`。一次 `start` 请求锁存 `channel[2:0]`，在
`cs_n=0` 下发送 19 拍 DS21298E 帧：第 1～5 拍 DIN 为
`START=1,SGL=1,D2..D0`，第 6 拍 DIN 无关（器件在该下降沿结束采样保持），
第 7 拍 DOUT 是器件驱动的 null 位，第 8～19 拍 DOUT 依次是 B11..B0（MSB
先出，下降沿输出、上升沿锁存）。主机在第 8～19 个上升沿采样 12 位数据，
并在整帧最后一个下降沿才更新 `data` 与脉冲 `done/data_valid`。

默认参数是 27 MHz 时钟、约 250 kHz SPI 时钟（每半周期 54 个系统时钟）。
SPI 分频器、CS、SCLK、MOSI、MISO 全部独立于 `sample_tick`，所以 ADC 事务
不会阻塞 I2S/音频帧。同步复位会在下一个时钟沿令 CS/SCLK 回到空闲态；事务
中途复位或 CS 被拉高后可以重新发起请求。`adc_data` 是保持寄存器的别名，
便于控制面读取。`SPI_HZ` 低于 1 Hz 时由守护 localparam 避免除零。

`source/sim/tb_mcp3208_spi.v` 覆盖 0、1、2047、2048、4095 五个边界码在
CH0 与 CH1 上的读取，8 路通道同时持有互不相同的非零码值以排除通道译码
错误，CH0/CH1 双通道交替，256 例 xorshift32 固定种子随机通道与码值，
busy 期间 start 被忽略，帧内第 3、8、15 拍复位恢复，并由线级审计逐拍核对
19 拍帧长、DIN 命令位、CS 低电平期间不得提交、每帧仅一个 `done`。

`source/sim/tb_mcp3208_i2s_coexist.v` 在 27 MHz 同源时钟下并行运行 PT8211
发射器与 ADC 主机，检查 tick 间隔严格 576 拍、SCLK 半周期严格 54 拍。
`source/sim/tb_mcp3208_params.v` 覆盖生产参数、过高 SPI_HZ 的钳位和
`SPI_HZ=0` 的守护。运行命令：

```powershell
$env:PATH = 'D:\NanjingUniversity\FPGA\msys64\ucrt64\bin;' + $env:PATH   # 否则会缺少 msys DLL
Set-Location output/handoff_milestone2_20261008/source
iverilog -g2012 -I . -o sim/tb_mcp3208_spi.vvp `
  sim/tb_mcp3208_spi.v sim/mcp3208_model.v rtl/audio/mcp3208_spi.v
vvp sim/tb_mcp3208_spi.vvp
# tb_mcp3208_spi PASS (vvp exit 0)
```

2026-10-15 的独立复核发现初版帧只有 18 拍、采样窗口提前一拍，读回值会
整体右移一位（4095 读成 2047），且器件模型与主机共享同一错误假设所以自检
无法发现；本轮已按数据手册修正主机、模型和自检，并新增两台测试。门禁现在
包含 14 台，详见 [S4 复核记录](../s4-review-20261015/README.md)。

完整门禁 `source/sim/run_simulation.ps1` 已包含三台 MCP3208 测试。MCP3208
实物供电、参考电压、引脚 Bank 电平和 ADC 噪声仍须到货后逐件验收；本包只
声明 RTL/模型 PASS，不声明硬件 PASS。
