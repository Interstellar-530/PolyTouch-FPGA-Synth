本轮确认效果后即停止扩测。没有修改生产代码、原测试、约束、配置或硬件。结论见 `docs/reviews/FPGA-力度边界优化效果审核-20261021-v0.1.md`。

`review_results.json` 记录审阅引擎 SHA256、命令退出码、旧版预期失败、已知旧失败以及构建内容匹配。`independent_equivalence.log` 是独立新旧引擎对照：768 帧、2304 组有符号分量和，检查四/八声部、不同精度和乘法器配置、音色模式及帧内输入变化。`source/` 保存该测试及由基线原样改模块名得到的参考引擎；参考引擎输入使用已知合法力度，不由待测输出反推结果。
