# 整体算法架构优化与保存点

2026-10-16，基线为 0eb82e8。停止新增功能，检查从控制输入、音高映射、共享波表、插值、包络、混合、压力增益到 I2S 的整条路径。本轮两次获得用户确认，先共享四路弯音乘法，再统一全局音色及压力增益乘法。板级接口、四声部、两张 512 点波表、现有控制命令、逐级数值舍入及饱和公式保持。

最终架构将一切实时乘法集中到 top 中一个带使能的有符号 18×18 乘法器。共享引擎先执行弯音、插值、包络和力度，完成后由全局混合器使用同一结果寄存器执行音色与压力增益。两段通过请求和操作数连接，不会同时使用乘法器，仿真对冲突逐周期断言。输入相位增量、弯音比率和重触发状态在采样节拍锁存；各声部随后按顺序更新相位，因而测试改为按帧核对，而非要求四个相位寄存器在同一系统时钟沿更新。

共享引擎的 32×32 运算收窄为 18×18；32×17 弯音乘法分解为高低两个 16×17 产品，保持完整 32 位输出。相邻插值产品连续发射，等待态与其他运算重叠。默认 ADC 中心 2048 的除法被精确移位及端点判断替换，其他中心保留原公式。四段弯音比率差值使用精确的移位加法，消除最后一个控制插值 DSP。音色混合仍使用上一轮的差值分解公式。全局结果比输入分量和有效晚数拍，压力参考测试已改为捕获输入帧、在结果有效时检查。

DSP 等效按 MULTALU36X18 一块、MULT18X18 半块折算，下降约 91.7%，以增加 395 个逻辑单元、227 个寄存器为代价。最终只有一个物理 18×18 乘法器；这不表示 LUT、延迟、音质的所有目标同时达到全局最优。报告为 Gowin 1.9.11.03 综合结果，未进行 PnR，不能据默认 100 MHz 综合估算宣称实物时序已经通过。

定向验证测得：无弯音调度由 84 拍缩短至 60 拍，加入共享弯音后为 76 拍，完整主输出在 81 拍完成，即 12.288 MHz 下约 6.592 µs，每帧剩余 175/256 拍。共享乘法器每帧仅使能 34 次，寄存器使能比例 13.28125%；这不是实测整机功耗下降百分比。采样率仍为 48 kHz，声部仍为四个，没有通过降音质或降采样率换资源。

四项新增自检通过：2048 个随机帧保持原共享引擎分量和逐位一致；另 2048 个随机帧覆盖完整 32 位增量、弯音比率和重触发，与旧四路并行实现逐位一致；全部 4096 个 ADC 码在默认和非默认中心下保持压力状态、弯音及相位增量一致；4096 个压力码、全部音色权重及正负边界下，共享主增益与原本地乘法版本输出和削波计数一致。统一顶层测得 1184 个 I2S 帧、1104 个非零帧、1048 次帧相位检查，通过 81 拍/34 次请求断言。压力、长段 I2S 的最新结果以 unified-top/results.json 为准。两档工程及 13 项构建检查也通过，见 build-regression。完整仿真门禁未执行，未烧录或推送 GitHub。

整体盘点仍有三个限制。第一，四声部同相、满包络、力度 100、压力全开时，当前权重 64 的理论峰值 44173，超过 32767；纯波表端点峰值可到 51000，需约 3.84 dB 余量。直接多右移一位可提供约 6 dB 余量，但会改变单音响度，本轮未作此行为改变。第二，弯音相对连续 ADC 理想映射最大误差约 1.228 音分；精确除法消除保留旧校准结果，没有悄悄调整锚点。第三，每个 ADC 通道新数据约 1 kHz，标准 SPI 245760 Hz、事务约 77.31 µs；现有 2 kHz 调度不等于单通道 2 kHz。原 ADC 顶层软复位后保留旧原始码，也仍待独立修复验证。

进一步增加到 32 声部仍需另做调度及状态存储规划，不能直接从当前资源余量宣称已经支持。当前主要指标余量已转移到控制调度、信号余量和实际输出测量。下一步优先决定保留单音响度还是保证全幅四声部无削波，再做对应数值策略；同时需要实际 PnR、DAC 延迟、噪声及传感器校准证据。
