# FSR 消音实现与 SRAM 下载

用户要求将 FSR 改为延音或消音中的一个。本次选择按住消音、松开恢复，演示和手动演奏都适用。生产音频接口、串口协议与 ADC 接线不变；CH0=FSR，CH1=旋钮弯音，T7 不接。此前用户已反馈旧 standard27 的 CJMCU 音频恢复，但并未提供仪器测量。

## 修改依据与范围

新增 fsr_mute.v，复用原有中值/IIR 压力滤波，以有效 ADC 组更新控制状态，按下阈值 512、松开阈值 256。FSR 只控制消音，不再连续控制音量。顶层用 UART 消音与 FSR 消音的逻辑或驱动现有渐变链路，并将低通精确零收敛与 LED 指示改用同一条件。FSR 不改变曲目、相位、包络或音符分配，旋钮弯音保留。

build/sources.list 加入新模块。sim/run_simulation.ps1 为引用顶层的旧测试补充新模块，并补齐升级后 FSR 集成台的完整前端依赖；Quick 加入阈值/滞回测试。旧压力集成台改测新语义，ADC 采样测试保留原有独立参考与尖峰检查，音频台将压力默认值改为未按下。原全局压力增益库与独立单元测试保留，生产顶层停用该增益功能。旧顶层压力参数保留作源码兼容。

## 验证证据

定向测试 4/4 通过：tb_pressure_top 从独立接收模型解码 4543 帧 I2S，覆盖演示/手动按压消音、松开恢复、左右声道一致、时钟连续、串口消音优先级、弯音以及不重触发音符；tb_fsr_mute 完成 1031 项阈值/滞回、更新使能、复位和旁路检查；tb_control_sampling 检查 210 个新鲜 ADC 组、420 次转换、单转换尖峰抑制和八相位 FSR 响应；tb_mute_slew 检查 1056 帧渐变与静音恢复。

采样测试中的 best_t90_us/worst_t90_us 保留旧指标字段名，现在实际测的是按压到消音状态置位的延迟，结果为 1093.666至1531.164µs（12.288MHz 测试档）。不包含后续完整静音渐变时间，也不等同实物延迟。生产 I2S 集成台使用真实 27MHz、UART 和 ADC 时序，只缩短测试曲单位以等待首个真实音符后进行检查。

定向门禁用时 163.29s；生产烧录脚本随后执行默认 Quick：13 个正向测试＋6 个非法参数负例，共 19 项通过。没有跳过仿真，没有运行全部历史 Full 回归。

最初两次集成台开发失败已保留：首次是新启用的 HOST 前端缺少测试源清单；第二次是在测试曲首拍前检查音频，得到零。补齐依赖、等待首个真实音符并仅缩短测试节拍后，完整断言通过。未删除或弱化精确静音、恢复、时钟或弯音判据。
