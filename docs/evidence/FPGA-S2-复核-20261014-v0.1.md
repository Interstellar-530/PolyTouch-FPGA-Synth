# S2 复核记录（2026-10-14）

S2 数字验收通过：最终十二台 RTL 门禁、PCM/WAV/FFT 分析和 Gowin 综合/PnR 均退出 0。首交付基线为 `8d0fa2f`，复核修补在工作分支 `codex/s2-gpio-keyboard` 上，测试记录的 33 个输入文件 SHA256 与最终工作区逐项一致。生产 Flash 仍保持 v1.01；本次没有烧录。

首交付的不足集中在可构建性和 Panic 边界。Gowin 工程没有收录 `gpio_keyboard.v`，且该文件用连续赋值驱动 `reg pop`，综合会拒绝；已补齐新建和已有工程的源文件清单，并把 `pop` 改为 `wire`。各 always 过程的循环变量已分开。消抖完成前收到 flush 时，原代码会在之后持续按住期间补发 Note On；新增断言复现了这一失败，`suppress_on` 修补后通过，键松开再按可重新起音。上述修改保持现有模块端口和事件格式。

满队列验收补了两层：单键的 2 项队列满载后送达 1 个 Off 和 1 个 On，丢弃计数为零；顶层人为延长高优先级 UART 来源的占用，使手动 FIFO 装满 12 个 On 和 4 个 Off，再让 GPIO 暂存另外 4 个 Off。恢复仲裁后，20 个事件逐音高核对全部送达，满队列同拍读写得到覆盖。缓冲容量按键分配，同一键超过 2 个未发送边沿仍会丢弃；不能把合计 24 项容量当成任意事件分布都可使用的共享队列。

A4 以 32768 点真实串行样本估计为 439.9999746619 Hz，误差约 0.00002534 Hz。方法为 Hann FFT 主峰定位后对原样本作正弦/余弦/DC 最小二乘细化；原 FFT 频点间隔仍为 1.430511 Hz。四个不同基频在逐个松键后消失，全部释放及 M0 数字样本为零；频谱和释音图已视觉复核，原始捕获 SHA256 与 S2 首交付一致。这是模型中的数字频率验证，不测量实物晶振或模拟输出。
